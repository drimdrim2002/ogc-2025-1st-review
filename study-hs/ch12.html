1부 · 흐름과 묶음

들어온 만큼 나간다: 흐름 보존

상수도관을 떠올려 보세요. 갈라지고 합쳐지는 관을 따라 물이 흐릅니다. 물탱크에서 보낸 물이 관을 지나다 중간에 새거나 갑자기 생겨날 수는 없습니다. 중간 연결 마디에서는 들어온 물의 양과 나간 물의 양이 같아야 합니다.

작은 배달망으로 숫자를 넣어 봅니다. 출발지 s에서 물건 2상자를 보내 도착지 t에서 2상자를 받습니다. 중간에 거점 a가 하나 있고, 길은 세 개뿐입니다. 각 길에는 하루에 보낼 수 있는 최대 양(용량)이 1상자로 정해져 있습니다.

이 규칙을 방향 간선 i → j를 지나는 흐름 변수 fij ≥ 0으로 적습니다. 각 지점 i에는 "내보내는 양"을 뜻하는 수 bi를 둡니다. 출발지이면 bi > 0, 도착지이면 bi < 0, 거점이면 bi = 0입니다. 위 오른쪽 그림에서는 bs = 2, ba = 0, bt = −2입니다.

정의 방향 그래프에서 간선마다 흐르는 양을 변수 fij ≥ 0으로 두고, 모든 노드 i마다 다음 등식을 요구하는 것을 흐름 보존(flow conservation)이라고 합니다.
Σj fij − Σj fji = bi모든 노드 i  (나가는 양 − 들어오는 양 = 공급 bi)
0 ≤ fij ≤ uij모든 방향 간선 i → j  (용량 제한)

오른쪽 그림의 세 노드에 이 식을 적으면 s는 fsa + fst = 2, a는 fat − fsa = 0, t는 −fat − fst = −2입니다. 간선마다 비용 cij를 곱해 Σ cijfij를 최소화하면 최소비용 흐름 문제입니다. 특히 bs = 1, bt = −1이고 나머지 bi = 0이며 비용이 간선 길이(또는 1)이면 s에서 t까지의 최단 경로 문제가 됩니다.

"들어온 양 − 나간 양 = 쓰는 양"으로 적을 수도 있습니다. 양변에 −1을 곱하면 모양이 바뀔 뿐 뜻은 같습니다. tryAgain 모형의 첫 번째 제약도 "원래 수요 + 다른 구간이 쪼개지며 들어온 토막 − 쪼개져 나간 수"를 맞추는 흐름 보존의 꼴입니다(4부).

짝짓기와 고르기: 배정, 집합 분할·덮개·포장

흐름이 물길이라면, 이번에는 "딱 맞게 고르기"입니다. 먼저 작업자 n명에게 일 n개를 한 사람당 하나씩 맡기는 배정(assignment) 문제를 봅니다. 이진변수 xik는 "작업자 i가 일 k를 맡으면 1"입니다.

Σk xik = 1모든 작업자 i (한 사람당 일 하나)
Σi xik = 1모든 일 k (일 하나당 한 사람)

이제 조금 더 넓은 상황을 생각합니다. 고객 1, 2, 3에게 물건을 배달해야 합니다. 트럭 한 대가 한 번에 돌 수 있는 후보 경로 여섯 가지를 미리 만들어 비용을 계산해 두었습니다.

후보 경로방문하는 고객비용특징
S1, S2, S3{1}, {2}, {3}4, 4, 4한 집씩 따로 간다
S4{1, 2}51과 2를 한 번에 돈다
S5{2, 3}52와 3을 한 번에 돈다
S6{1, 2, 3}9세 집을 한 번에 돈다

후보 경로 j를 고르면 xj = 1, 안 고르면 0입니다. 고객마다 "적힌 경로 중 몇 개에 들어가는가"를 세는 식은 같고, 오른쪽 부등호만 달라집니다. 고객 2를 예로 들면 S2, S4, S5, S6에 고객 2가 들어 있으므로 합은 x2 + x4 + x5 + x6입니다.

정의 원소들의 집합과 후보 묶음 S1, …, Sn(각각 비용 cj)이 있고, 원소 i가 묶음 j에 들어 있으면 aij = 1, 아니면 0이라고 둡니다. 이진변수 xj ∈ {0, 1}에 대해 다음 세 모형이 있습니다.
  • 집합 분할(set partitioning): Σj aijxj = 1 (모든 원소 i). 모든 원소가 고른 묶음 중 정확히 하나에 들어갑니다.
  • 집합 덮개(set covering): Σj aijxj ≥ 1 (모든 원소 i). 모든 원소가 적어도 하나에 들어갑니다.
  • 집합 포장(set packing): Σj aijxj ≤ 1 (모든 원소 i). 고른 묶음끼리 서로 겹치지 않습니다(보통 최대화).

위의 배달 예에서 집합 분할의 가능해는 {1}{2}{3}(비용 12), {1, 2}{3}(9), {1}{2, 3}(9), {1, 2, 3}(9) 네 가지입니다. 최적값은 9이고 최적해는 셋입니다. 반면 S4 = {1, 2}와 S5 = {2, 3}을 함께 고르면 고객 2를 두 번 방문하게 되어(x2 + x4 + x5 + x6 = 2) 집합 분할에서는 안 되지만, 집합 덮개에서는 비용 10의 가능해로 허용됩니다.

경로를 미리 다 만들어 두면 제약이 "고객마다 = 1" 한 종류로 놀랄 만큼 깔끔해집니다. 문제는 고객이 100명만 되어도 가능한 경로의 수가 천문학적으로 많아 목록을 미리 만들 수 없다는 것입니다. 그래서 필요한 경로만 그때그때 만들어 넣는 방법(열 생성)을 15장에서 배웁니다.

2부 · 순서와 연결성

외판원 문제와 부분 순환

배달 기사 한 명이 도시 0에서 출발해 나머지 도시 1, …, n−1을 한 번씩만 들르고 다시 도시 0으로 돌아오려 합니다. 이동 거리의 합이 가장 짧은 길을 찾는 문제가 유명한 외판원 문제(TSP, traveling salesman problem)입니다.

가장 먼저 떠오르는 변수는 xij ∈ {0, 1}("도시 i에서 바로 도시 j로 이동하면 1", i ≠ j)입니다. 도시마다 한 번 나가고 한 번 들어와야 하므로 다음 두 줄을 적습니다.

Σj≠i xij = 1모든 도시 i (각 도시에서 정확히 한 번 나간다)
Σi≠j xij = 1모든 도시 j (각 도시로 정확히 한 번 들어온다)

이 두 줄을 차수 제약이라고 부릅니다. 이제 도시 6개에서 이 식만 넣고 풀었을 때 무슨 일이 생기는지 봅니다.

정의 전체 도시를 하나의 큰 고리로 도는 대신, 몇 개의 작은 고리로 갈라졌을 때 그 작은 고리를 부분 순환(subtour)이라고 합니다.
핵심 사실 차수 제약만 만족하는 0/1 해는 "도시들을 몇 개의 서로 겹치지 않는 고리로 나눈 것"과 같습니다. 고리가 딱 하나일 때만 외판원 문제의 해입니다.

차수 제약은 각 도시의 바로 앞과 바로 뒤만 봅니다(국소적인 조건). 3번 도시는 5번에서 와서 4번으로 가고 있을 뿐, 0번 도시와 이어져 있는지는 전혀 묻지 않기 때문에 3 → 4 → 5 → 3처럼 자기들끼리만 도는 작은 고리를 막지 못합니다.

고리가 하나인지, 여러 부분 순환으로 갈라졌는지는 다음 도시 번호를 따라가 보면 바로 알 수 있습니다.

def find_cycles(nxt):
    seen = [0] * len(nxt)
    cycles = []
    for start in range(len(nxt)):
        if seen[start] == 0:
            cur = start
            cyc = []
            while seen[cur] == 0:
                seen[cur] = 1
                cyc.append(cur)
                cur = nxt[cur]
            cycles.append(cyc)
    return cycles

print("해 A:", find_cycles([1, 2, 3, 4, 5, 0]))
print("해 B:", find_cycles([1, 2, 0, 4, 5, 3]))

해 A: [[0, 1, 2, 3, 4, 5]]
해 B: [[0, 1, 2], [3, 4, 5]]
  • 1~3행 nxt[i]는 도시 i 다음에 가는 도시 번호입니다. seen은 방문했는지 적는 목록입니다.
  • 4~12행 아직 안 본 도시에서 출발해 화살표를 따라가며 처음 도시로 돌아올 때까지 cyc에 담습니다.
  • 15~16행 해 A는 고리가 하나뿐이고, 해 B는 고리가 두 개([0, 1, 2]와 [3, 4, 5])로 갈라졌습니다.

방법 ①: 순번 변수 u와 MTZ 제약

이제 부분 순환을 1차 부등식으로 막는 세 가지 방법을 배웁니다. 첫째 방법은 방문 순서 번호표를 붙이는 것입니다. 이 방법을 만든 세 사람(Miller, Tucker, Zemlin)의 머리글자를 따서 MTZ 제약이라고 부릅니다.

이 절에서만 도시의 방문 순번을 나타내는 변수로 ui를 씁니다(9장의 쌍대 변수 u와는 다른 뜻입니다). 4부에서는 쓰지 않습니다.

출발 도시 0은 빼고, 나머지 도시 1, …, n−1마다 순번 변수 ui를 하나씩 둡니다. "도시 0 다음 첫 번째로 들르는 도시는 u = 1, 두 번째는 u = 2, …, 마지막 도시는 u = n − 1"이 되도록, i에서 j로 가면 j의 번호표가 i보다 최소 1 크다고 적습니다. 11장에서 배운 big-M 꼴(M = n − 1)을 그대로 씁니다.

uj ≥ ui + 1 − (n − 1)(1 − xij)모든 i ≠ j (단 i, j ∈ {1, …, n−1}, 도시 0은 제외)
1 ≤ ui ≤ n − 1모든 i ∈ {1, …, n−1}

도시 6개(n = 6)일 때 앞의 엉터리 해 B(0→1→2→0과 3→4→5→3)가 왜 막히는지 숫자를 넣어 봅니다. 부분 순환 3 → 4 → 5 → 3에는 도시 0이 없으므로 세 간선 모두 위 식이 걸립니다(x34 = x45 = x53 = 1).

u4 ≥ u3 + 1,   u5 ≥ u4 + 1,   u3 ≥ u5 + 1

세 식의 왼쪽끼리, 오른쪽끼리 모두 더하면 u3 + u4 + u5 ≥ u3 + u4 + u5 + 3, 곧 0 ≥ 3이라는 모순이 나옵니다. 번호표가 한 바퀴 돌며 계속 커질 수는 없기 때문입니다.

부분 순환이 하나라도 있으면 그중 적어도 하나는 출발 도시 0을 지나지 않으므로(0은 고리 하나에만 들어갈 수 있으니까요), 그 고리에서 위와 같은 모순이 생깁니다. 반대로 도시 전체를 한 바퀴 도는 정상적인 해 0 → i1 → i2 → … → in−1 → 0에서는 uit = t로 두면 됩니다. 가는 간선(xij = 1)에서는 uj = ui + 1이 딱 맞고, 안 가는 간선(xij = 0)에서는 식이 uj ≥ ui − (n − 2)인데 ui ≤ n − 1, uj ≥ 1이므로 언제나 성립합니다. 그래서 멀쩡한 한 바퀴 순환은 하나도 잘리지 않습니다.

출발 도시 0과 연결된 간선에 MTZ 식을 걸지 않는 것이 핵심입니다. 마지막 도시에서 도시 0으로 돌아올 때는 번호표가 n−1에서 다시 0으로 돌아와야 하므로, 거기까지 식을 걸면 정상적인 한 바퀴까지 잘려 버립니다.

방법 ②: 부분 순환 제거 부등식

이번에는 순번 변수 u를 새로 만들지 않고 x만으로 부분 순환을 막아 봅니다. 해 B의 부분 순환 S = {3, 4, 5}를 보세요. 도시 3개를 도는 작은 고리에는 간선이 3개(3→4, 4→5, 5→3) 있습니다. 전체를 한 바퀴 도는 길이라면 S 안의 도시들끼리만 오가는 간선이 많아야 2개여야 합니다(마지막 하나는 S 밖으로 나가야 하니까요).

x34 + x43 + x35 + x53 + x45 + x54 ≤ 2   (부분집합 S = {3, 4, 5}에 대해)
정의 도시들의 부분집합 S(원소 개수 2 ≤ |S| ≤ n − 1)마다 "S 안의 도시들끼리 잇는 간선은 |S| − 1개 이하"라고 적는 식을 부분 순환 제거 부등식이라고 합니다.
Σi∈S Σj∈S, j≠i xij ≤ |S| − 1   (2 ≤ |S| ≤ n − 1인 모든 부분집합 S)

이 식은 big-M도 추가 변수도 없어서 깔끔합니다. 하지만 치명적인 약점이 있습니다. 부분집합 S의 개수가 대략 2n개라서 도시가 50개만 되어도 부등식이 1,000조 개를 넘어, 모형에 처음부터 다 적을 수 없습니다. 그래서 실제 솔버는 일단 차수 제약만으로 풀고, 답에 부분 순환이 보이면 그 S에 대한 식만 골라서 덧붙이고 다시 푸는 방식을 씁니다(14장의 절단평면에서 다시 만납니다).

연결성을 적는 세 방법 비교

"고른 것들이 출발점(도시 0이나 배의 출입구)과 하나로 이어져 있어야 한다"는 조건을 1차 부등식으로 적는 세 가지 방법을 한눈에 견주어 봅니다. 둘째 방법은 1부의 흐름을 쓰는 것이고, 셋째 방법은 5장에서 배운 높이 h(i)를 쓰는 tryAgain의 방법입니다.

  • ① 순번 변수(MTZ): 위에서 본 방법입니다. 도시마다 순번 변수 u를 두고 big-M을 써서 간선을 따라 순번이 늘게 합니다.
  • ② 흐름 변수: 도시 0이 물건 n − 1개를 내보내고, 다른 도시마다 1개씩 받는다고 둡니다. 물건은 선택된 간선으로만 흐를 수 있게 0 ≤ fij ≤ (n − 1)xij를 겁니다. 도시 0과 끊긴 부분 순환 안에는 물건이 들어갈 수 없으므로, 그 도시들은 1개를 받을 수 없어 모순이 생깁니다.
  • ③ 미리 정한 높이로 전파하기(tryAgain의 방법): 순서를 변수로 두지 않고, 5장에서 배운 대로 너비 우선 탐색(BFS) 방문 순번으로 높이 h(i)를 미리 고정합니다. 각 노드의 아래 이웃 pred(i)에 대해서만 연결을 허락하면, 높이가 계속 줄어드는 길만 따라가므로 부분 순환이나 "서로 받쳐 주는 섬"이 절대 생길 수 없습니다.

5장에서 배운 6칸 고리(출입구 0, 칸 1~5가 0-1-2-3-4-5-0으로 이어진 배)를 떠올려 보세요. 칸 1과 칸 5에 머무는 차가 있을 때, 그냥 모든 이웃을 허용하면 칸 2, 3, 4가 서로를 근거로 "접근 가능하다"고 우기는 서로 받쳐 주는 섬이 생겼습니다. 아래 이웃 pred(i)만 적으면 근거를 따라갈수록 높이가 줄어들어 반드시 출입구에서 끝나므로 섬이 사라집니다.

3부 · 택배 트럭 경로 문제와 대칭성

택배 트럭 경로 문제의 모형

이제 11장의 배달 시각(big-M)과 이 장의 흐름 보존·집합 분할·MTZ를 하나로 합쳐 봅니다. 물류센터(노드 0)에서 트럭 K대가 출발해 고객 1, …, n에게 배달하고 돌아옵니다. 트럭마다 실을 수 있는 용량은 Q, 고객 i가 주문한 무게는 qi, 배달받을 수 있는 시간창은 [ai, bi]입니다(학술 이름으로는 용량과 시간창이 있는 차량 경로 문제, CVRPTW라고 부릅니다).

결정변수는 둘입니다. 이진변수 xijk는 "트럭 k가 i에서 바로 j로 가면 1", 실수 변수 tik는 "트럭 k가 고객 i에서 배달을 시작하는 시각"입니다. cij는 이동 비용, si는 일하는 시간, τij는 이동 시간입니다.

최소화  Σk Σi Σj cij xijk모든 트럭의 총 이동 비용
(1)Σk Σj xijk = 1모든 고객 i  [집합 분할: 한 번만 방문]
(2)Σi xihk − Σj xhjk = 0모든 고객 h, 모든 트럭 k  [흐름 보존]
(3)Σj x0jk ≤ 1모든 트럭 k  [집합 포장: 트럭당 한 번 출발]
(4)Σi qi Σj xijk ≤ Q모든 트럭 k  [용량 제한]
(5)tjk ≥ tik + si + τij − Mij(1 − xijk)모든 고객 i ≠ j, 모든 트럭 k  [big-M · MTZ 겸용]
(6)ai ≤ tik ≤ bi모든 고객 i, 모든 트럭 k  [시간창]

여섯 줄 모두 우리가 이미 배운 관용구입니다. 특히 (5)번은 11장에서 구한 가장 작은 유효한 Mij = bi + si + τij − aj를 씁니다. 동시에 si + τij > 0인 한 물류센터(0)를 거치지 않는 고리를 돌면 시각이 끝없이 늘어나므로, MTZ처럼 부분 순환도 함께 막아 줍니다.

모형의 크기를 세어 봅니다. 고객 n = 100명, 트럭 K = 10대라면 노드가 101개이므로 변수 xijk만 101 × 100 × 10 = 101,000개이고, 제약 (5)는 100 × 99 × 10 = 99,000줄입니다. 변수가 세 개의 첨자를 달고 다니기 때문에 크기가 빠르게 불어납니다.

대칭성: 이름표만 다른 같은 해

위 모형에는 숨은 골칫거리가 하나 더 있습니다. 트럭 10대가 모두 같은 트럭이라고 합시다. 그러면 "1번 트럭이 강남을 돌고 2번 트럭이 강북을 도는 해"와 "2번 트럭이 강남을 돌고 1번 트럭이 강북을 도는 해"는 실제로는 완전히 같은 계획입니다. 하지만 모형에서는 xij1과 xij2가 다른 변수라서 서로 다른 두 해로 셉니다.

정의 물건이나 차량처럼 서로 구별할 필요가 없는 대상에 번호를 붙여 적었을 때, 번호(이름표)만 맞바꾼 사실상 같은 해가 여럿 생기는 현상을 대칭성(symmetry)이라고 합니다.

트럭 10대가 모두 일을 하면 번호표를 바꾸는 가짓수가 10! = 3,628,800가지입니다. 분지한계법(13장)은 번호표만 다른 360만 개의 해를 일일이 갈라 보며 치워야 할 수 있어서 풀이가 크게 느려집니다.

대칭성을 없애는 길은 둘입니다. 첫째는 "1번 트럭부터 차례로 쓴다", "트럭 번호가 클수록 첫 고객 번호가 크다" 같은 대칭 깨기 제약을 덧붙이는 것입니다. 둘째는 더 근본적인 방법인데, 애초에 변수에 이름표를 넣지 않는 것입니다. 바로 이어서 볼 tryAgain 모형이 이 길을 택했습니다. 변수 xpqi에는 "몇 번째 차인지"가 들어 있지 않고, 오직 구간이 있는지 없는지만 적습니다.

4부 · tryAgain 모형

tryAgain 모형의 변수 x, y, z와 목적함수

이제 1장의 자동차 운반선 문제를 적은 tryAgain 모형 전체를 봅니다. 먼저 문제에서 주어지거나 그래프에서 미리 계산해 두는 수(파라미터)부터 정리합니다.

기호뜻미니 문제 B에서의 값
N, P, F노드 수(출입구 0 + 칸 1~N−1), 항구 수(0~P−1), 경로 고정비N = 3, P = 4, F = 10
dpq항구 p에서 실어 항구 q에서 내릴 차의 수 (p < q)d02 = 1 (차 A), d13 = 1 (차 B), 나머지 0
dist(i)출입구 0에서 칸 i까지의 최단거리(4장 BFS)dist(1) = 1, dist(2) = 2
h(i), pred(i)노드 i의 높이(5장), 높이가 더 낮은 이웃들의 집합h(i) = i, pred(1) = {0}, pred(2) = {1}

핵심 생각은 구간입니다. 차 한 대가 "어느 항구 p에서 실려, 칸 i에 서 있다가, 항구 q에서 내려질 때까지"를 하나의 구간이라고 부릅니다. 1장에서 본 미니 문제 B(일렬 배: 출입구 0–칸 1–칸 2, 차 A: 0→2, 차 B: 1→3)의 최적해 (가)를 구간 막대로 그려 봅니다.

모형의 결정변수는 세 종류입니다. 숫자를 넣어 쓸 때 항구 둘과 칸 번호가 헷갈리면 x02,1(p = 0, q = 2, 칸 1)처럼 쉼표를 넣습니다.

정의 (tryAgain 모형의 변수)
  • xpqi ∈ {0, 1} (p < q, 칸 i = 1, …, N−1): 항구 p에서 칸 i에 실려 항구 q에서 내리는 구간이 있으면 1, 없으면 0.
  • ypi ∈ {0, 1} (중간 항구 p = 1, …, P−2, 노드 i = 0, …, N−1): 항구 p에서 노드 i가 접근 가능하면 1.
  • zpqr ≥ 0 정수 (p < q < r): 항구 p에서 실어 r에서 내릴 차 가운데, 중간 항구 q에서 잠깐 내렸다 다시 실어 구간을 둘((p, q)와 (q, r))로 쪼갠 대수.

y를 첫 항구(0)와 마지막 항구(P−1)에 두지 않는 이유는 간단합니다. 첫 항구에서는 배가 비어 있고, 마지막 항구에서는 남은 차를 모두 내리므로 머무는 차가 없기 때문입니다. 모든 칸이 비어 있어 접근 가능 여부를 따질 필요가 없습니다.

목적함수는 구간의 비용 합입니다. 구간 하나마다 실을 때 경로 하나, 내릴 때 경로 하나, 곧 경로 둘이 생기고, 칸 i까지의 경로 하나의 비용은 F + dist(i)입니다. 따라서 구간 하나의 비용은 2 · (F + dist(i))입니다.

최소화  Σp<q Σi 2 · (F + dist(i)) · xpqi모든 항구 쌍 p < q, 모든 칸 i

z와 y에는 비용이 없습니다. 구간을 쪼개면 x가 하나 더 1이 되면서 2(F + dist(i))가 자동으로 붙기 때문입니다. 또한 모든 계수가 2 × (정수)이므로 목적함수 값은 언제나 짝수입니다(13장 「k의 배수」 논증의 근거입니다).

제약 ①~⑥: 여섯 줄로 문제 전체를 적다

이제 여섯 가지 제약을 한꺼번에 적어 놓고, 각 줄이 앞의 어느 관용구인지 읽습니다.

제약 ①Σi xpqi = dpq − Σp<r<q zprq + Σr>q zpqr + Σr<p zrpq모든 항구 쌍 p < q
제약 ②Σp<q Σr>q xpri ≤ 1 − yqi모든 중간 항구 q, 모든 칸 i
제약 ③Σp<q xpqi ≤ yqi모든 중간 항구 q, 모든 칸 i
제약 ④Σr>q xqri ≤ yqi모든 중간 항구 q, 모든 칸 i
제약 ⑤yqi ≤ Σj∈pred(i) yqj모든 중간 항구 q, 모든 칸 i
제약 ⑥yq0 = 1모든 중간 항구 q
  • 제약 ① (수요 맞추기 = 흐름 보존). 왼쪽은 "(p, q) 구간이 몇 대 있는가"입니다. 오른쪽은 원래 수요 dpq에서 중간 항구 r에서 쪼개져 사라진 수(zprq)를 빼고, 더 긴 구간 (p, r)이나 (r, q)가 쪼개지며 새로 생긴 앞·뒤 토막(zpqr, zrpq)을 더한 값입니다.
  • 제약 ② (머무는 차가 있는 칸은 접근 불가). 왼쪽은 항구 q보다 일찍(p < q) 실려 q보다 늦게(r > q) 내리는 구간, 곧 항구 q에서 칸 i에 머무는 차의 합입니다. 11장에서 본 "모은 식"(x1 + x2 + … ≤ 1 − y)이라서, 머무는 차는 많아야 1대이고(포장), 1대라도 있으면 yqi = 0이 됩니다.
  • 제약 ③ (내리려면 접근 가능). 왼쪽은 항구 q에서 칸 i로부터 내리는 차의 합입니다. 내리는 차는 많아야 1대이고, 내리려면 yqi = 1이어야 합니다.
  • 제약 ④ (실으려면 접근 가능). 왼쪽은 항구 q에서 칸 i에 싣는 차의 합입니다. 실으려면 역시 yqi = 1이어야 합니다. 제약 ③과 ④는 서로를 막지 않아서, 같은 항구에서 한 차를 내리고 그 칸에 새 차를 실을 수 있습니다.
  • 제약 ⑤⑥ (접근 가능 전파). 2부에서 본 "고정 높이 전파" 그대로입니다. 출입구는 언제나 접근 가능하고(⑥), 칸 i가 접근 가능하려면 아래 이웃 pred(i) 가운데 적어도 하나가 접근 가능해야 합니다(⑤).

"한 칸에 차 두 대가 겹치는 일은 왜 없는가?" 모형에 "동시에 한 대 이하"라는 식을 따로 적지 않았는데도 겹칠 수 없습니다. 칸 i에 두 구간 A(a1 → a2)와 B(b1 → b2)가 겹쳤다고 해 봅시다. ① B가 A의 도중에 실리면(a1 < b1 < a2), 항구 b1에서 A는 머무는 차이므로 ②가 y = 0을 강제하고, B를 실어야 하므로 ④가 y = 1을 요구해 모순입니다. ② 같은 항구에서 실려 A가 먼저 내리면(a1 = b1, a2 < b2), 항구 a2에서 B는 머무는 차(y = 0)인데 A를 내려야 하므로 ③이 y = 1을 요구해 역시 모순입니다. 시작과 끝이 모두 같으면 같은 변수 xpqi ∈ {0, 1}이므로 애초에 1대뿐입니다.

11장 끝에서 본 대로 y는 목적함수에 비용이 0인 스위치입니다. 그래서 아무 일도 없는 빈칸의 y가 0으로 나와도 제약 위반이 아니며, 실제로 싣거나 내리지 않으므로 해가 틀릴 일도 없습니다.

가장 작은 예(미니 문제 B)에 숫자 넣기

미니 문제 B(N = 3, P = 4, d02 = d13 = 1)에 일반식을 그대로 풀어 적어 봅니다. 먼저 항구 쌍 여섯 개에 대한 제약 ① 여섯 줄입니다.

x01,1 + x01,2 = 0 + z012 + z013(0, 1): 0→2나 0→3이 1에서 쪼개진 앞 토막
x02,1 + x02,2 = 1 − z012 + z023(0, 2): 수요 1대, 항구 1에서 쪼개면 빠짐
x03,1 + x03,2 = 0 − z013 − z023(0, 3): 수요 없음 → z013 = z023 = 0
x12,1 + x12,2 = 0 + z123 + z012(1, 2): 0→2의 뒤 토막 또는 1→3의 앞 토막
x13,1 + x13,2 = 1 − z123 + z013(1, 3): 수요 1대, 항구 2에서 쪼개면 빠짐
x23,1 + x23,2 = 0 + z023 + z123(2, 3): 1→3이 2에서 쪼개진 뒤 토막

앞 그림의 해 (가)(x01,1 = 1, x12,1 = 1, x13,2 = 1, z012 = 1, 나머지 x와 z는 0)를 넣어 보세요. (0, 1)은 1 = 0 + 1, (0, 2)는 0 = 1 − 1, (1, 2)는 1 = 0 + 1, (1, 3)은 1 = 1로 여섯 줄 모두 딱 맞습니다. 비용은 22 + 22 + 24 = 68입니다.

이제 재배치 없이(z = 0) 차 A를 안쪽 칸 2에, 차 B를 바깥쪽 칸 1에 둔 배치(x02,2 = 1, x13,1 = 1)를 제약 ②③⑤에 넣어 봅니다. 항구 2, 칸 2에서 A를 내려야 하므로 제약 ③이 x02,2 ≤ y2,2에서 y2,2 = 1을 요구합니다. 그러면 제약 ⑤(y2,2 ≤ y2,1) 때문에 y2,1 = 1이어야 합니다. 그런데 항구 2, 칸 1에는 차 B가 머물고 있으므로 제약 ②(x13,1 ≤ 1 − y2,1)가 y2,1 = 0을 요구합니다. 모순입니다! 이렇게 식 세 줄이 사슬처럼 맞물려 불가능한 배치를 막아 줍니다.

def model_size(N, P):
    pairs = P * (P - 1) // 2
    triples = P * (P - 1) * (P - 2) // 6
    nx = pairs * (N - 1)
    ny = (P - 2) * N
    nz = triples
    nc = pairs + 4 * (P - 2) * (N - 1) + (P - 2)
    return nx + ny + nz, nc

print("미니 문제 B:", model_size(3, 4))
print("공식 예시:", model_size(5, 5))
print("본선 큰 문제:", model_size(163, 20))

  • 2~3행 항구 쌍(PC2)과 항구 셋(PC3)의 개수를 정수 나눗셈 //으로 구합니다.
  • 4~6행 x, y, z 변수의 개수입니다.
  • 7행 제약 ①~⑥을 모두 더한 줄 수입니다.
  • 10~12행 N = 163, P = 20인 큰 문제도 변수 약 3만 5천 개, 제약 약 1만 2천 줄에 담깁니다.

가이드와 연결

가이드의 「모형 한 줄씩」 절에 나오는 변수 x, y, z와 제약 ①~⑥이 바로 이 장 4부의 식입니다. 가이드가 "첨자에는 노드와 항구만 있고 간선과 순번은 없다"고 적은 것은, 2부에서 비교한 MTZ·흐름 방법 대신 고정 높이 전파를 택했기 때문입니다.

가이드가 1등 팀이 대칭성을 피한 비결로 꼽는 "어느 수요의 차인지 이름을 붙이지 않고 구간의 개수만 센 것"은 3부의 대칭성 이야기입니다. 대칭 깨기 제약을 덧붙이는 대신 아예 이름표를 변수에서 뺐습니다.

가이드가 설명하는 "위치변경과 높이를 거스르는 길을 잃는다"는 대목은 2부 비교 표의 「멀쩡한 답을 잃는가: 예」에 해당합니다. 16장에서 이 모형의 장단점을 이론 전체로 다시 짚어 봅니다.

  • 흐름 보존: 노드마다 (나가는 양) − (들어오는 양) = (공급). 최소비용 흐름과 최단 경로가 이 꼴입니다.
  • 집합 분할(= 1), 덮개(≥ 1), 포장(≤ 1)은 고른 묶음들이 원소를 몇 번 덮는지로 갈립니다.
  • 차수 제약만 적으면 부분 순환이 생깁니다. MTZ(순번 변수 u + big-M), 흐름 변수, 부분 순환 제거 부등식, 고정 높이 전파로 막습니다.
  • 구별할 필요 없는 대상에 번호표를 붙이면 대칭성이 생겨 탐색이 느려집니다.
  • tryAgain 모형은 변수 xpqi(구간), ypi(접근 가능), zpqr(쪼개기)와 제약 ①~⑥으로 이루어지며, big-M도 대칭성도 없습니다.

연습문제

1부의 작은 배달망(s→a 비용 1, a→t 비용 1, s→t 비용 3)에서 각 길의 용량이 2상자로 늘고, s에서 t로 2상자를 보낸다고 합시다. 흐름 보존식을 만족하면서 가장 싼 흐름은 무엇이고 총비용은 얼마인가요?

fsa = 2, fat = 2, fst = 0입니다. 흐름 보존: s는 2 + 0 = 2, a는 2 − 2 = 0, t는 −2 − 0 = −2로 모두 성립합니다. 총비용은 1 × 2 + 1 × 2 = 4입니다.

1부의 배달 예(고객 {1, 2, 3}, S1={1}(4), S2={2}(4), S3={3}(4), S4={1,2}(5), S5={2,3}(5), S6={1,2,3}(9))에서 S6의 비용이 9에서 10으로 올랐을 때, 집합 분할의 최적값과 집합 덮개의 최적값은 각각 얼마인가요?

집합 분할에서는 {1, 2}{3}과 {1}{2, 3}이 비용 5 + 4 = 9로 가장 쌉니다(S6은 10이라 탈락). 집합 덮개에서는 {1, 2}와 {2, 3}을 함께 골라도 5 + 5 = 10이므로 9보다 싸지 않아 최적값은 역시 9입니다.

도시 5개(0~4)에서 해 0 → 1 → 0, 2 → 3 → 4 → 2가 MTZ 제약을 어기는 것을 보이세요. 0 → 1 → 0의 간선에는 MTZ 식이 걸리나요?

2 → 3 → 4 → 2에는 도시 0이 없으므로 u3 ≥ u2 + 1, u4 ≥ u3 + 1, u2 ≥ u4 + 1이 모두 걸립니다. 세 식을 더하면 0 ≥ 3으로 모순입니다. 0 → 1 → 0의 두 간선에는 도시 0이 끼어 있어 MTZ 식이 걸리지 않지만, 부분 순환 하나만 막아도 해 전체가 불능이 되므로 충분합니다.

본문의 find_cycles 함수에 [2, 0, 1, 4, 3]을 넣으면 어떤 결과가 나올지 손으로 따라가 보세요.

start = 0에서 0 → 2 → 1 → 0으로 첫 고리 [0, 2, 1]을 찾습니다. start = 1, 2는 이미 방문했으므로 건너뛰고, start = 3에서 3 → 4 → 3으로 둘째 고리 [3, 4]를 찾습니다. 결과는 [[0, 2, 1], [3, 4]]로, 부분 순환 두 개가 나옵니다.

3 × 3 격자 배(pred(3) = {1}, pred(4) = {1, 2}, pred(6) = {3, 4})의 어느 항구에서 칸 1과 칸 2에 모두 머무는 차가 있습니다. 제약 ②와 ⑤를 따라가며 y6 = 1이 가능한지 확인하세요.

칸 1과 칸 2에 머무는 차가 있으므로 제약 ②에서 y1 = 0, y2 = 0입니다. 제약 ⑤에 의해 y3 ≤ y1 = 0, y4 ≤ y1 + y2 = 0이므로 y3 = y4 = 0이고, 따라서 y6 ≤ y3 + y4 = 0입니다. y6 = 1은 불가능합니다.

미니 문제 B의 다른 최적해 (나)(x02,2 = 1, x12,1 = 1, x23,1 = 1, z123 = 1)를 제약 ①의 여섯 줄에 대입해 확인하고, y1,1, y1,2, y2,1, y2,2의 값을 정해 보세요.

제약 ①: (0,1) 0 = 0, (0,2) 1 = 1 − 0 + 0, (0,3) 0 = 0, (1,2) 1 = 0 + 1 + 0, (1,3) 0 = 1 − 1 + 0, (2,3) 1 = 0 + 0 + 1로 모두 맞습니다. 항구 1에서는 칸 2에 A가 머무니 y1,2 = 0(②), 칸 1에 B를 실으니 y1,1 = 1(④). 항구 2에서는 칸 2에서 A를 내리니 y2,2 = 1(③), 그러려면 y2,1 = 1(⑤)이어야 하고 칸 1에는 머무는 차가 없어 ②도 성립합니다.

항구가 5개(0~4)일 때, 제약 ②에서 항구 q = 2, 칸 i의 왼쪽 합을 풀어 쓰세요.

p < 2이므로 p는 0 또는 1, r > 2이므로 r은 3 또는 4입니다. 따라서 왼쪽은 x03,i + x04,i + x13,i + x14,i입니다. 항구 2를 사이에 끼고 지나는 구간 네 가지입니다.

노드 N = 8, 항구 P = 4인 가지가 있는 배에서 tryAgain 모형의 변수 x, y, z와 제약 ①~⑥의 개수를 각각 세고, 본문의 model_size(8, 4)와 맞는지 확인하세요.

x: (4×3/2) × 7 = 6 × 7 = 42개. y: (4 − 2) × 8 = 16개. z: 4×3×2/6 = 4개. 변수 합계 62개. 제약 ①: 6줄, ②~⑤: 4 × 2 × 7 = 56줄, ⑥: 2줄. 제약 합계 64줄입니다.
