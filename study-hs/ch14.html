강한 정식화와 절단평면

13장에서 분지한계법이 빨리 끝나려면 "LP 완화의 값이 진짜 최적값에 가까워야 한다"고 했습니다. 같은 정수 문제라도 식을 어떻게 적느냐에 따라 LP 완화의 값이 크게 달라집니다. 이 장에서는 식을 처음부터 단단하게 적는 원리(강한 정식화)와, 풀면서 소수 답만 정교하게 잘라 내는 방법(절단평면)을 배웁니다.

  • 미리 알아야 할 것. 3장(행렬식, 크라메르 공식, 삼각형 연립방정식), 5장(이분 그래프, 홀수 순환), 12장(tryAgain 모형의 변수와 제약 ①~⑥), 13장(LP 완화, 하한, 분지한계법). 고등학교의 직선의 방정식과 부등식의 영역.
  • 이 장을 읽고 나면. 두 정식화 중 어느 쪽이 더 강한지 판정할 수 있고, 볼록 껍질과 절단평면의 뜻을 그림과 숫자로 설명할 수 있습니다.
1부 · 정식화의 강도와 볼록 껍질

같은 정수해, 다른 LP 영역: 강한 정식화와 약한 정식화

농장에 흩어져 있는 말들을 울타리로 둘러싼다고 생각해 봅시다. 말들이 서 있는 자리는 똑같은데, 울타리를 헐렁하게 치면 빈 땅이 많이 들어가고, 말들 바로 바깥에 팽팽하게 치면 빈 땅이 줄어듭니다. 정수계획에서도 마찬가지입니다. 정수해(말)는 똑같은데, 정수 조건을 지운 LP 완화의 영역(울타리)은 식마다 넓이가 다릅니다.

11장에서 본 창고 예로 숫자를 확인합니다. 창고를 열면 고정비 100이 들고(이진변수 y), 고객 10명에게 이 창고에서 보내려면(이진변수 x1, …, x10) 창고가 열려 있어야 합니다. 두 가지로 적을 수 있습니다.

P강xj ≤ y  (모든 j = 1, …, 10, 모두 10줄)0 ≤ xj ≤ 1,  0 ≤ y ≤ 1
P약x1 + x2 + … + x10 ≤ 10y  (한 줄)0 ≤ xj ≤ 1,  0 ≤ y ≤ 1

x와 y가 0 아니면 1일 때는 두 모형이 허용하는 해가 똑같습니다. 하지만 정수 조건을 지우고 0과 1 사이의 소수를 허용한 뒤, "고객 1은 반드시 받아야 한다"(x1 = 1)를 넣고 창고 비용 100y를 최소화하면 어떻게 될까요?

  • P강에서는: 첫 줄 x1 ≤ y 때문에 1 ≤ y, 곧 y = 1이어야 합니다. LP 완화의 최솟값은 100입니다.
  • P약에서는: 1 + 0 + … + 0 ≤ 10y이므로 y = 0.1만 되어도 식을 지킵니다! LP 완화의 최솟값은 10입니다.

진짜 정수 최적값은 100입니다. P강은 LP 한 번으로 이미 100(gap 0)을 맞추지만, P약은 10이라는 턱없이 느슨한 하한을 내놓습니다. P강의 열 줄을 모두 더하면 P약의 한 줄이 나오므로, P강을 지키는 점은 모두 P약도 지키고, (x1 = 1, 나머지 x = 0, y = 0.1)처럼 P약에만 들어 있는 소수 점이 있습니다.

정의 정수해들의 집합 X가 있을 때, 그 정수해들을 품는 LP 영역 P(P 안의 정수점이 정확히 X인 영역)를 X의 정식화(formulation)라고 합니다. 같은 X를 나타내는 두 정식화 P1, P2가 P1 ⊂ P2를 만족하면 P1이 P2보다 강한 정식화(strong formulation), P2가 더 약한 정식화라고 합니다.
핵심 사실 최소화 문제에서 P1 ⊂ P2이면, LP 완화의 최적값은 언제나 다음 순서를 따릅니다.
(P2의 LP 값) ≤ (P1의 LP 값) ≤ (진짜 정수 최적값)

P1의 점은 모두 P2에도 들어 있으므로, P2에서 고를 수 있는 후보가 더 많습니다. 후보가 많을수록 최솟값은 더 작아질 수 있으므로 P2의 LP 값이 더 낮거나 같습니다. 반대로 P1은 정수해 X를 모두 품고 있으므로 P1의 LP 값은 정수 최적값 이하입니다. 곧 울타리가 좁을수록(강할수록) LP 하한이 진짜 값에 가까워집니다.

볼록 껍질과 이상적 정식화

그러면 정수해들을 감싸는 울타리 가운데 가장 팽팽한 울타리는 무엇일까요? 나무판 위에서 정수해가 있는 자리마다 못을 박아 두고, 그 바깥을 고무줄 하나로 팽팽하게 감싸 보세요. 고무줄이 만드는 다각형이 정수해들을 품는 가장 작은 볼록 영역입니다.

정의 점들을 모두 품는 가장 작은 볼록한 영역(고무줄로 감싼 모양)을 볼록 껍질(convex hull)이라고 합니다. LP 완화의 영역이 정수해들의 볼록 껍질과 정확히 같아지는 정식화를 이상적 정식화(ideal formulation)라고 합니다.

트럭 예(최소화 10x + 7y, 제약 9x + 5y ≥ 30, x, y ≥ 0 정수)로 고무줄을 걸어 봅니다. 조건을 지키는 정수점은 (0, 6), (1, 5), (2, 3), (3, 1), (4, 0)과 그 오른쪽 위 점들입니다. 아래쪽 가장자리에 고무줄을 걸면 어느 점들에 걸릴까요?

(0, 6)과 (3, 1)을 잇는 직선은 5x + 3y = 18입니다. (1, 5)를 넣으면 5 + 15 = 20 > 18이고, (2, 3)을 넣으면 10 + 9 = 19 > 18이라 두 점은 고무줄 안쪽에 들어갑니다. 고무줄이 걸리는 아래쪽 모퉁이는 (0, 6), (3, 1), (4, 0) 세 점뿐입니다. 따라서 트럭 예의 볼록 껍질은 다음 부등식들로 적힙니다.

5x + 3y ≥ 18(0, 6)과 (3, 1)을 잇는 변
x + y ≥ 4(3, 1)과 (4, 0)을 잇는 변
x ≥ 0,  y ≥ 0좌표축
핵심 사실 이상적 정식화에서는 정수 조건을 지우고 LP만 풀어도 정수 최적해가 나옵니다(LP 값 = 정수 최적값).

고무줄의 모퉁이(꼭짓점)는 못을 박은 자리, 곧 정수해에만 걸립니다. 6장에서 배웠듯이 LP의 최적해는 영역의 꼭짓점에서 나오므로, 볼록 껍질 위에서 LP를 풀면 꼭짓점인 정수해가 바로 나옵니다.

변수가 수만 개인 현실 문제에서는 고무줄의 모든 변을 미리 적을 수 없습니다. 그래서 실전의 목표는 처음부터 이상적 정식화에 가능한 한 가깝게 적고, 모자란 부분은 3부의 절단평면으로 깎아 내는 것입니다.

모은 식은 약한가, 강한가: 클릭 부등식과 5칸 고리

11장과 12장을 읽으면서 의아한 점이 하나 있었을 것입니다. 방금 창고 예에서는 변수를 한 줄에 모은 x1 + … + x10 ≤ 10y가 약한 식이었습니다. 그런데 12장 tryAgain 모형의 제약 ③(Σp xpqi ≤ yqi)은 여러 x를 한 줄에 모은 식인데도 오히려 강하다고 합니다. 왜 반대일까요?

열쇠는 모은 변수들이 동시에 1이 될 수 있는가입니다. 창고에서는 고객 10명을 동시에 받을 수 있어서 y 앞에 10(big-M)을 곱해야 했고, 그래서 y = 0.1만 되어도 x1 = 1이 허용되었습니다. 반면 tryAgain의 제약 ③은 한 항구에서 한 칸으로부터 내리는 차가 많아야 1대이므로, 모은 x들이 서로 동시에 1이 될 수 없습니다. 그래서 y 앞에 1이 붙습니다.

이진변수 x1, x2가 동시에 1이 될 수 없을 때, 두 식을 점 (x1, x2, y) = (0.5, 0.5, 0.5)로 비교해 봅니다.

정식화(0.5, 0.5, 0.5)을 넣으면판정
풀어 쓴 식: x1 ≤ y, x2 ≤ y, x1 + x2 ≤ 10.5 ≤ 0.5, 0.5 ≤ 0.5, 1 ≤ 1모두 통과 (소수 점이 남는다)
모은 식: x1 + x2 ≤ y0.5 + 0.5 = 1 ≤ 0.5위반! (소수 점을 잘라 낸다)

둘 다 정수해는 똑같이 (0, 0, 0), (0, 0, 1), (1, 0, 1), (0, 1, 1) 넷뿐이지만, 모은 식 쪽이 훨씬 강합니다.

같은 원리가 그래프의 삼각형과 5칸 고리에도 나타납니다.

  • 삼각형(클릭 부등식): 세 일 x1, x2, x3 중 어느 둘도 동시에 할 수 없다고 합시다. 쌍마다 x1 + x2 ≤ 1, x2 + x3 ≤ 1, x1 + x3 ≤ 1 세 줄을 적으면 (0.5, 0.5, 0.5)가 통과해 합이 1.5가 됩니다. 반면 셋을 한꺼번에 모은 클릭 부등식(clique inequality) x1 + x2 + x3 ≤ 1을 적으면 1.5 ≤ 1이 거짓이라 소수 점을 바로 막습니다.
  • 5칸 고리(0-1-2-3-4-0): 다섯 칸 중 이웃한 두 칸은 동시에 고를 수 없다고 합시다. 이웃한 쌍마다 x0 + x1 ≤ 1, …, x4 + x0 ≤ 1을 적으면 다섯 칸 모두 0.5를 넣는 답(합 2.5)이 통과합니다. 하지만 정수로 고르면 고리를 따라 많아야 2칸밖에 고르지 못하므로 x0 + x1 + x2 + x3 + x4 ≤ 2가 모든 정수해에 성립하고 (0.5, 0.5, 0.5, 0.5, 0.5)를 막아 줍니다.
2부 · LP만 풀어도 정수가 나오는 경우와 tryAgain

완전 단모듈: LP만 풀어도 정수가 나오는 조건

3장에서 계수와 오른쪽 수가 모두 정수인 연립방정식은 (정수) ÷ (계수 행렬의 행렬식) 꼴로 풀리므로, 행렬식이 +1이나 −1이면 해가 반드시 정수라고 배웠습니다. 또 5장에서 홀수 순환이 없는 그래프가 이분 그래프라고 배웠습니다.

12장의 배정 문제나 흐름 보존 문제(공급량과 용량이 정수일 때)는 이상하게도 정수 조건을 빼고 LP만 풀어도 답이 정수로 나옵니다. 6·7장에서 보았듯이 LP의 최적해는 가능 영역의 꼭짓점에 있고, 꼭짓점은 제약식 몇 줄을 등식으로 놓은 연립방정식의 해입니다. 그러니 어떤 행렬식을 계산해도 0, +1, −1만 나오는 행렬이라면 LP 꼭짓점이 언제나 정수일 것입니다.

정의 행렬 A에서 행 몇 개와 열 같은 개수만큼을 골라 만든 모든 정사각 부분행렬의 행렬식이 0, +1, −1 중 하나뿐이면, 그 행렬 A를 완전 단모듈(totally unimodular, TU)이라고 합니다. (이름은 알아 두기만 하면 됩니다. 중요한 것은 아래의 결과입니다.)
핵심 사실 제약 행렬 A가 완전 단모듈이고 오른쪽 수 b가 정수이면, LP 완화의 꼭짓점은 모두 정수입니다. 따라서 LP만 풀어도 정수 최적해가 나옵니다.

언제 완전 단모듈이 될까요? 고등학교 수준에서 꼭 기억할 만한 두 가지 경우가 있습니다.

  • 이분 그래프(5장)와 흐름 보존(12장): 5장에서 배운 대로 홀수 순환이 없는 이분 그래프에서는 노드를 두 편으로 갈라, 두 편을 잇는 간선마다 +1, −1처럼 부호를 맞출 수 있어 행렬식이 0, ±1만 나옵니다. 그래서 일대일 배정 문제나 최소비용 흐름 문제는 LP로 곧바로 정수가 나옵니다. 반면 3장에서 본 삼각형(홀수 순환) 연립방정식은 행렬식이 2가 되어 답이 (1/2, 1/2, 1/2)로 깨졌습니다. 5칸 고리(홀수 순환)도 행렬식이 ±2라서 LP만 풀면 0.5가 나옵니다.
  • 연속된 1 (연속 1 성질): 표의 세로줄(열)마다 1이 끊기지 않고 위아래로 연속된 행에만 모여 있으면 완전 단모듈입니다. 12장의 tryAgain 제약 ②(머무는 차)만 떼어 놓고 보면, 구간 (p, r)에 서 있는 차는 항구 p+1, p+2, …, r−1에 연속으로 1이 나타납니다. 그래서 한 칸에 머무는 차 조건만 놓고 보면 소수가 나오지 않습니다.

5장에서 "배 그래프가 이분 그래프이면 모형의 거리 비용이 실제 비용과 같다"고 했습니다. 그것과 "제약 행렬이 완전 단모듈이라 LP가 정수해를 낸다"는 것은 서로 다른 이야기입니다. tryAgain 모형은 제약 ①(수요와 z)과 제약 ⑤(여러 칸의 y 연결)가 블록들을 얽어 놓기 때문에 모형 전체는 완전 단모듈이 아닙니다.

공식 예시에서 왜 LP 완화 값이 145까지 내려가는지 들여다봅니다. 이 문제에서는 항구 0에서 실어 항구 2에서 내릴 차가 2대 있습니다(d02 = 2). 정수해에서는 어떻게 실어도 항구 1에서 칸 두 개가 완전히 막히므로, 안쪽 칸의 차를 위해 어쩔 수 없이 재배치(z012 = 2)를 해야 하고 비용이 190이 됩니다.

그런데 LP 완화에서는 솔버가 이 두 대를 칸 1, 2, 3, 4에 0.5대씩 나누어 싣습니다(x02,1 = x02,2 = x02,3 = x02,4 = 0.5). 그리고 항구 1, 2의 모든 칸에서 접근 가능 변수 y를 0.5로 둡니다. 항구 1, 칸 1의 제약 ②를 보세요.

머무는 차 0.5 ≤ 1 − y1,1 = 0.5   (성립!)

칸마다 "반쯤 차 있고, 반쯤 접근 가능"한 상태가 됩니다. 그러면 그 "반쯤 접근 가능한 몫 0.5"를 이용해 다른 차들을 칸마다 0.5대씩 싣고 내릴 수 있습니다(제약 ③④의 0.5 ≤ 0.5). 결국 재배치(z)가 하나도 없는 채로 145라는 낮은 하한이 나옵니다. 미니 문제 B에서 46이 나오는 이유도 똑같이 차를 0.5대씩 쪼개기 때문입니다.

3 × 3 격자 배에서 제약 ⑤(y4 ≤ y1 + y2)를 보면, 칸 1과 2에 각각 0.5대씩 머물러 y1 = y2 = 0.5일 때 y4 ≤ 0.5 + 0.5 = 1이 되어 칸 4가 완전히 접근 가능하다고 칩니다. 다만 이 점 하나는 "칸 1만 막힌 해"와 "칸 2만 막힌 해"의 평균이기도 합니다. 진짜 약점은 제약 ①과 ⑤가 여러 칸의 "반반" 상태를 한꺼번에 엮을 때 드러납니다. 그래서 솔버는 이 초기 LP 위에 아래의 절단평면을 덧붙여 하한을 끌어올립니다.

3부 · 풀면서 깎아 들어가기: 절단평면

유효 부등식과 절단평면

조각가가 큰 돌덩이에서 조각상을 만드는 일을 떠올려 보세요. 조각상(정수해들)은 절대 건드리지 않으면서, 겉에 붙은 불필요한 돌(소수 답)만 정으로 조금씩 깎아 나갑니다. 최적화에서 이 정 역할을 하는 식이 절단평면입니다.

정의 모든 정수 가능해가 지키는 부등식을 유효 부등식(valid inequality)이라고 합니다. 현재 LP 완화의 최적해가 정수가 아닐 때, 정수해는 하나도 자르지 않으면서 지금의 소수 최적해만 잘라 내는 유효 부등식을 절단평면(cutting plane, 줄여서 cut)이라고 합니다.

13장의 분지한계법이 영역을 둘로 "나누는" 방법이라면, 절단평면은 소수 모퉁이만 "깎아 내는" 방법입니다. 트럭 예에서 볼록 껍질의 한 변이었던 x + y ≥ 4가 바로 절단평면입니다. 9x + 5y ≥ 30을 지키는 모든 정수해(큰 트럭 x대, 작은 트럭 y대로 30톤을 실으려면 최소 4대는 필요함)가 이 식을 지키지만, 원래 LP 최적해 (10/3, 0)은 10/3 + 0 < 4라서 잘려 나갑니다.

올림으로 만드는 절단: Chvátal–Gomory 절단

그렇다면 x + y ≥ 4 같은 절단평면은 어떻게 찾을까요? 13장에서 배운 「정수이고 L 이상이면 ⌈L⌉ 이상」과 9장의 "제약에 양수를 곱해 더하기"를 합치면 어떤 문제에서든 절단평면을 만들 수 있습니다. 이것을 Chvátal–Gomory(흐바탈–고모리) 반올림 절단이라고 합니다.

방법은 세 걸음입니다.

  1. 원래 제약들(≥ 꼴)에 0 이상의 수를 곱해 더합니다.
  2. 변수가 0 이상(x ≥ 0)이므로, 왼쪽 계수를 모두 올림(천장 ⌈ ⌉)해도 식은 여전히 성립합니다(더 큰 수를 더했으니까요).
  3. 이제 왼쪽은 정수 계수 × 정수 변수의 합이라서 반드시 정수입니다. 정수가 오른쪽 수 이상이면 오른쪽 수도 올림할 수 있습니다!

트럭 예 9x + 5y ≥ 30에 1/9을 곱해서 세 걸음을 밟아 봅니다.

① 1/9 곱하기:  x + (5/9)y ≥ 30/9 = 10/3약 3.33
② 왼쪽 계수 올림:  ⌈1⌉x + ⌈5/9⌉y = x + y ≥ 10/3x, y ≥ 0이라 왼쪽이 커짐
③ 오른쪽 올림:  x + y ≥ ⌈10/3⌉ = 4x, y가 정수라 왼쪽이 정수

단 세 줄 만에 그림의 절단평면 x + y ≥ 4가 나왔습니다! 말로 읽으면 "큰 트럭도 9톤밖에 못 실으니, 30톤을 실으려면 트럭이 적어도 4대는 필요하다"는 당연한 사실입니다. 방금 만든 부등식이 정말 모든 정수해를 통과시키고 (10/3, 0)만 자르는지 Python으로 확인해 봅니다.

def ceil_div(a, b):
    return (a + b - 1) // b

u_num, u_den = 1, 9
c1 = ceil_div(9 * u_num, u_den)
c2 = ceil_div(5 * u_num, u_den)
rhs = ceil_div(30 * u_num, u_den)
print("새 부등식:", c1, "* x +", c2, "* y >=", rhs)

ok = True
for x in range(0, 7):
    for y in range(0, 7):
        if 9 * x + 5 * y >= 30 and c1 * x + c2 * y < rhs:
            ok = False
print("정수해 모두 통과:", ok)
print("LP 해 (10/3, 0) 통과:", c1 * 10 / 3 + c2 * 0 >= rhs)

새 부등식: 1 * x + 1 * y >= 4
정수해 모두 통과: True
LP 해 (10/3, 0) 통과: False
  • 1~2행 양의 정수 a, b에 대해 ⌈a ÷ b⌉를 계산하는 함수입니다. 예: (30 + 8) // 9 = 4.
  • 4~7행 u = 1/9을 곱한 뒤 계수와 오른쪽을 모두 올림해 새 부등식을 만듭니다.
  • 9~13행 모든 정수 가능해가 새 부등식을 지키는지(유효 부등식인지) 검사합니다.
  • 14~15행 정수해는 모두 통과(True)하고, 원래 LP 해 (10/3, 0)은 잘립니다(False).

이미 만든 절단평면을 재료로 삼아 이 반올림을 몇 번 더 반복할 수도 있습니다. 예컨대 (1/4)(9x + 5y ≥ 30) + (3/4)(x + y ≥ 4)를 더하면 3x + 2y ≥ 10.5에서 3x + 2y ≥ 11이 나오고, 다시 (1/3)(9x + 5y ≥ 30) + (2/3)(3x + 2y ≥ 11)을 더하면 5x + 3y ≥ 52/3에서 볼록 껍질의 나머지 변 5x + 3y ≥ 18까지 나옵니다! 그러면 LP 하한이 37이 되어 분지 없이 답이 나옵니다.

Gomory 분수 절단 심화

앞 절에서는 곱할 수 1/9을 사람이 골랐습니다. 고르지 않아도, 8장의 심플렉스법이 LP를 다 푼 뒤 남긴 마지막 사전(표)에서 곧바로 절단평면을 뽑아내는 방법이 Gomory 분수 절단입니다. 단, 여유·잉여 변수까지 모두 정수인 순수 정수 문제에 씁니다.

트럭 예에서 s = 9x + 5y − 30을 잉여 변수로 두면(9, 5, 30이 모두 정수이므로 x, y가 정수면 s도 정수입니다), 8장의 마지막 사전은 x = 10/3 − (5/9)y + (1/9)s였습니다. 비기저 변수를 왼쪽으로 모아 적습니다.

x + (5/9)y − (1/9)s = 10/3

이제 각 수를 바닥(⌊a⌋)과 분수 부분(frac(a) = a − ⌊a⌋)으로 나눕니다. 주의할 점은 음수의 바닥입니다. −1/9 이하의 가장 큰 정수는 0이 아니라 −1이므로, frac(−1/9) = −1/9 − (−1) = 8/9입니다.

오른쪽10/331/3

바닥 부분끼리 왼쪽으로 모으면 x + 0·y − 1·s − 3 = 1/3 − (5/9)y − (8/9)s입니다. x와 s가 정수이면 왼쪽은 정수이고, 오른쪽은 1/3에서 0 이상의 수를 뺀 것이라 1보다 작습니다. 1보다 작은 정수는 0 이하이므로 오른쪽 ≤ 0, 곧 다음 부등식이 반드시 성립합니다.

(5/9)y + (8/9)s ≥ 1/3  →  5y + 8s ≥ 3

여기에 s = 9x + 5y − 30을 도로 넣으면 72x + 45y ≥ 243, 양변을 9로 나누어 8x + 5y ≥ 27이 나옵니다! 현재 LP 해 (10/3, 0)에서는 8(10/3) = 26.67 < 27이라 잘립니다. 다만 이 식을 더한 LP 해는 (27/8, 0), 값 33.75로, 앞의 CG 절단(35.5)보다는 덜 깎습니다. 기계적으로 뽑아내는 대신 한 번에 깎는 양이 작을 수 있기 때문입니다.

구조를 이용한 절단: 덮개 부등식

문제의 모양을 알면 더 날카로운 절단평면을 만들 수 있습니다. 대표적인 것이 배낭 제약 Σ wjxj ≤ W(xj ∈ {0, 1})에서 만드는 덮개 부등식(cover inequality)입니다.

무게 제한이 7 kg인 배낭에 물건 세 개(3 kg, 3 kg, 2 kg)를 넣는다고 합시다.

3x1 + 3x2 + 2x3 ≤ 7   (x1, x2, x3 ∈ {0, 1})

세 물건을 다 넣으면 무게 합이 3 + 3 + 2 = 8 > 7로 넘칩니다. 따라서 세 물건 중 많아야 두 개까지만 넣을 수 있습니다.

x1 + x2 + x3 ≤ 2

이 식이 덮개 부등식입니다. LP 해 (1, 1, 0.5)는 원래 식(3 + 3 + 1 = 7)은 통과하지만 덮개 부등식(1 + 1 + 0.5 = 2.5 ≤ 2)에서 바로 잘립니다.

정의 배낭 제약 Σ wjxj ≤ W(xj ∈ {0, 1}, wj ≥ 0)에서, 무게 합이 용량 W를 넘는 물건 묶음 C를 덮개(cover)라고 합니다. 덮개 C의 물건을 전부 넣을 수는 없으므로 부등식 Σj∈C xj ≤ |C| − 1이 항상 성립하며, 이것을 덮개 부등식이라고 합니다.

덮개 C는 작을수록 더 강한 식을 만듭니다. 예를 들어 5x1 + 4x2 + 3x3 ≤ 8에서는 {1, 2}만 묶어도 5 + 4 = 9 > 8이므로 x1 + x2 ≤ 1이 나옵니다. 이 식은 LP 점 (1, 0.75, 0)을 잘라 내지만, 셋을 다 묶은 x1 + x2 + x3 ≤ 2는 1 + 0.75 + 0 = 1.75 ≤ 2라서 자르지 못합니다. 그래서 솔버는 원소를 하나라도 빼면 덮개가 안 되는 가장 작은 덮개를 찾아 넣습니다.

분지절단법

절단평면만으로 끝까지 깎아 들어가는 것은 너무 많은 식이 필요해서 느리고, 13장의 분지한계법만으로 끝까지 나누는 것은 하한이 낮아 가지가 너무 많이 자랍니다. 그래서 현대 MIP 솔버는 두 방법을 합친 분지절단법(branch-and-cut)을 씁니다.

  • 먼저 뿌리(맨 처음 문제)에서 LP 완화를 풀고, 소수 답을 자르는 절단평면(클릭 부등식, 덮개 부등식, Gomory 절단 등)을 몇 차례 덧붙여 하한을 바짝 끌어올립니다.
  • 하한이 더 이상 크게 오르지 않으면 그때 분지를 시작합니다.
  • 가지로 내려간 뒤에도 필요하면 절단평면을 조금 더 붙여 하한을 높이고, 가지치기 (다)로 빨리 버립니다.

다만 절단평면을 너무 많이 넣으면 제약 수가 늘어나 LP 한 번 푸는 시간이 길어집니다. 그래서 솔버는 효과가 큰 절단평면만 남기고 약한 것은 버리는 규칙을 둡니다. 처음부터 정식화를 강하게 적어 두면 솔버가 깎아야 할 모퉁이가 줄어들고, 약하게 적으면 솔버가 절단평면으로 메워야 합니다.

가이드와 연결

가이드의 「강한 정식화와 약한 정식화」에서 창고 예의 10줄과 1줄을 비교한 표(하한 100 대 10), 그리고 그림의 "색칠한 영역을 정수점들 쪽으로 깎아 들어가는 것"이 이 장 1부의 포함 관계(P1 ⊂ P2)와 볼록 껍질입니다.

가이드는 tryAgain 모형의 장점으로 "제약 ②③④가 여러 x를 계수 1로 모은 꼴이라 오히려 강하다"고 설명합니다. 1부의 「모은 식은 약한가, 강한가」가 창고 예와의 차이(동시에 1이 될 수 없는가)를 정확히 짚어 주었습니다.

가이드가 공식 예시와 미니 문제 B에서 확인한 LP 완화 값(145 대 190, 46 대 68)과 "제약 ⑤가 약한 고리일 수 있다"는 평가의 배경이 2부입니다. 그리고 솔버 로그에서 절단평면이 하한을 올리는 장치로 소개된 것이 3부의 분지절단법입니다.

  • 정수해는 같아도 LP 영역이 좁을수록 강한 정식화이고 LP 하한이 높습니다.
  • 정수해에 고무줄을 감싼 모양이 볼록 껍질이고, 이것이 LP 영역과 같으면 이상적 정식화입니다.
  • 서로 동시에 1이 될 수 없는 변수들을 한 줄에 모은 식(클릭 부등식, tryAgain의 ②③④)은 풀어 쓴 식보다 강합니다.
  • 제약 행렬이 완전 단모듈(이분 그래프의 배정, 흐름 보존, 연속된 1)이면 LP만 풀어도 정수해가 나옵니다.
  • tryAgain 모형의 초기 LP는 0.5씩 쪼개기 때문에 공식 예시 145(최적 190), 미니 문제 B 46(최적 68)의 틈이 있습니다.
  • 절단평면은 정수해를 하나도 자르지 않으면서 소수 해만 잘라 냅니다. 현대 솔버는 이것을 분지한계법과 합친 분지절단법을 씁니다.

연습문제

정수해 집합 X = {(0, 0), (1, 0), (0, 1)}에 대해 두 정식화 P1: x + y ≤ 1 (0 ≤ x, y ≤ 1)과 P2: 2x + 2y ≤ 3 (0 ≤ x, y ≤ 1)이 있습니다. 둘 다 X의 정식화인지 확인하고, 어느 쪽이 더 강한지 답하세요.

네 꼭짓점 중 (1, 1)은 P1에서 2 ≤ 1 거짓, P2에서 4 ≤ 3 거짓이므로 둘 다 정수점이 {(0, 0), (1, 0), (0, 1)}뿐입니다. x + y ≤ 1이면 2x + 2y ≤ 2 ≤ 3이므로 P1 ⊂ P2, 곧 P1이 더 강합니다. (사실 P1은 세 점을 감싸는 직각삼각형으로 볼록 껍질 그 자체입니다.)

이진변수 x1, x2, x3와 y에 대해 "x1, x2, x3 ≤ y(세 줄)"와 "x1 + x2 + x3 ≤ 3y(한 줄)" 중 어느 쪽이 강한가요? 만약 x1, x2, x3가 서로 동시에 1이 될 수 없다면 가장 강한 한 줄은 무엇인가요?

세 줄을 더하면 한 줄짜리가 나오므로 세 줄 쪽이 강합니다. (예: (1, 0, 0, 1/3)은 한 줄짜리만 통과합니다.) 서로 동시에 1이 될 수 없다면 x1 + x2 + x3 ≤ y가 가장 강합니다. 이 한 줄은 "각각 ≤ y"와 클릭 부등식 "합 ≤ 1"을 모두 품습니다.

5칸 고리(0-1-2-3-4-0)에서 이웃한 두 칸은 동시에 고를 수 없습니다. xi ∈ {0, 1}일 때 왜 x0 + x1 + x2 + x3 + x4 ≤ 2가 유효 부등식인지 확인하고, LP 점 (0.5, 0.5, 0.5, 0.5, 0.5)가 잘리는지 보세요.

다섯 칸이 고리 모양으로 이어져 있으므로 3칸 이상을 고르면 반드시 어느 두 칸은 이웃하게 됩니다. 따라서 정수로 고르면 많아야 2칸이므로 합 ≤ 2가 모든 정수해에서 성립합니다. 점 (0.5, 0.5, 0.5, 0.5, 0.5)는 이웃 부등식(0.5 + 0.5 ≤ 1)을 모두 지키지만 합이 2.5 > 2라서 잘립니다.

표에서 열마다 1이 연속된 행에 모여 있는 3 × 3 행렬 [[1, 0, 1], [1, 1, 0], [0, 1, 1]]은 연속된 1 성질을 가지나요? 행렬식은 얼마인가요?

3열이 1행과 3행에 1이 있고 2행은 0이라서 1이 끊어져 있습니다. 연속된 1 성질이 깨졌습니다. 행렬식을 계산하면 1·(1·1 − 0·1) − 0 + 1·(1·1 − 1·0) = 2입니다. 3장의 삼각형 연립방정식과 같은 행렬이라 완전 단모듈이 아닙니다.

공식 예시의 tryAgain LP 해에서 항구 1, 칸 1의 제약 ②, ③, ④에 x02,1 = 0.5, x13,1 = 0.5, 칸 1의 나머지 x = 0, y1,1 = 0.5를 넣어 모두 성립하는지 확인하세요.

② 머무는 차는 0 < 1 < r인 구간이므로 x02,1 = 0.5 ≤ 1 − 0.5 = 0.5(성립). ③ 내리는 차는 p < 1인 구간 x01,1 = 0 ≤ 0.5(성립). ④ 싣는 차는 r > 1인 구간 x12,1 + x13,1 + x14,1 = 0.5 ≤ 0.5(성립). 반 대가 머무는 칸에 반 대를 싣는 소수 해가 통과합니다.

정수 x, y ≥ 0와 제약 2x + 3y ≥ 5에 u = 1/2을 곱해 Chvátal–Gomory 절단을 만들고, 원래 LP 점 (5/2, 0)이 잘리는지 확인하세요.

① 1/2 곱하기: x + (3/2)y ≥ 5/2. ② 계수 올림: x + 2y ≥ 5/2. ③ 오른쪽 올림: x + 2y ≥ 3. 정수 가능해 중 x + 2y의 최솟값은 3((1, 1)과 (3, 0))이므로 유효합니다. 원래 LP 점 (5/2, 0)을 넣으면 2.5 < 3이라 잘립니다.

[심화] 어떤 순수 정수 문제의 마지막 사전에 행 x1 + (1/4)x3 − (3/4)x4 = 7/4가 있습니다(x3, x4는 비기저). Gomory 분수 절단을 적으세요.

frac(1/4) = 1/4, frac(−3/4) = −3/4 − (−1) = 1/4, frac(7/4) = 3/4입니다. 따라서 절단평면은 (1/4)x3 + (1/4)x4 ≥ 3/4, 곧 x3 + x4 ≥ 3입니다. 현재 LP 해에서는 비기저 변수 x3 = x4 = 0이라서 0 ≥ 3 위반으로 잘립니다.

배낭 제약 5x1 + 4x2 + 3x3 ≤ 8(xj ∈ {0, 1})에서 덮개 {1, 2}로 만든 덮개 부등식 x1 + x2 ≤ 1이 본문의 코드처럼 모든 0/1 가능해를 통과시키는지 8가지 조합을 손으로 확인하세요.

x1 = x2 = 1이면 무게가 5 + 4 = 9 > 8이라서 x3이 0이든 1이든 원래 제약을 어깁니다. 나머지 6가지 조합은 모두 x1 + x2 ≤ 1을 지킵니다. 따라서 원래 제약을 지키는 0/1 해는 하나도 빠짐없이 x1 + x2 ≤ 1을 지킵니다.
