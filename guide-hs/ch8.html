이 장은 tryAgain의 모형 전체를 읽습니다. 새로운 생각은 없습니다. 7장의 「구간」, 「머무는 차」, 「접근 가능」을 4장에서 배운 식 쓰는 법으로 옮겨 적은 것이 전부입니다.

차례는 이렇습니다. 먼저 미니 문제 B의 모형을 한 줄도 빼지 않고 전부 적어 봅니다. 변수 22개, 식 24줄이라 한눈에 들어옵니다. 그다음 같은 식을 아무 크기의 문제에나 쓸 수 있는 일반식으로 적고, 팀의 코드와 나란히 봅니다. 마지막으로 공식 예시에 대 보고 모형의 장단점을 따집니다.

식은 발표자료 부록(13~15쪽)에, 코드는 function.cpp의 formulate(43~177줄)에 있습니다. 둘을 대조한 결과 식 자체는 일치했습니다. 설명이 다른 부분은 장 끝의 표에 모았습니다.

미니 문제 B를 다시 적습니다. 일렬 배(출입구 0, 칸 1, 칸 2), 항구 0·1·2·3, 고정비 F = 10. 차 A는 항구 0에서 2까지, 차 B는 항구 1에서 3까지 갑니다. 6장과 7장에서 구한 것도 함께 적습니다.

변수 x: 구간이 있는가

7장에서 차 한 대가 "한 번 실려서 한 번 내려질 때까지"를 구간이라고 불렀습니다. 구간은 (실은 항구, 내린 항구, 머문 칸) 세 가지로 적힙니다. 가능한 구간 하나마다 0 또는 1이 되는 변수를 하나씩 둡니다.

변수 x

xpq,i = 1이면 "항구 p에서 칸 i에 실려 항구 q에서 내려지는 구간이 있다", 0이면 없다. 숫자를 넣어 쓸 때는 항구 둘과 칸 사이에 쉼표를 찍겠습니다. x02,1은 항구 0 → 2, 칸 1입니다.

항구 쌍은 (0,1), (0,2), (0,3), (1,2), (1,3), (2,3)의 여섯 가지(네 항구에서 둘을 고르는 4C2)이고 칸이 둘이니 x는 12개입니다.

항구 쌍(0,1)(0,2)(0,3)(1,2)(1,3)(2,3)
칸 1x01,1x02,1x03,1x12,1x13,1x23,1
칸 2x01,2x02,2x03,2x12,2x13,2x23,2

수요에 없는 쌍 (0,1)이나 (1,2)에도 변수가 있습니다. 잠깐 내렸다 다시 실으면 "항구 0에서 1까지"처럼 원래 주문에 없던 짧은 구간이 생기기 때문입니다. 1장의 해 (가)와 (나)를 x로 적으면 이렇습니다.

x에 대해 세 가지를 짚어 둡니다.

  • x는 차가 아니라 구간을 가리킵니다. (가)에서 차 A는 구간 둘이 되어 x 두 개(x01,1, x12,1)가 1입니다.
  • x에는 "어느 차인지"가 없습니다. x12,1 = 1은 (가)에서는 A의 뒤 토막이고 (나)에서는 B의 앞 토막입니다. 모형은 둘을 구별하지 않습니다. 같은 항구에서 타서 같은 항구에서 내리는 차끼리는 누가 누구든 비용이 같기 때문입니다. 차에 이름을 다시 붙이는 일은 9장에서 합니다.
  • x가 배치의 전부입니다. xpq,i = 1이면 "항구 p를 떠날 때부터 항구 q에 닿을 때까지 칸 i에 차가 있다"가 정해집니다. 모든 항구에서의 배 안 모습이 x만으로 정해집니다.

변수 z와 y

변수 z

zpqr는 0 이상의 정수입니다. "항구 p에서 r까지 가는 구간 가운데, 중간 항구 q에서 잠깐 내렸다 다시 실어 둘로 쪼갠 것이 몇 대인가"를 뜻합니다. 첨자는 왼쪽부터 (실은 항구, 쪼갠 항구, 내릴 항구)이고 p < q < r입니다.

항구 넷에서 셋을 고르는 방법은 4C3 = 4가지이므로 z는 z012, z013, z023, z123 네 개입니다. (가)는 z012 = 1(0 → 2 구간을 항구 1에서 쪼갬), (나)는 z123 = 1이고 나머지는 0입니다. z는 "누구를"이 아니라 "몇 대를"입니다.

변수 y

yp,i = 1이면 "항구 p에서 노드 i가 접근 가능하다". 7장에서 칸에 붙이던 「접근 가능」 딱지가 이 변수입니다. 딱지가 붙으면 1, 안 붙으면 0입니다.

y는 중간 항구에만 둡니다. 첫 항구(0)에서는 배가 비어 있고 마지막 항구(3)에서는 전부 내리므로 머무는 차가 없습니다. 모든 칸이 접근 가능하니 따질 것이 없습니다. 중간 항구는 1과 2, 노드는 0·1·2이므로 y는 y1,0, y1,1, y1,2, y2,0, y2,1, y2,2 여섯 개입니다.

합치면 변수는 12 + 4 + 6 = 22개입니다.

목적함수: 구간 하나에 경로 둘

구간 하나는 선적 경로 하나와 하역 경로 하나를 만듭니다. 칸 i를 쓰는 구간이면 두 경로 모두 길이가 dist(i)이고, 비용은 각각 F + dist(i)입니다. 그러니 구간 하나의 비용은 2 × (F + dist(i))입니다. 칸 1을 쓰면 2 × (10 + 1) = 22, 칸 2를 쓰면 2 × (10 + 2) = 24입니다.

최소화  22 × (x01,1 + x02,1 + x03,1 + x12,1 + x13,1 + x23,1)칸 1을 쓰는 구간
       + 24 × (x01,2 + x02,2 + x03,2 + x12,2 + x13,2 + x23,2)칸 2를 쓰는 구간

4장에서 본 "0과 1에 수를 곱해 더하면 고른 것들의 합이 된다"는 꼴입니다. (가)는 칸 1의 구간 둘과 칸 2의 구간 하나라서 22 + 22 + 24 = 68입니다. 1장에서 경로를 하나씩 더해 얻은 값과 같습니다. 구간을 쪼개면 x가 하나 더 켜지고 그만큼 비용이 붙으므로, 재배치 비용은 따로 적지 않아도 들어갑니다. z와 y에는 비용이 없습니다.

제약 ① 수요: 구간의 개수 맞추기

항구 쌍마다 "그 쌍의 구간이 몇 개 있어야 하는가"를 정하는 식입니다. 쪼개는 일이 없다면 간단합니다. (0,2)의 구간은 수요대로 1개, (0,1)의 구간은 0개여야 합니다. 쪼개면 개수가 바뀝니다. 긴 구간 하나가 사라지고 짧은 구간 둘이 생깁니다.

x01,1 + x01,2 = 0 + z012 + z013(0,1): 0→2나 0→3이 항구 1에서 쪼개지면 앞 토막이 생긴다
x02,1 + x02,2 = 1 − z012 + z023(0,2): 수요 1대. 항구 1에서 쪼개면 사라진다
x03,1 + x03,2 = 0 − z013 − z023(0,3): 수요가 없다
x12,1 + x12,2 = 0 + z123 + z012(1,2): 1→3의 앞 토막이거나 0→2의 뒤 토막
x13,1 + x13,2 = 1 − z123 + z013(1,3): 수요 1대. 항구 2에서 쪼개면 사라진다
x23,1 + x23,2 = 0 + z023 + z123(2,3): 0→3이나 1→3이 항구 2에서 쪼개지면 뒤 토막이 생긴다

읽는 법은 모두 같습니다. 왼쪽은 그 항구 쌍의 구간 개수(칸마다 있으면 1이니 더하면 개수)이고, 오른쪽은 원래 수요에서, 쪼개져 사라진 만큼 빼고, 다른 구간이 쪼개지면서 생긴 토막만큼 더한 것입니다. 4장에서 본 "들어온 만큼 나간다"는 수량 보존의 꼴입니다.

셋째 줄을 보세요. 왼쪽은 0 이상이고 오른쪽은 0 이하이므로 양쪽 다 0이어야 합니다. z013 = z023 = 0, x03,1 = x03,2 = 0이 저절로 정해집니다. 없는 주문을 쪼갤 수는 없다는 당연한 말을 식이 해 줍니다.

해 (가)의 값(x01,1 = x12,1 = x13,2 = 1, z012 = 1, 나머지 x와 z는 0)을 여섯 줄에 넣어 양쪽이 같은지 확인해 보세요. 첫 줄은 1 + 0 = 0 + 1 + 0입니다. 둘째 줄은 0 + 0 = 1 − 1 + 0입니다. 수요 한 대가 항구 1에서 쪼개져 사라졌고, 그 대신 (0,1)과 (1,2)에 한 대씩 생겼습니다.

제약 ②③④: 칸을 쓰려면 접근 가능해야

7장의 규칙을 중간 항구(1과 2)마다, 칸(1과 2)마다 한 줄씩 적습니다. 세 종류의 차를 x로 적는 것이 요령입니다. 항구 q에서 칸 i를 볼 때,

  • 머무는 차는 q보다 먼저 실려 q보다 나중에 내리는 구간입니다. 항구 1에서는 (0,2)와 (0,3), 항구 2에서는 (0,3)과 (1,3)입니다.
  • 내리는 차는 q에서 끝나는 구간입니다. 항구 1에서는 (0,1), 항구 2에서는 (0,2)와 (1,2)입니다.
  • 싣는 차는 q에서 시작하는 구간입니다. 항구 1에서는 (1,2)와 (1,3), 항구 2에서는 (2,3)입니다.
제약 ②x02,i + x03,i ≤ 1 − y1,i항구 1, 칸 i = 1, 2
x03,i + x13,i ≤ 1 − y2,i항구 2, 칸 i = 1, 2
제약 ③x01,i ≤ y1,i항구 1, 칸 i = 1, 2
x02,i + x12,i ≤ y2,i항구 2, 칸 i = 1, 2
제약 ④x12,i + x13,i ≤ y1,i항구 1, 칸 i = 1, 2
x23,i ≤ y2,i항구 2, 칸 i = 1, 2

줄마다 i에 1과 2를 넣으면 두 줄이 되므로 모두 12줄입니다. 4장에서 본 "모은 식"이고, 한 줄이 두 가지를 말합니다.

  • 제약 ② (머무는 차가 있는 칸은 접근 불가). 오른쪽은 많아야 1이니 머무는 차는 한 칸에 많아야 한 대입니다. 그리고 머무는 차가 있으면(왼쪽이 1) 1 ≤ 1 − y에서 y = 0, 곧 그 칸에는 딱지를 붙일 수 없습니다. 7장의 규칙 (나)입니다.
  • 제약 ③ (내리려면 접근 가능). 한 항구에서 한 칸으로부터 내리는 차는 많아야 한 대이고, 내리려면 y = 1이어야 합니다.
  • 제약 ④ (실으려면 접근 가능). 싣는 쪽도 같습니다.

제약 ③과 ④는 서로를 막지 않습니다. 같은 항구, 같은 칸에서 제약 ③의 x와 제약 ④의 x가 둘 다 1일 수 있습니다. 차를 내리고 그 자리에 다른 차를 싣는 것입니다. (가)의 항구 1, 칸 1이 그렇습니다(x01,1을 내리고 x12,1을 싣습니다). "내린 다음 싣는다"는 순서 덕분에 문제가 없습니다.

제약 ⑤⑥: 접근 가능은 출입구에서 이어져야

제약 ⑤yp,1 ≤ yp,0항구 p = 1, 2. 칸 1의 아래 이웃은 출입구
yp,2 ≤ yp,1항구 p = 1, 2. 칸 2의 아래 이웃은 칸 1
제약 ⑥yp,0 = 1항구 p = 1, 2. 출입구는 언제나 접근 가능

제약 ⑤는 4장의 "y이면 x" 꼴입니다. 칸 2에 딱지를 붙이려면(yp,2 = 1) 칸 1에도 딱지가 있어야 합니다(yp,1 = 1). 7장의 규칙 (다), 곧 "아래 이웃 가운데 접근 가능한 칸이 있어야 접근 가능할 수 있다"입니다. 일렬 배에서는 아래 이웃이 하나뿐이라 식이 단순합니다. 아래 이웃이 여럿인 배에서는 오른쪽이 그 이웃들의 y를 더한 것이 됩니다(2부). 제약 ⑤가 4줄, 제약 ⑥이 2줄입니다.

이것으로 끝입니다. 제약 ① 6줄, 제약 ②③④⑤ 각 4줄, 제약 ⑥ 2줄, 모두 24줄입니다. 경로도 순서도 나오지 않습니다.

식이 정말 막아 주는가

1장에서 우리는 "재배치 없이는 안 된다"는 것을 머리로 따졌습니다. 식도 같은 결론을 내는지 봅니다. 재배치 없이(z가 모두 0) 차를 세우는 방법은 두 가지뿐입니다.

A를 칸 2, B를 칸 1 (x02,2 = x13,1 = 1)

항구 2에서 A를 내려야 합니다. 제약 ③에서 x02,2 = 1 ≤ y2,2이므로 y2,2 = 1. 제약 ⑤에서 y2,2 ≤ y2,1이므로 y2,1 = 1. 그런데 칸 1에는 B가 머뭅니다. 제약 ②에서 x13,1 = 1 ≤ 1 − y2,1이므로 y2,1 = 0. 1이면서 0일 수는 없습니다.

A를 칸 1, B를 칸 2 (x02,1 = x13,2 = 1)

항구 1에서 B를 실어야 합니다. 제약 ④에서 x13,2 = 1 ≤ y1,2이므로 y1,2 = 1. 제약 ⑤에서 y1,1 = 1. 그런데 칸 1에는 A가 머뭅니다. 제약 ②에서 x02,1 = 1 ≤ 1 − y1,1이므로 y1,1 = 0. 역시 모순입니다.

두 배치 모두 제약을 지키는 y를 찾을 수 없으므로 가능해가 아닙니다. "칸 2의 차를 움직이려면 칸 1에 머무는 차가 없어야 한다"가 식 세 줄(③ 또는 ④ → ⑤ → ②)의 사슬로 강제됩니다.

반대로 (가)는 모든 제약을 지킵니다. 항구 1에서는 머무는 차가 없으니 y1,1 = y1,2 = 1로 두면 되고, 항구 2에서는 칸 2에 B가 머무니 y2,2 = 0, 칸 1에서 A를 내리니 y2,1 = 1입니다. 제약 ⑤의 y2,2 ≤ y2,1은 0 ≤ 1로 성립합니다.

전부 넣어 보기

변수가 22개뿐이니 컴퓨터로는 값을 넣는 모든 경우를 다 해 볼 수 있습니다. x 12개에 0 또는 1, y 가운데 칸에 붙는 4개에 0 또는 1(출입구의 y는 1로 고정), z 4개에 0, 1, 2를 넣는 조합은 212 × 24 × 34 = 5,308,416가지입니다. 조합마다 24줄을 검사해서 다 지키는 것만 남기고, 그 가운데 목적함수가 가장 작은 것을 고릅니다. 프로그램 전체는 12장 부록의 mini_model_enumerate.py이고 뼈대는 다음과 같습니다.

for xv in product((0, 1), repeat=12):
    x = dict(zip(xkeys, xv))
    for zv in product((0, 1, 2), repeat=4):
        z = dict(zip(zkeys, zv))
        if not demand_ok(x, z):
            continue
        for yv in product((0, 1), repeat=4):
            y = dict(zip(ykeys, yv))
            if not access_ok(x, y):
                continue
            feasible += 1
            c = cost(x)
  • 1~2 product((0, 1), repeat=12)는 0과 1을 12자리에 늘어놓는 모든 경우(4,096가지)를 차례로 만들어 줍니다. 둘째 줄은 그것을 x01,1, x01,2, … 에 하나씩 짝지어 dict로 만듭니다.
  • 3~6 z도 같은 식으로 모든 경우를 만듭니다. demand_ok는 제약 ① 여섯 줄을 검사하는 함수입니다. 어기면 continue로 다음 조합으로 넘어갑니다.
  • 7~10 y의 모든 경우에 대해 access_ok가 제약 ②~⑥을 검사합니다.
  • 11~12 여기까지 온 조합은 가능해입니다. 개수를 세고 목적함수 값을 계산합니다.

아무 크기에나 쓰는 식

미니 문제 B의 24줄은 규칙을 따라 기계적으로 만든 것입니다. 그 규칙을 Σ로 적은 것이 일반식입니다. 노드가 N개(0이 출입구, 칸은 1부터 N−1), 항구가 P개(0부터 P−1)인 문제를 생각합니다. 첨자의 약속은 이렇습니다. p, q, r은 항구이고 i, j는 노드입니다. 변수의 첨자에 항구가 둘 이상 나오면 왼쪽 것이 항상 더 이른 항구입니다.

한 칸에 두 대가 겹치는 일은 왜 없는가

"한 칸에는 언제나 한 대 이하"를 직접 말하는 식은 없습니다. 제약 ②③④가 함께 그 일을 합니다.

칸 i에 구간 둘이 겹쳐 있다고 해 봅니다. 먼저 시작하는 쪽을 A(항구 a1에서 a2까지), 다른 쪽을 B(항구 b1에서 b2까지)라고 부릅니다. 동시에 시작하면 먼저 끝나는 쪽을 A라고 합니다. 겹치는 방식은 두 가지뿐입니다.

  • B가 A의 도중에 시작한다(a1 < b1 < a2). 항구 b1에서 A는 머무는 차입니다. 제약 ②에 의해 y = 0. 그런데 B를 그 항구에서 실어야 하니 제약 ④에 의해 y = 1. 모순입니다.
  • 같은 항구에서 시작하고 A가 먼저 끝난다(a1 = b1, a2 < b2). 항구 a2에서 A를 내려야 하니 제약 ③에 의해 y = 1. 그런데 B는 머무는 차이니 제약 ②에 의해 y = 0. 모순입니다.

두 경우 모두 모순이 생기는 항구는 첫 항구도 마지막 항구도 아닙니다. 그래서 y가 없는 항구 0과 P−1에 대해 따로 식을 두지 않아도 됩니다. 시작과 끝이 모두 같은 두 구간은 같은 변수 xpqi이므로 애초에 둘이 될 수 없습니다.

6장의 5칸 고리(노드 0-1-2-3-4-0, 출입구와 칸 넷)로 봅니다. 너비 우선 탐색은 1, 4, 2, 3 순으로 방문하고, 칸 3의 거리는 2(3 → 4 → 0), 아래 이웃은 pred(3) = {2, 4}입니다. 칸 4에 머무는 차가 있으면 칸 3은 칸 2를 근거로 접근 가능하고, 실제로 나가는 길은 3 → 2 → 1 → 0, 길이 3입니다. 모형은 이 경로를 길이 2로 계산합니다.

이런 일이 생기려면 거리가 같은 두 노드가 이웃이어야 하고, 그것은 배에 간선 수가 홀수인 고리가 있다는 뜻입니다. 거리가 둘 다 d인 이웃 i, j가 있으면 "출입구에서 i까지 d걸음, i에서 j로 1걸음, j에서 출입구까지 d걸음"으로 2d + 1걸음 만에 제자리로 돌아오기 때문입니다. 위 고리에서는 칸 2와 3이 그런 쌍이고 고리의 간선이 5개입니다. 고리가 없는 배(가지만 있는 배)나 고리의 간선 수가 모두 짝수인 배(대각선 통로가 없는 바둑판)에서는 이웃끼리 거리가 언제나 1 차이 나므로, 아래 이웃은 모두 거리가 1 작고, 모형의 비용과 실제 비용이 정확히 같습니다.

홀수 고리가 없는 그래프를 이분 그래프라고 부릅니다. 교재 5장에 세 길이의 부등식과 함께 설명되어 있습니다.

대회 사이트의 「문제 생성 방법」에는 바둑판에 삼각형 모양이나 대각선 통로를 넣는 선택 사항(tri, diag)이 있다고 적혀 있어서, 그런 문제에서는 차이가 날 수 있습니다. 다만 위에서 본 공개 연습 문제 20개는 직접 검사해 보니 모두 홀수 고리가 없었습니다. 이 20문제에서는 모형의 목적함수 값이 채점기가 계산할 총비용과 정확히 같습니다. 숨겨진 평가 문제도 그랬는지는 확인하지 못했습니다.

어느 경우든 제출된 해는 유효합니다. 차이는 "솔버가 가장 작게 만든 값"과 "채점기가 계산한 값"이 조금 다를 수 있다는 것뿐입니다.

x24,3 = 1을 한국어 문장으로 읽어 보세요. 항구 3에서 이 차는 어떤 종류의 차인가요?

"항구 2에서 칸 3에 실려 항구 4에서 내려지는 구간이 있다." 항구 2를 떠날 때부터 항구 4에 닿을 때까지 칸 3에 차가 있습니다. 항구 3에서는 싣지도 내리지도 않으니 머무는 차입니다.

미니 문제 B의 해 (나)(x02,2 = x12,1 = x23,1 = 1, z123 = 1)를 제약 ①의 여섯 줄에 넣어 확인하고, y 여섯 개의 값을 정해 보세요.

제약 ①: (0,1) 0 = 0 + 0 + 0, (0,2) 1 = 1 − 0 + 0, (0,3) 0 = 0, (1,2) 1 = 0 + 1 + 0, (1,3) 0 = 1 − 1 + 0, (2,3) 1 = 0 + 0 + 1. 모두 성립합니다. y: 출입구는 y1,0 = y2,0 = 1. 항구 1에서는 칸 2에 A가 머무니 y1,2 = 0(제약 ②), 칸 1에 B를 실으니 y1,1 = 1(제약 ④). 항구 2에서는 칸 2에서 A를 내리니 y2,2 = 1(제약 ③), 그러려면 y2,1 = 1(제약 ⑤). 칸 1에는 그 항구에서 내리고 싣는 차만 있고 머무는 차가 없으니 제약 ②도 지켜집니다.

ypi = 1인데 칸 i에서 아무것도 싣지도 내리지도 않는 해는 허용되나요?

허용됩니다. y는 목적함수에 없고, 제약은 "쓰려면 1이어야 한다"와 "1이려면 아래 이웃이 받쳐 줘야 하고 머무는 차가 없어야 한다"만 요구합니다.

제약 ⑤에서 pred(i) 대신 모든 이웃을 쓰면 어떤 해가 잘못 허용되나요?

출입구와 끊긴 칸들이 서로를 근거로 접근 가능하다고 주장하는 해입니다(7장의 「서로 받쳐 주는 섬」). 솔버는 그 칸들에 차를 싣고 내리는 해를 낼 것이고, 실제로는 길이 없으므로 무효해가 됩니다.

  • 변수는 세 종류입니다. xpqi(구간이 있는가), ypi(접근 가능한가), zpqr(몇 대를 쪼갰는가).
  • 목적함수는 구간마다 2 × (F + dist(i))를 더한 것이고 언제나 짝수입니다.
  • 제약은 여섯 가지입니다. ① 구간의 개수 맞추기 ② 머무는 차가 있는 칸은 접근 불가 ③ 내리려면 접근 가능 ④ 실으려면 접근 가능 ⑤ 접근 가능하려면 아래 이웃이 받쳐 줘야 ⑥ 출입구는 접근 가능. 경로와 순서는 나오지 않습니다.
  • 미니 문제 B는 변수 22개, 제약 24줄이고 가능해는 8개, 최적은 68입니다. 공식 예시는 변수 65개, 제약 61줄이고 최적은 190입니다.
  • 모형은 위치변경과 높이를 거스르는 길을 쓰지 못하고, 홀수 고리가 있는 배에서는 비용을 실제보다 작게 셀 수 있습니다.
