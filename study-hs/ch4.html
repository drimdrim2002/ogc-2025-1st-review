그래프와 너비 우선 탐색

자동차 운반선 안에는 차를 세우는 칸이 수백 개 있고, 그 사이를 잇는 통로가 그물처럼 얽혀 있습니다. 이 장에서는 배 안의 구조를 점과 선으로 그린 그래프로 나타내는 법을 배우고, 출입구에서 가까운 칸부터 차례로 훑으며 최단거리를 재는 너비 우선 탐색(BFS)을 손과 Python으로 익힙니다.

  • 미리 알아야 할 것. 2장(집합 기호 ∈, ⊂, |S|), Python의 리스트, for, while, if. (3장의 행렬과 벡터는 이 장에서 쓰지 않습니다.)
  • 이 장을 읽고 나면. 배의 구조를 노드와 간선으로 적을 수 있고, BFS로 층·최단거리 dist·부모를 손과 Python으로 구할 수 있으며, 막힌 칸을 지운 그래프에서 BFS가 무엇을 찾는지 설명할 수 있습니다.
1부 · 그래프의 말

배를 그래프로 보기

수학 시간에 배우는 그래프는 y = x²처럼 함수를 좌표평면에 그린 곡선입니다. 여기서 말하는 그래프는 이름만 같은 다른 것입니다. 지하철 노선도를 떠올리면 됩니다. 노선도에서 중요한 것은 "어느 역과 어느 역이 선로로 바로 이어져 있는가"뿐이고, 역을 종이의 어느 위치에 그렸는지는 중요하지 않습니다.

자동차 운반선도 노선도와 똑같이 그릴 수 있습니다. 차 한 대를 세우는 칸과 배의 문인 출입구를 점으로 찍고, 차가 한 걸음에 바로 지나갈 수 있는 이웃 칸 사이를 선으로 잇습니다.

이 책에서 계속 쓸 격자 배를 예로 봅니다. 가로 3칸, 세로 3칸짜리 배이고, 왼쪽 위 모서리인 0번이 출입구, 1번부터 8번까지가 차를 세우는 칸입니다.

그림에서 읽은 말들을 정의로 정리합니다. 앞으로 모든 그래프 이야기는 이 말들로 적습니다.

정의
  • 그래프(graph) G = (V, E): 점들의 집합 V와 점 둘을 잇는 선들의 집합 E로 이루어진 그림입니다.
  • 노드(node): 그래프의 점입니다(꼭짓점이라고도 합니다). 이 문제에서는 출입구 0과 칸 1, 2, …가 노드입니다.
  • 간선(edge): 두 노드를 잇는 선 {i, j}입니다. 방향이 없어 양쪽으로 다닐 수 있고, 길이는 모두 1로 칩니다.
  • 이웃(neighbor): 간선 하나로 바로 이어진 두 노드입니다. 4의 이웃은 1, 2, 6, 7입니다.

1장에서 본 대로 차 한 대를 싣거나 내릴 때 생기는 경로 하나의 비용은 F + (지나간 통로 수)입니다. 그래프의 말로 바꾸면 F + (지나간 간선 수)입니다. 그러니 간선 수가 적은 경로를 찾을수록 비용이 쌉니다.

경로, 순환, 연결, 트리

격자 배에서 노드 0부터 6까지 가는 길을 생각해 봅니다. 0 → 2 → 4 → 6도 길이고, 0 → 2 → 4 → 1 → 0 → 2 → 4 → 6처럼 중간에 맴도는 것도 통로만 따라간 길입니다. 하지만 같은 칸을 두 번 밟고 돌아가는 것은 낭비일 뿐입니다. 그래서 "같은 노드를 두 번 지나지 않는 길"에 따로 이름을 붙입니다.

정의
  • 경로(path): 간선을 따라 이어 간 노드의 나열로, 같은 노드를 두 번 지나지 않습니다. 경로의 길이는 그 경로가 지나는 간선 수입니다.
  • 순환(cycle): 출발한 노드로 되돌아오는 길입니다(처음과 끝 노드만 같고, 나머지 노드는 겹치지 않으며, 간선 3개 이상).
  • 연결(connected): 어떤 두 노드 사이에도 이어진 경로가 있으면 그래프가 연결되어 있다고 합니다.
  • 트리(tree): 연결되어 있고 순환이 하나도 없는 그래프입니다.

경로 0 → 2 → 4 → 6은 간선 3개를 지나므로 길이가 3입니다. 순환 1 → 3 → 6 → 4 → 1은 길이가 4입니다. 격자 배에는 순환이 있으므로 트리가 아닙니다.

핵심 사실 노드가 n개인 트리는 간선이 정확히 n − 1개이고, 어떤 두 노드를 골라도 둘을 잇는 경로가 정확히 하나뿐입니다.

간선 없이 점 n개만 있으면 n개의 덩어리입니다. 간선을 하나 이을 때마다 덩어리 수가 1씩 줄어드므로, 한 덩어리(연결)가 되려면 간선이 적어도 n − 1개 필요합니다. 여기에 간선을 하나라도 더 붙이면 이미 이어져 있던 두 점 사이에 새 길이 생겨 순환이 만들어집니다. 같은 이유로 두 노드를 잇는 경로가 둘 이상이면 그 둘이 합쳐져 순환이 되므로, 순환이 없는 트리에서는 경로가 하나뿐입니다.

일렬로 칸이 늘어선 배나 가지가 갈라지기만 하는 배는 트리입니다. 반면 격자 배처럼 통로가 그물처럼 얽힌 배는 순환이 있어서, 한 칸에서 출입구로 나가는 경로가 여러 개입니다. 그러면 그중 가장 짧은 경로를 어떻게 체계적으로 찾을까요? 이 질문에 답하는 방법이 다음 부의 너비 우선 탐색입니다.

2부 · 너비 우선 탐색 (BFS)

물결처럼 한 층씩 퍼져 나가기

잔잔한 연못에 돌을 던지면 물결이 동그랗게 퍼져 나갑니다. 돌이 떨어진 곳에서 가까운 곳에 먼저 닿고, 먼 곳에는 나중에 닿습니다. 너비 우선 탐색(breadth-first search, BFS)은 그래프 위에서 이 물결을 그대로 흉내 내는 방법입니다. 출입구(노드 0)에 돌을 던진다고 생각하면 됩니다.

격자 배에서 손으로 물결을 따라가 봅니다. 먼저 간선 목록을 보고 노드마다 이웃 목록을 적어 둡니다(간선이 0-1, 0-2, 1-3, 1-4, 2-4, 2-5, 3-6, 4-6, 4-7, 5-7, 6-8, 7-8 순서로 적혀 있다고 합시다).

0의 이웃: 1, 21의 이웃: 0, 3, 42의 이웃: 0, 4, 5
3의 이웃: 1, 64의 이웃: 1, 2, 6, 75의 이웃: 2, 7
6의 이웃: 3, 4, 87의 이웃: 4, 5, 88의 이웃: 6, 7

규칙은 간단합니다. 이미 본 노드는 다시 모으지 않으면서, 현재 물결의 이웃들을 다음 물결로 모읍니다. 이때 어떤 노드가 다음 물결에 들어가도록 처음 눈에 띄는 것을 발견, 자기 차례가 되어 그 노드의 이웃을 살펴보는 것을 방문이라고 부릅니다.

그림 오른쪽의 세 굵은 선 중 `{3, 6}`을 확인해 둡시다. 층 L₂의 3이 6을 먼저 발견했으므로 6의 부모는 3이고, `{3, 6}`이 부모 간선입니다. 반대로 `{4, 6}`과 `{7, 8}`은 이미 발견된 노드를 다시 만난 간선이라 부모 간선이 아닙니다. 부모 간선 8개만 남기면 노드 9개짜리 트리가 됩니다.

이제 방금 손으로 한 절차를 정의로 적습니다.

정의
  • 너비 우선 탐색(BFS, breadth-first search): 출발 노드(출입구 0)에서 시작해, 아직 발견하지 않은 이웃을 한 층씩 모으며 가까운 노드부터 방문하는 탐색 방법입니다.
  • 층(layer) Lk: 출발 노드에서 k번째 물결에 모인 노드들의 집합입니다(L0 = {0}).
  • 부모(parent): BFS에서 어떤 노드를 처음 발견해 준 바로 앞 층의 노드입니다.
  • 최단거리 dist(i): 출발 노드 0에서 노드 i까지 가는 경로 중 간선 수가 가장 적은 것의 간선 수입니다.

BFS가 보장하는 두 가지

격자 배의 표에서 층 번호가 곧 0에서의 최단거리였습니다. 예를 들어 노드 8은 층 4에 있고, 8에서 0으로 가는 길은 간선 4개보다 짧을 수 없습니다. 이것은 우연이 아닙니다.

핵심 사실 (BFS는 최단거리를 잰다) 출입구 0에서 BFS를 하면, 층 Lk에 들어간 노드는 정확히 최단거리 dist(i) = k인 노드들입니다. 또 어떤 노드에서든 부모를 따라 거슬러 올라가면 출입구까지 가는 최단 경로가 나옵니다.

층 1은 0의 이웃이므로 거리가 1입니다. 층 2는 층 1의 이웃 가운데 층 0·1에 없던 노드들이니 2걸음으로 갈 수 있고, 1걸음 이하로는 못 갑니다. 이렇게 층 번호가 하나 늘 때마다 거리가 정확히 1씩 늘어납니다. 부모는 언제나 바로 앞 층에 있으므로, 부모를 따라 한 걸음씩 거슬러 올라가면 매번 거리가 1씩 줄어 k걸음 만에 0에 닿습니다.

수학적 귀납법으로 확인하기. "Lk에 든 노드 = dist가 k인 노드"가 k까지 성립한다고 가정하면, Lk+1의 노드는 Lk의 이웃이므로 dist ≤ k + 1이고 앞 층에 없었으므로 dist ≤ k가 아닙니다. 따라서 dist = k + 1입니다. 반대로 dist = k + 1인 노드는 최단 경로의 바로 앞 노드가 Lk에 있으므로 Lk를 훑을 때 반드시 발견됩니다.

두 번째로 눈여겨볼 성질이 있습니다. 격자 배의 12개 간선을 하나씩 살펴보세요. `{0, 1}`은 L₀–L₁, `{2, 4}`는 L₁–L₂, `{4, 6}`은 L₂–L₃을 잇습니다. L₀과 L₂를 바로 건너뛰어 잇는 간선은 하나도 없습니다.

핵심 사실 (간선은 같은 층이나 이웃 층만 잇는다) 어떤 간선 {u, v}의 양 끝 노드 u, v에 대해서도 |dist(u) − dist(v)| ≤ 1입니다. 즉 모든 간선은 같은 층의 두 노드를 잇거나, 바로 이웃한 두 층의 노드를 잇습니다.

만약 u가 층 1에 있는데 그 이웃 v가 층 3에 있었다고 해 봅시다. BFS가 층 1의 u를 방문할 때 u의 이웃인 v를 이미 봤을 것이므로, v는 늦어도 층 2에서 발견되었어야 합니다. 그러니 두 층 이상 건너뛰는 간선은 있을 수 없습니다.

격자 배에서는 심지어 같은 층을 잇는 간선도 하나도 없었습니다. 하지만 5장에서 볼 "5칸 고리" 같은 배에서는 같은 층의 두 노드를 잇는 간선이 나타납니다. 이 작은 차이가 5장의 핵심 주제가 됩니다.

3부 · Python으로 BFS, 그리고 칸을 지운 그래프

Python으로 옮기기

앞에서 손으로 만든 표를 그대로 Python 코드로 적습니다. "지금 층" 리스트(layer)와 "다음 층" 리스트(next_layer) 두 개를 번갈아 쓰는 것이 전부입니다.

def bfs(N, E):
    nbr = []
    for i in range(N):
        nbr.append([])
    for e in E:
        nbr[e[0]].append(e[1])
        nbr[e[1]].append(e[0])
    dist = [-1] * N
    parent = [-1] * N
    order = []
    dist[0] = 0
    layer = [0]
    while len(layer) > 0:
        next_layer = []
        for i in layer:
            order.append(i)
            for j in nbr[i]:
                if dist[j] == -1:
                    dist[j] = dist[i] + 1
                    parent[j] = i
                    next_layer.append(j)
        layer = next_layer
    return order, dist, parent

E = [[0, 1], [0, 2], [1, 3], [1, 4], [2, 4], [2, 5], [3, 6], [4, 6], [4, 7], [5, 7], [6, 8], [7, 8]]
order, dist, parent = bfs(9, E)
print("방문 순서:", order)
print("거리:", dist)
print("부모:", parent)

방문 순서: [0, 1, 2, 3, 4, 5, 6, 7, 8]
거리: [0, 1, 1, 2, 2, 2, 3, 3, 4]
부모: [-1, 0, 0, 1, 1, 2, 3, 4, 6]
  • 1행 N은 노드 개수, E는 간선 목록입니다.
  • 2~7행 노드마다 이웃 목록 nbr[i]를 만듭니다. 간선 [u, v]는 양방향이므로 u와 v 양쪽 목록에 모두 넣습니다.
  • 8~10행 dist와 parent를 모두 −1로 채워 두고, "아직 발견하지 못한 노드" 표시로 씁니다. order에는 방문 순서를 쌓습니다.
  • 11~12행 출입구(노드 0)의 거리를 0으로 두고, 층 0 리스트 [0]에서 시작합니다.
  • 13행 지금 층에 노드가 남아 있는 동안 계속 돕니다.
  • 15~16행 지금 층의 노드 i를 차례로 방문하고, order에 기록합니다.
  • 17~21행 i의 이웃 j를 봅니다. dist[j] == -1이면 처음 발견한 노드이므로 거리(나보다 1 큼)와 부모(i)를 적고 다음 층에 넣습니다.
  • 22행 다음 층이 새로운 지금 층이 됩니다. 다음 층이 비어 있으면 while 문이 끝납니다.
  • 25~29행 3 × 3 격자 배에 실행합니다. 앞의 표와 똑같은 결과가 나옵니다.

18행의 if dist[j] == -1:을 빼먹으면? 이미 방문한 이웃도 다시 다음 층에 들어가서 0 → 1 → 0 → 1 …처럼 끝나지 않고 무한히 돕니다. "한 번 발견한 노드는 다시 넣지 않는다"가 BFS가 멈추게 해 주는 핵심 조건입니다.

방금 본 order와 parent를 보면, 노드 8의 부모는 6, 6의 부모는 3, 3의 부모는 1, 1의 부모는 0입니다. 거꾸로 적으면 8 → 6 → 3 → 1 → 0, 길이 4 = dist[8]인 최단 경로입니다.

한 가지 더 눈여겨볼 점이 있습니다. 만약 25행에서 맨 앞 두 간선의 순서를 바꾸어 [0, 2]를 [0, 1]보다 먼저 적으면 어떻게 될까요? 층 L₁이 [2, 1]이 되어 2가 1보다 먼저 방문되므로 order와 노드 4의 부모(2로 바뀜)는 달라집니다. 하지만 각 노드가 속한 층과 최단거리 dist는 절대 달라지지 않습니다.

칸을 지운 그래프에서의 BFS

실제 자동차 운반선에서는 배가 비어 있는 채로만 움직이지 않습니다. 어떤 항구에서 차를 내리거나 실으려고 할 때, 다른 칸들에는 계속 실려 있을 머무는 차가 서 있습니다. 머무는 차가 있는 칸은 다른 차가 밟고 지나갈 수 없는 벽과 같습니다.

그러면 "머무는 차가 서 있는 칸들을 피해 출입구에서 어떤 칸까지 가는 가장 짧은 길"은 어떻게 찾을까요? 답은 놀랍도록 간단합니다. 머무는 차가 있는 칸을 그래프에서 지워 버리고, 남은 그래프에서 똑같이 BFS를 돌리면 됩니다.

3 × 3 격자 배에서 칸 1과 칸 4에 머무는 차가 있다고 합시다. 둘을 지운 그래프에서 출입구 0부터 BFS를 해 봅니다.

Python 코드에서는 18행에 "j가 막힌 칸 목록에 없다"는 조건 하나만 덧붙이면 됩니다. 막힌 칸을 아예 발견하지도 않고 건너뛰므로, 막힌 칸이 그래프에서 빠진 것과 똑같이 동작합니다. 앞에서 본 BFS의 최단거리 성질은 이 작은 그래프에서도 그대로 성립합니다. 그러니 거기서 나온 부모를 따라가면 막힌 칸을 피해서 가는 가장 짧은 경로(3 → 6 → 8 → 7 → 5 → 2 → 0)가 나옵니다.

만약 칸 1과 칸 2에 모두 머무는 차가 있어서 둘을 다 지우면 어떻게 될까요? 출입구 0의 이웃이 모두 막혔으니 BFS는 층 0에서 바로 끝나고, 칸 3부터 8까지는 dist가 −1 그대로 남습니다. 즉 출입구에서 닿을 수 없는 칸이라는 뜻입니다.

가이드와 연결

가이드의 「높이 매기기」 절에서 배 안을 그래프로 바꾸고 BFS를 돌리는 코드가 바로 이 장의 코드입니다. 다만 1등 팀은 order(몇 번째로 방문했는가)를 「높이」라는 새 번호로 쓰고, 이 높이를 가지고 다음 장의 방향과 접근 가능 규칙을 만듭니다.

가이드의 「해 복원」 절에서는 솔버가 배치를 정한 뒤, 각 항구에서 머무는 차가 서 있는 칸을 막아 두고 BFS를 다시 돌려 실제 이동 경로를 만듭니다. 그것이 바로 이 장 마지막 절의 「칸을 지운 그래프에서의 BFS」입니다.

  • 그래프는 노드(출입구와 칸)와 간선(이웃 통로)으로 이루어집니다. 같은 노드를 두 번 지나지 않는 길이 경로, 제자리로 돌아오는 길이 순환입니다.
  • 연결되어 있고 순환이 없는 그래프가 트리입니다. 노드 n개인 트리는 간선이 n − 1개이고 두 노드 사이 경로가 하나뿐입니다.
  • BFS는 출입구에서 가까운 노드부터 한 층씩 방문하며, 층 번호가 곧 최단거리 dist입니다.
  • 부모를 거슬러 올라가면 출입구까지 가는 최단 경로가 나옵니다.
  • 모든 간선은 같은 층이나 바로 이웃한 층만 잇습니다.
  • 머무는 차가 있는 칸을 지우고 BFS를 다시 돌리면, 막힌 칸을 피하는 최단 경로를 얻을 수 있습니다.

연습문제

3 × 3 격자 배에서 노드 4의 이웃을 모두 적고, 노드 0에서 노드 8로 가는 경로를 서로 다르게 두 가지 적어 보세요.

노드 4의 이웃은 1, 2, 6, 7입니다. 0에서 8로 가는 경로 예: 0 → 1 → 3 → 6 → 8(길이 4), 0 → 2 → 5 → 7 → 8(길이 4). 길이가 6인 우회 경로(0 → 1 → 4 → 2 → 5 → 7 → 8)도 같은 노드를 두 번 지나지 않으므로 경로입니다.

칸 9개와 출입구 1개로 이루어진 배가 트리 모양이라면, 통로(간선)는 몇 개이고 출입구에서 9번 칸으로 가는 경로는 몇 가지인가요?

노드가 총 n = 10개이므로 간선은 n − 1 = 9개입니다. 트리는 순환이 없으므로 두 노드를 잇는 경로는 정확히 1가지뿐입니다.

본문의 3 × 3 격자 배 BFS 결과에서 노드 7의 부모는 누구이고, 부모를 따라 출입구 0까지 가는 경로는 무엇인가요?

parent[7] = 4입니다(층 2에서 4가 5보다 먼저 방문되어 7을 발견했기 때문). 부모를 따라가면 7 → 4 → 1 → 0이고, 길이는 3 = dist[7]로 최단 경로입니다.

3 × 3 격자 배에서 맨 앞 두 간선의 순서를 바꾸어 [0, 2]를 [0, 1]보다 먼저 적고 BFS를 돌리면, 층 L₀~L₄와 방문 순서 order, 그리고 노드 4의 부모는 어떻게 되나요?

층은 {0}, {2, 1}, {4, 5, 3}, {6, 7}, {8}로 각 층에 든 노드 집합과 최단거리 dist는 변하지 않습니다. 다만 층 1에서 2가 먼저 방문되므로 order는 [0, 2, 1, 4, 5, 3, 6, 7, 8]이 되고, 노드 4는 2가 처음 발견하므로 4의 부모가 1에서 2로 바뀝니다.

3 × 3 격자 배에서 칸 2와 칸 4에 머무는 차가 서 있을 때, 둘을 지운 그래프에서 BFS를 돌려 층과 각 칸의 최단거리(닿지 못하면 −1)를 구하세요.

층 0: {0}, 층 1: {1}, 층 2: {3}, 층 3: {6}, 층 4: {8}, 층 5: {7}, 층 6: {5}. 거리 목록은 노드 0부터 8까지 차례로 [0, 1, −1, 2, −1, 6, 3, 5, 4]입니다. 칸 5는 원래 거리 2였지만 0 → 1 → 3 → 6 → 8 → 7 → 5로 돌아가야 해서 거리 6이 됩니다.

노드 5개가 0-1-2-3-4-0으로 둥글게 이어진 「5칸 고리」에서 0부터 BFS를 할 때 층 L₀, L₁, L₂를 적고, 같은 층의 두 노드를 잇는 간선을 찾으세요.

L₀ = {0}, L₁ = {1, 4}, L₂ = {2, 3}입니다. 같은 층의 두 노드를 잇는 간선은 L₂ 안의 {2, 3}입니다. 이 간선의 뜻은 5장에서 깊이 다룹니다.

3 × 3 격자 배에서 칸 1과 칸 2에 모두 머무는 차가 서 있다면, 둘을 지운 그래프의 BFS는 어디서 멈추고 dist는 어떻게 나오나요?

출입구 0의 이웃이 1과 2뿐인데 둘 다 막혀 있으므로, 층 0 = [0]을 방문한 뒤 다음 층이 비어서 바로 멈춥니다. dist는 [0, −1, −1, −1, −1, −1, −1, −1, −1]이 됩니다.
