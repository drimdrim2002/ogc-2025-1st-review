종합 과제: 새 문제를 적어 보기

도착점은 "새 문제를 보고 식으로 적는 것"이었습니다. 아래 문제를 식으로 적고, 전부 해 보기 프로그램과 솔버로 각각 풀어 답을 맞춰 보세요. 실마리는 접어 두었으니 먼저 스스로 적어 본 뒤 펼칩니다. 답으로 적은 숫자는 이 문서를 쓰면서 두 방법으로 계산해 맞춰 본 것입니다.

과제 A. 트럭 수 줄이기. 무게가 4, 8, 1, 4, 2, 1톤인 화물 여섯 개를, 한 대에 10톤까지 싣는 트럭에 나눠 싣습니다. 트럭은 세 대까지 부를 수 있습니다. 가장 적은 트럭으로 다 실으려면?

과제 A의 실마리와 답

변수는 두 종류입니다. xjk는 "화물 j를 트럭 k에 실으면 1", uk는 "트럭 k를 부르면 1"입니다. 제약은 "화물마다 정확히 한 트럭"(Σk xjk = 1, 모든 화물 j)과 "부른 트럭에만, 10톤 이하로"(Σj wj xjk ≤ 10 uk, 모든 트럭 k)입니다. 목적함수는 Σk uk의 최소화입니다. 둘째 제약은 uk = 0이면 오른쪽이 0이 되어 그 트럭에 아무것도 못 싣게 합니다. 답은 2대입니다. 무게의 합이 20톤이라 2대가 꽉 차야 하고, 실제로 (8, 2)와 (4, 4, 1, 1)로 나눌 수 있습니다.

과제 B. 버스 차고지 (순서를 없애는 연습). 버스 6대가 저녁에 1번, 2번, …, 6번 순서로 차고지에 들어옵니다. 차고지에는 한쪽으로 들어가 반대쪽으로 나가는 긴 차로가 2개 있고, 차로 하나에 3대가 들어갑니다. 아침에는 3, 1, 2, 6, 4, 5번 순서로 나가야 합니다. 같은 차로에서 앞에 선 버스가 뒤 버스보다 늦게 나가야 하면 뒤 버스가 막힙니다. 한 번도 막히지 않게 버스를 차로에 배정할 수 있을까요? 나가는 순서가 3, 2, 1, 6, 5, 4라면 어떨까요?

과제 B의 실마리와 답

얼핏 "차로 안에서 몇 번째 자리인가"라는 순서 변수가 필요해 보입니다. 하지만 들어오는 순서가 정해져 있으므로, 같은 차로 안의 자리 순서는 들어온 순서로 저절로 정해집니다. 정할 것은 "어느 차로인가"뿐입니다. xbl을 "버스 b를 차로 l에 넣으면 1"로 둡니다. 먼저 들어오는데 나중에 나가야 하는 쌍을 미리 찾아 두면, 제약은 "그런 쌍은 같은 차로에 둘 수 없다"(xal + xbl ≤ 1, 모든 차로 l), "버스마다 정확히 한 차로", "차로마다 3대 이하"입니다.

첫 번째 순서에서 문제가 되는 쌍은 (1, 3), (2, 3), (4, 6), (5, 6) 네 개이고, {1, 2, 6}과 {3, 4, 5}로 나누면 한 번도 막히지 않습니다. 차로 이름만 바꾼 것을 빼면 이 방법 하나뿐입니다. 두 번째 순서에서는 문제가 되는 쌍이 여섯 개로 늘어, 어떻게 배정해도 적어도 두 쌍은 막힙니다. tryAgain이 "한 항구 안의 순서는 높이로 저절로 정해진다"는 것을 써서 배치만 변수로 남긴 것(7장)과 같은 발상입니다.

과제 C (선택). 순서를 없앨 수 없는 경우. 숙제 n개를 하나씩 해야 합니다. 숙제마다 걸리는 시간과 마감이 있고, 마감을 넘긴 시간의 합을 가장 작게 하고 싶습니다. 이 문제에서 "어느 것을 먼저 할지"를 변수에서 뺄 수 있을까요?

과제 C의 실마리

뺄 수 없습니다. 여기서는 순서 자체가 정하려는 것입니다. 식으로 적으려면 숙제 두 개의 쌍마다 "i를 j보다 먼저 한다"는 0/1 변수가 필요하고, 그 변수와 시작 시각을 잇는 데 big-M이라는 요령이 들어갑니다(교재 11장). 숙제가 n개면 쌍이 n(n−1)/2개라서 변수가 빠르게 늘고, 모형도 약해집니다. 과제 B와 견주어 보면 "순서를 없앨 수 있는 구조를 찾았는가"가 얼마나 큰 차이인지 보입니다. 숙제가 대여섯 개라면 순서 n!가지를 전부 해 보는 쪽이 더 간단합니다.

통과 기준. 과제 A와 B에서 실마리를 보기 전에 변수와 제약의 뼈대를 적을 수 있었다면 도착점에 온 것입니다. 과제 B에서 자리 순서를 변수로 두었다면, 7장을 다시 읽고 "무엇이 정해지면 나머지가 따라오는가"를 먼저 묻는 연습을 더 합니다.

"""너비 우선 탐색(BFS)으로 노드마다 높이·거리·아래 이웃을 구한다 (6장).

팀 코드 function.cpp 의 getBFSOrientation 을 Python으로 옮긴 것이다.
실행: python3 bfs_height.py
"""


def bfs_height(N, E):
    """N: 노드 수(0이 출입구), E: 간선 목록. (높이, 거리, 방문 순서, 아래 이웃)을 돌려준다."""
    nbr = [[] for _ in range(N)]            # nbr[i] = 노드 i의 이웃 목록
    for u, v in E:
        nbr[u].append(v)
        nbr[v].append(u)

    height = [None] * N                     # 높이 = 방문 순번
    dist = [None] * N                       # 출입구에서의 거리
    order = []                              # 방문한 순서대로 노드 번호
    dist[0] = 0
    layer = [0]                             # 지금 층: 출입구 하나로 시작
    while layer:
        next_layer = []                     # 다음 층
        for i in layer:
            height[i] = len(order)          # 지금까지 방문한 노드 수 = 이번 노드의 순번
            order.append(i)
            for j in nbr[i]:
                if dist[j] is None:         # 처음 발견한 이웃이면
                    dist[j] = dist[i] + 1
                    next_layer.append(j)
        layer = next_layer

    # 아래 이웃: 이웃 가운데 높이가 더 낮은 노드
    pred = {i: [j for j in nbr[i] if height[j] < height[i]] for i in range(1, N)}
    return height, dist, order, pred

"""미니 문제 B의 모형(8장)을 '변수 값의 모든 조합을 다 넣어 보기'로 푼다.

솔버가 하는 일을 가장 무식한 방법으로 흉내 낸 것이다.
변수에 0과 1을 넣는 모든 경우를 만들고, 제약식 ①~⑥을 전부 지키는 것만 남긴 뒤,
그중 목적함수 값이 가장 작은 것을 고른다.
실행: python3 mini_model_enumerate.py
"""
from itertools import product

# ----- 문제: 일렬 배(출입구 0, 칸 1, 칸 2), 항구 0~3, 고정비 10 -----
P, F = 4, 10
cells = [1, 2]                      # 칸
dist = {1: 1, 2: 2}                 # 출입구에서 칸까지의 거리
pred = {1: [0], 2: [1]}             # 아래 이웃 (7장)
demand = {(0, 2): 1, (1, 3): 1}     # 차 A: 항구 0→2, 차 B: 항구 1→3

pairs = [(p, q) for p in range(P) for q in range(p + 1, P)]            # 항구 쌍 6개
mid = [1, 2]                                                           # 중간 항구
xkeys = [(p, q, i) for (p, q) in pairs for i in cells]                 # x 12개
ykeys = [(p, i) for p in mid for i in cells]                           # y 4개 (y_p0 은 1로 고정)
zkeys = [(p, q, r) for p in range(P) for q in range(p + 1, P) for r in range(q + 1, P)]  # z 4개


def demand_ok(x, z):
    """제약 ①: 항구 쌍 (p, q)마다 구간의 개수가 맞는가"""
    for (p, q) in pairs:
        left = sum(x[p, q, i] for i in cells)
        right = (demand.get((p, q), 0)
                 - sum(z[p, r, q] for r in range(p + 1, q))      # (p,q)가 r에서 쪼개져 사라진 수
                 + sum(z[p, q, r] for r in range(q + 1, P))      # (p,r)이 q에서 쪼개진 앞 토막
                 + sum(z[r, p, q] for r in range(p)))            # (r,q)가 p에서 쪼개진 뒤 토막
        if left != right:
            return False
    return True


def access_ok(x, y):
    """제약 ②~⑥: 중간 항구마다, 칸마다"""
    for q in mid:
        yq = {0: 1}                                              # ⑥ 출입구는 항상 접근 가능
        for i in cells:
            yq[i] = y[q, i]
        for i in cells:
            staying = sum(x[p, r, i] for p in range(q) for r in range(q + 1, P))
            unload = sum(x[p, q, i] for p in range(q))
            load = sum(x[q, r, i] for r in range(q + 1, P))
            if staying > 1 - yq[i]: return False                 # ② 머무는 차가 있으면 접근 불가
            if unload > yq[i]: return False                      # ③ 내리려면 접근 가능해야
            if load > yq[i]: return False                        # ④ 실으려면 접근 가능해야
            if yq[i] > sum(yq[j] for j in pred[i]): return False  # ⑤ 아래 이웃이 받쳐 줘야
    return True


def cost(x):
    return sum(2 * (F + dist[i]) * x[p, q, i] for (p, q, i) in xkeys)


tried = feasible = 0
best_cost, best = None, []
for xv in product((0, 1), repeat=len(xkeys)):                    # x: 2^12 = 4096가지
    x = dict(zip(xkeys, xv))
    for zv in product((0, 1, 2), repeat=len(zkeys)):             # z: 0, 1, 2 → 3^4 = 81가지
        z = dict(zip(zkeys, zv))
        tried += 16                                              # y 16가지를 함께 센 것
        if not demand_ok(x, z):
            continue
        for yv in product((0, 1), repeat=len(ykeys)):            # y: 2^4 = 16가지
            y = dict(zip(ykeys, yv))
            if not access_ok(x, y):
                continue
            feasible += 1
            c = cost(x)
            if best_cost is None or c < best_cost:
                best_cost, best = c, []
            if c == best_cost:
                best.append((x, y, z))

print("넣어 본 조합:", tried)
print("제약을 모두 지킨 조합(가능해):", feasible)
print("가장 작은 목적함수 값:", best_cost)
seen = set()
for x, y, z in best:
    key = (tuple(k for k in xkeys if x[k]), tuple((k, z[k]) for k in zkeys if z[k]))
    if key in seen:
        continue
    seen.add(key)
    print("  x = 1:", [k for k in xkeys if x[k]], " z > 0:", {k: z[k] for k in zkeys if z[k]},
          " y = 1:", [k for k in ykeys if y[k]])
print("x, z 가 서로 다른 최적해의 수:", len(seen), " (y 까지 구별하면", len(best), "개)")

import itertools, sys, json
from collections import Counter

def bfs_orientation(N, E, accessible=None):
    nbr = [[] for _ in range(N)]
    for u, v in E:
        nbr[u].append(v); nbr[v].append(u)
    if accessible is None: accessible = [True]*N
    INF = float('inf')
    pred = [INF]*N; pos = [INF]*N; dist = [INF]*N
    order = []
    search = [0]; dist[0] = 0; pred[0] = -1; p = 0
    while search:
        nxt = []
        for i in search:
            order.append(i); pos[i] = p; p += 1
            for j in nbr[i]:
                if accessible[j] and pred[j] == INF:
                    pred[j] = i; dist[j] = dist[i]+1; nxt.append(j)
        search = nxt
    return nbr, pred, pos, dist, order

def compositions(o, d):
    """[o,d) 구간을 연속한 구간(leg)들로 쪼개는 모든 방법"""
    res = []
    mids = list(range(o+1, d))
    for r in range(len(mids)+1):
        for cut in itertools.combinations(mids, r):
            pts = [o, *cut, d]
            res.append(tuple(zip(pts[:-1], pts[1:])))
    return res

    predset = {i: [j for j in nbr[i] if pos[j] < pos[i]] for i in range(1, N)}
    cars = []
    for k, ((o, d), q) in enumerate(K):
        cars += [(k, o, d)]*q
    best = [float('inf'), None]
    nodes_by_dist = sorted(range(1, N), key=lambda i: (dist[i], pos[i]))

    def accessible_ok(assign):
        # assign: list of (p,q,i)
        for port in range(1, P-1):
            staying = {i for (p, q, i) in assign if p < port < q}
            active = {i for (p, q, i) in assign if p == port or q == port}
            if active & staying: return False
            # y: 가장 크게 잡을 수 있는 y (staying 아닌 노드 중 단조 경로로 닿는 것)

                    y.add(i)
            if not active <= y: return False
        return True

    seen_multisets = set()
    for combo in itertools.product(*[compositions(o, d) for (_, o, d) in cars]):
        legs = sorted(l for c in combo for l in c)
        key = tuple(legs)
        if key in seen_multisets: continue
        seen_multisets.add(key)
        # 하한: 모든 leg가 가장 가까운 노드에
        if 2*len(legs)*(F+1) >= best[0]: continue
        occ = {i: [] for i in range(1, N)}
        assign = []
        def dfs(idx, cost):
            if cost + 2*(len(legs)-idx)*(F+1) >= best[0]: return
            if idx == len(legs):
                if accessible_ok(assign):
                    best[0] = cost; best[1] = (list(assign), combo)
                return
            p, q = legs[idx]
            prev_same = idx > 0 and legs[idx-1] == (p, q)
            for i in nodes_by_dist:
                if prev_same and pos[i] < pos[assign[-1][2]]: continue  # 대칭 제거
                if any(not (q <= a or b <= p) for a, b in occ[i]): continue
                occ[i].append((p, q)); assign.append((p, q, i))
                dfs(idx+1, cost + 2*(F+dist[i]))
                assign.pop(); occ[i].pop()
        dfs(0, 0)
    cost, (assign, combo) = best
    # z 복원
    z = Counter()
    for (k, o, d), comp in zip(cars, combo):
        # 순차 분할: (o,d) -> 첫 leg (o,m) + (m,d) ...  (긴 구간에서 짧은 구간으로)
        cur_o = o
        for (a, b) in comp[:-1]:
            z[(a, b, d)] += 1
    return dict(cost=cost, x=sorted(assign), z=dict(z), dist=dist, pos=pos,
                predset=predset, cars=cars, combo=combo)

def reconstruct(N, E, P, K, x, z):
    """function.cpp의 get_solution을 그대로 옮긴 것"""
    xs = set(x)
    pool = {}
    for k, ((o, d), q) in enumerate(K):
        pool[(o, d)] = [k]*q
    rem = dict(z)
    left = len([v for v in rem.values() if v > 0])
    while left > 0:
        for key in list(rem):
            value = rem[key]
            p, q, r = key
            amt = min(value, len(pool.get((p, r), [])))
            if amt == 0: continue
            for _ in range(amt):
                k = pool[(p, r)].pop()
                pool.setdefault((p, q), []).append(k)
                pool.setdefault((q, r), []).append(k)
            rem[key] -= amt
            if amt == value: left -= 1
    sol = {p: [] for p in range(P)}
    for c in range(P):
        acc = [True]*N
        if 0 < c < P-1:
            for i in range(1, N):
                acc[i] = not any((p, r, i) in xs for p in range(c) for r in range(c+1, P))
        nbr, pred, pos, dist, order = bfs_orientation(N, E, acc)
        def route(i):
            r = []
            while i != 0:
                r.append(i); i = pred[i]
            r.append(0); return r
        if c > 0:
            for i in order[1:]:
                for p in range(c):
                    if (p, c, i) in xs:
                        sol[c].append([route(i), 0])   # 원 코드: 하역 경로의 수요 번호는 항상 0
        if c < P-1:
            for i in reversed(order[1:]):
                for r in range(c+1, P):
                    if (c, r, i) in xs:
                        k = pool[(c, r)].pop()
                        sol[c].append([route(i)[::-1], k])
    return sol

def check(N, E, P, K, F, LB, solution):
    """util.check_feasibility를 numpy 없이 옮긴 것"""
    Eset = set(map(tuple, E))
    alloc = [-1]*N
    obj = 0; inf = []
    for p in range(P):
        for route, k in solution[p]:
            if len(route) <= 1: inf.append('short')
            if len(route) != len(set(route)): inf.append('not simple')
            for u, v in zip(route[:-1], route[1:]):
                if (u, v) not in Eset and (v, u) not in Eset: inf.append(f'bad edge {(u,v)}')
            if route[0] == 0:
                if alloc[route[-1]] != -1: inf.append(f'load occupied {route}')
                if any(alloc[i] != -1 for i in route[:-1]): inf.append(f'load blocked {route}')
                alloc[route[-1]] = k
            elif route[-1] == 0:
                if alloc[route[0]] == -1: inf.append(f'unload empty {route}')
                if any(alloc[i] != -1 for i in route[1:]): inf.append(f'unload blocked {route}')
                alloc[route[0]] = -1
            else:
                inf.append('rehandling route (not expected)')
            obj += F + len(route) - 1
        cur = Counter(a for a in alloc if a >= 0)
        exp = {k: r for k, ((o, d), r) in enumerate(K) if o <= p < d}
        if cur != exp: inf.append(f'port {p}: {dict(cur)} != {exp}')
    return obj, obj - LB, inf

def lower_bound(N, E, P, K, F):
    _, _, _, dist, _ = bfs_orientation(N, E)
    ds = sorted(dist[1:])
    LB = 0
    for p in range(P):
        load = sum(q for ((o, d), q) in K if o == p)
        unload = sum(q for ((o, d), q) in K if d == p)
        LB += F*(load+unload) + sum(ds[:load]) + sum(ds[:unload])
    return LB

"""tryAgain의 모형(8장)을 무료 솔버로 푼다. Google OR-Tools 사용.

- 설치: pip install ortools      (라이선스가 필요 없다)
- 실행: python3 roro_model_ortools.py
- 원본: 팀 코드 function.cpp 의 formulate(). 변수와 제약식의 번호 ①~⑥은 8장과 같다.
"""
from ortools.linear_solver import pywraplp


def bfs_height(N, E):
    """6장: 출입구(0)에서 너비 우선 탐색. 높이와 거리, 이웃 목록을 돌려준다."""
    nbr = [[] for _ in range(N)]
    for u, v in E:
        nbr[u].append(v)
        nbr[v].append(u)
    height, dist = [None] * N, [None] * N
    dist[0] = 0
    layer, count = [0], 0
    while layer:
        next_layer = []
        for i in layer:
            height[i] = count
            count += 1
            for j in nbr[i]:
                if dist[j] is None:
                    dist[j] = dist[i] + 1
                    next_layer.append(j)
        layer = next_layer
    return nbr, height, dist


def solve(prob, relax=False):
    """relax=True 이면 '0 또는 1'이라는 조건을 '0 이상 1 이하'로 풀어 준 LP 완화를 푼다 (5장)."""
    N, E, P, K, F = prob["N"], prob["E"], prob["P"], prob["K"], prob["F"]
    nbr, height, dist = bfs_height(N, E)

    pred = {}                                   # pred[i] = 칸 i의 아래 이웃 목록
    for i in range(1, N):
        pred[i] = []
        for j in nbr[i]:
            if height[j] < height[i]:
                pred[i].append(j)

    pairs = []                                  # 항구 쌍 (p, q), p < q
    for p in range(P):
        for q in range(p + 1, P):
            pairs.append((p, q))
    cells = range(1, N)                         # 칸 (출입구 제외)
    mid = range(1, P - 1)                       # 중간 항구

    d = {}                                      # d[p, q] = 항구 p에서 실어 q에서 내릴 차의 수
    for (p, q) in pairs:
        d[p, q] = 0
    for (o, dest), qty in K:
        d[o, dest] = qty

    s = pywraplp.Solver.CreateSolver("GLOP" if relax else "SCIP")
    INF = s.infinity()

    def var(lo, hi, name):          # 정수 변수(완화할 때는 실수 변수) 하나 만들기
        if relax:
            return s.NumVar(lo, hi, name)
        return s.IntVar(lo, hi, name)

    # --- 결정변수 ---
    x, y, z = {}, {}, {}
    for (p, q) in pairs:
        for i in cells:
            x[p, q, i] = var(0, 1, f"x_{p}_{q}_{i}")
    for p in mid:
        for i in range(N):
            y[p, i] = var(0, 1, f"y_{p}_{i}")
    for p in range(P):
        for q in range(p + 1, P):
            for r in range(q + 1, P):
                z[p, q, r] = var(0, INF, f"z_{p}_{q}_{r}")

    # --- 목적함수: 구간 하나 = 선적 경로 + 하역 경로 ---
    cost = 0
    for (p, q) in pairs:
        for i in cells:
            cost = cost + 2 * (F + dist[i]) * x[p, q, i]
    s.Minimize(cost)

    # --- 제약 ① 수요: 항구 쌍마다 구간의 개수 맞추기 ---
    for (p, q) in pairs:
        left = 0
        for i in cells:
            left = left + x[p, q, i]
        right = d[p, q]
        for r in range(p + 1, q):
            right = right - z[p, r, q]          # (p,q)가 r에서 쪼개져 사라진 수
        for r in range(q + 1, P):
            right = right + z[p, q, r]          # (p,r)이 q에서 쪼개진 앞 토막
        for r in range(p):
            right = right + z[r, p, q]          # (r,q)가 p에서 쪼개진 뒤 토막
        s.Add(left == right)

    for q in mid:
        s.Add(y[q, 0] == 1)                     # 제약 ⑥ 출입구는 접근 가능
        for i in cells:
            staying = 0                         # 항구 q에서 칸 i에 머무는 구간
            for p in range(q):
                for r in range(q + 1, P):
                    staying = staying + x[p, r, i]
            s.Add(staying <= 1 - y[q, i])       # 제약 ② 머무는 차가 있으면 접근 불가

            unload = 0                          # 항구 q에서 칸 i로부터 내리는 구간
            for p in range(q):
                unload = unload + x[p, q, i]
            s.Add(unload <= y[q, i])            # 제약 ③ 내리려면 접근 가능

            load = 0                            # 항구 q에서 칸 i에 싣는 구간
            for r in range(q + 1, P):
                load = load + x[q, r, i]
            s.Add(load <= y[q, i])              # 제약 ④ 실으려면 접근 가능

            below = 0                           # 아래 이웃들의 y
            for j in pred[i]:
                below = below + y[q, j]
            s.Add(y[q, i] <= below)             # 제약 ⑤ 아래 이웃이 받쳐 줘야

    status = s.Solve()
    assert status == pywraplp.Solver.OPTIMAL
    xs, zs = {}, {}
    for k in x:
        if x[k].solution_value() > 1e-6:
            xs[k] = x[k].solution_value()
    for k in z:
        if z[k].solution_value() > 1e-6:
            zs[k] = z[k].solution_value()
    return s.Objective().Value(), xs, zs, s.NumVariables(), s.NumConstraints()

- 이 문서를 쓰면서 gurobipy 14.0.0 으로 실행해 총비용 190 이 나오는 것을 확인했다.
"""
import gurobipy as gp
from gurobipy import GRB


def bfs_orientation(N, E):
    """6장: 출입구(0)에서 너비 우선 탐색. 높이 pos, 거리 dist, 이웃 목록 nbr를 돌려준다."""
    nbr = [[] for _ in range(N)]
    for u, v in E:
        nbr[u].append(v)
        nbr[v].append(u)
    pos, dist = [None] * N, [None] * N
    dist[0] = 0
    layer, position = [0], 0
    seen = {0}
    while layer:
        nxt = []
        for i in layer:
            pos[i] = position
            position += 1
            for j in nbr[i]:
                if j not in seen:
                    seen.add(j)
                    dist[j] = dist[i] + 1
                    nxt.append(j)
        layer = nxt
    return nbr, pos, dist


def build_model(prob):
    N, E, P, K, F = prob["N"], prob["E"], prob["P"], prob["K"], prob["F"]
    nbr, pos, dist = bfs_orientation(N, E)
    pred = {i: [j for j in nbr[i] if pos[j] < pos[i]] for i in range(1, N)}
    d = {(p, q): 0 for p in range(P) for q in range(p + 1, P)}
    for (o, dest), qty in K:
        d[o, dest] = qty

    m = gp.Model("roro")
    pairs = [(p, q) for p in range(P) for q in range(p + 1, P)]
    nodes = range(1, N)          # 칸 (출입구 제외)
    mid = range(1, P - 1)        # 첫 항구와 마지막 항구를 뺀 항구

    # --- 변수 ---
    x = m.addVars(((p, q, i) for (p, q) in pairs for i in nodes), vtype=GRB.BINARY, name="x")
    y = m.addVars(((p, i) for p in mid for i in range(N)), vtype=GRB.BINARY, name="y")
    z = m.addVars(((p, q, r) for p in range(P) for q in range(p + 1, P) for r in range(q + 1, P)),
                  vtype=GRB.INTEGER, lb=0, name="z")

    # --- 목적함수: 구간 하나 = 선적 경로 + 하역 경로 ---
    m.setObjective(gp.quicksum(2 * (F + dist[i]) * x[p, q, i] for (p, q) in pairs for i in nodes),
                   GRB.MINIMIZE)

    # --- 제약 ① 수요 ---
    for (p, q) in pairs:
        m.addConstr(
            gp.quicksum(x[p, q, i] for i in nodes)
            == d[p, q]
            - gp.quicksum(z[p, r, q] for r in range(p + 1, q))      # (p,q)가 r에서 쪼개져 없어짐
            + gp.quicksum(z[p, q, r] for r in range(q + 1, P))      # (p,r)이 q에서 쪼개진 앞 토막
            + gp.quicksum(z[r, p, q] for r in range(p)),            # (r,q)가 p에서 쪼개진 뒤 토막
            name=f"demand_{p}_{q}")

    for q in mid:
        m.addConstr(y[q, 0] == 1, name=f"gate_{q}")                                   # ⑥
        for i in nodes:
            staying = gp.quicksum(x[p, r, i] for p in range(q) for r in range(q + 1, P))
            m.addConstr(staying <= 1 - y[q, i], name=f"occupied_{q}_{i}")              # ②
            m.addConstr(gp.quicksum(x[p, q, i] for p in range(q)) <= y[q, i],
                        name=f"unload_{q}_{i}")                                       # ③
            m.addConstr(gp.quicksum(x[q, r, i] for r in range(q + 1, P)) <= y[q, i],
                        name=f"load_{q}_{i}")                                         # ④
            m.addConstr(y[q, i] <= gp.quicksum(y[q, j] for j in pred[i]),
                        name=f"propagate_{q}_{i}")                                    # ⑤
    return m, x, y, z
