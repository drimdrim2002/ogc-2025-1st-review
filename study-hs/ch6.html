선형계획 ①: 그림으로 풀기

2장에서 변수가 실수이고 식이 모두 1차식인 최적화 문제를 선형계획(LP)이라고 불렀습니다. 변수가 정수여야 하는 문제와 달리, 소수 답을 허용하면 문제를 그림으로 풀 수 있고 아주 커져도 빠르게 풀 수 있습니다. 이 장에서는 변수가 둘인 LP를 좌표평면에 그려서 푸는 법을 배우고, 왜 LP에서는 "모퉁이만 살피면 되는지"와 "동네 최고가 왜 전체 최고인지"를 이해합니다.

  • 미리 알아야 할 것. 2장(결정변수, 제약, 목적함수, 가능해, 가능 영역, 최적해, 트럭 예와 공방 예), 고등학교의 직선의 방정식, 연립일차방정식, 부등식의 영역. (3장의 벡터와 행렬은 쓰지 않습니다.)
  • 이 장을 읽고 나면. 변수가 둘인 LP의 가능 영역과 같은 값 직선(등고선)을 그려 최적해를 찾을 수 있고, LP의 세 결말(최적·불능·비유계)과 볼록의 뜻을 설명할 수 있습니다.

부등식의 영역과 선형계획

2장에서 만난 공방 예를 다시 꺼냅니다. 책상 x1개와 의자 x2개를 만들어 이익을 가장 크게 하려 합니다. 단, 여기서는 1.5개처럼 소수 개수도 만들 수 있다고 둡니다.

최대화  5x1 + 4x2목적함수: 이익(만 원)
제약    6x1 + 4x2 ≤ 24목재 제한
         x1 + 2x2 ≤ 6작업 시간 제한
         x1 ≥ 0,  x2 ≥ 0개수는 0 이상
정의 선형계획(linear programming, LP)은 결정변수가 실수이고, 목적함수와 제약이 모두 1차식(1차 등식 또는 1차 부등식)인 최적화 문제입니다.

변수가 x1과 x2 둘뿐이므로, 제약을 모두 지키는 점 (x1, x2)를 좌표평면에 색칠해 볼 수 있습니다.

좌표평면에서 직선 ax + by = c는 평면을 두 반쪽으로 나눕니다. 한쪽이 ax + by ≤ c의 영역이고, 반대쪽이 ax + by ≥ c의 영역입니다. 어느 쪽인지는 직선 밖의 쉬운 점 하나(예: 원점 (0, 0))를 대입해 보면 바로 알 수 있습니다.

공방 예의 부등식 넷을 하나씩 그려 겹치는 곳을 찾습니다. 원점 (0, 0)을 넣으면 6·0 + 4·0 = 0 ≤ 24이고 0 + 2·0 = 0 ≤ 6이므로, 두 직선 모두 원점이 있는 쪽입니다. x1 ≥ 0, x2 ≥ 0까지 합치면 1사분면 안에 사각형이 생깁니다. 이것이 공방 예의 가능 영역입니다.

같은 값 직선(등고선)을 밀어 올리기

가능 영역 안의 점은 무한히 많습니다. 그중 이익 z = 5x1 + 4x2가 가장 큰 점은 어디일까요? 이익이 같은 점들을 모아 직선으로 그려 봅니다.

예를 들어 이익이 딱 10만 원이 되는 점들을 모으면 5x1 + 4x2 = 10입니다. (2, 0), (1, 5/4), (0, 5/2)처럼 이 직선 위의 점은 어느 것이나 이익이 10입니다. 지도에서 높이가 같은 곳을 이은 선을 등고선이라고 부르듯, 목적함수 값이 같은 점들을 이은 직선을 같은 값 직선 또는 등고선(level line)이라고 부릅니다.

z를 10에서 15, 20, 21로 키우면 직선 5x1 + 4x2 = z는 어떻게 움직일까요? x2 = −(5/4)x1 + z/4이므로 기울기는 −5/4로 변하지 않고, y절편 z/4만 커집니다. 즉, 등고선은 기울기를 유지한 채 오른쪽 위로 평행 이동합니다.

그림에서 보듯이 z = 21일 때 등고선은 가능 영역의 꼭짓점 (3, 3/2) 한 점에만 닿습니다. 이 점은 두 직선 6x1 + 4x2 = 24와 x1 + 2x2 = 6을 연립해 풀어서 구합니다. 아래 식의 4배를 위 식에서 빼거나 두 식을 적당히 맞춰 풀면 6x1 + 4x2 = 24, 2x1 + 4x2 = 12에서 4x1 = 12, 곧 x1 = 3이고 x2 = 3/2입니다. z를 21보다 조금이라도 크게 하면 등고선이 가능 영역 밖으로 벗어나므로, 21이 가장 큰 이익입니다.

정의 변수가 둘인 LP에서 가능 영역과 같은 값 직선(등고선)을 좌표평면에 그려, 등고선을 목적함수가 좋아지는 방향으로 평행 이동해 최적해를 찾는 방법을 도해법(graphical method)이라고 합니다.

그렇다면 트럭 예에서 "트럭 대수는 정수"라는 조건을 잠깐 지우면 어떨까요? 2장에서 다룬 트럭 예의 LP 버전은 다음과 같습니다.

최소화  10x + 7y트럭 값(만 원)
제약    9x + 5y ≥ 30,  x ≥ 0,  y ≥ 0소수 대수 허용

가능 영역은 직선 9x + 5y = 30의 오른쪽 위 전체입니다. 공방 예처럼 사각형으로 닫혀 있지 않고 위와 오른쪽으로 끝없이 뻗어 있습니다. 하지만 이번에는 최소화이므로 등고선 10x + 7y = z를 값이 작아지는 왼쪽 아래로 밉니다. 경계의 꼭짓점은 (10/3, 0)과 (0, 6) 둘뿐입니다. 값을 계산하면 (10/3, 0)에서 10·(10/3) + 0 = 100/3 ≈ 33.33이고, (0, 6)에서 42입니다. 따라서 왼쪽 아래로 밀던 등고선이 가장 나중에 닿는 곳은 (10/3, 0)이고, 최적값은 100/3 ≈ 33.33입니다.

2장에서 정수 조건이 있을 때의 최적값은 (3, 1)의 37이었습니다. 정수 조건을 지우니 값이 37에서 33.33으로 내려갔습니다. (물론 실제로 큰 트럭을 3.33대 부를 수는 없으므로, 이 값 33.33은 "정수 답을 아무리 잘 골라도 33.33보다 쌀 수는 없다"는 기준선이 됩니다. 13장에서 이 사실을 크게 씁니다.)

꼭짓점 정리: 모퉁이만 보면 된다

도해법을 쓸 때 눈치챘을 것입니다. 공방 예에서도, 트럭 예에서도 최적해는 가능 영역의 한가운데가 아니라 뾰족한 모퉁이(꼭짓점)에 있었습니다.

정의 가능 영역의 점 가운데, 영역 안의 다른 두 점을 이은 선분의 중간에 놓일 수 없는 점을 꼭짓점(vertex)이라고 합니다.

사각형의 네 모퉁이가 꼭짓점인 이유를 이 정의로 확인해 봅니다. 변 위의 가운데 점 (2, 0)은 같은 영역 안의 (1, 0)과 (3, 0)을 이은 선분의 한가운데에 있으므로 꼭짓점이 아닙니다. 영역 안쪽의 점 (1, 1)도 양옆 점을 이은 선분 위에 놓이므로 꼭짓점이 아닙니다. 반면 (3, 3/2)는 어느 두 점의 선분 한가운데에도 둘 수 없으므로 꼭짓점입니다.

핵심 사실 (꼭짓점 정리) LP에 최적해가 있다면, 가능 영역의 꼭짓점 가운데에도 반드시 최적해가 있습니다.

등고선을 목적함수가 좋아지는 쪽으로 끝까지 밀어 보면, 마지막으로 걸리는 곳은 평평한 면이나 모퉁이입니다. 한 점(모퉁이)에만 걸리면 그 점이 바로 꼭짓점입니다. 만약 등고선이 영역의 변 하나와 평행해서 변 전체가 한꺼번에 마지막으로 걸린다면 어떨까요? 그래도 그 변의 양 끝 점은 꼭짓점이고, 그 두 꼭짓점 역시 최적해입니다.

실제로 공방 예에서 목적함수를 6x1 + 4x2로 바꾸면, 등고선 기울기가 목재 제약 직선과 같아져 변 (4, 0)–(3, 3/2) 위의 모든 점이 값 24로 최적해가 됩니다. 이처럼 최적해가 무수히 많을 때도 양 끝 꼭짓점 (4, 0)과 (3, 3/2)가 여전히 최적해에 포함됩니다.

이 사실이 왜 대단할까요? 가능 영역 안에는 점이 무한히 많지만, 꼭짓점은 몇 개 되지 않기 때문입니다. 아래 Python 코드는 공방 예의 경계선 네 개가 서로 만나서 만드는 교점 후보 여섯 개를 검사해, 가능 영역 안의 꼭짓점을 고르고 가장 큰 이익을 찾습니다.

pts = [[0, 0], [4, 0], [6, 0], [0, 3], [0, 6], [3, 1.5]]
best_z = -1
best_p = []
for p in pts:
    x1 = p[0]
    x2 = p[1]
    ok = (6 * x1 + 4 * x2 <= 24) and (x1 + 2 * x2 <= 6) and (x1 >= 0) and (x2 >= 0)
    if ok:
        z = 5 * x1 + 4 * x2
        print(p, "가능, 이익 =", z)
        if z > best_z:
            best_z = z
            best_p = p
    else:
        print(p, "영역 밖")
print("최적:", best_p, best_z)

[0, 0] 가능, 이익 = 0
[4, 0] 가능, 이익 = 20
[6, 0] 영역 밖
[0, 3] 가능, 이익 = 12
[0, 6] 영역 밖
[3, 1.5] 가능, 이익 = 21.0
최적: [3, 1.5] 21.0
  • 1행 네 직선(x1 = 0, x2 = 0, 6x1 + 4x2 = 24, x1 + 2x2 = 6)이 둘씩 만나서 만드는 교점 여섯 개입니다.
  • 2~3행 지금까지 찾은 가장 큰 이익 best_z와 그때의 점 best_p를 저장할 변수입니다.
  • 4~7행 점마다 네 개의 제약을 모두 지키는지 확인해 참이면 ok에 넣습니다.
  • 8~15행 가능 영역 안의 점(꼭짓점)이면 이익 5 * x1 + 4 * x2를 계산하고 최대를 갱신합니다. (6, 0)과 (0, 6)은 영역 밖이라 버려집니다.
  • 16행 가장 좋은 꼭짓점 [3, 1.5]와 최적값 21.0을 출력합니다.

다음 장에서는 3장의 행렬과 연립방정식을 써서, 그림을 못 그릴 때도 이 교점(꼭짓점)들을 계산으로 찾아내는 방법을 배웁니다.

대학 교재에서는 가능 영역처럼 1차 부등식 몇 개가 겹쳐 만든 영역을 다면체(polyhedron), 다면체가 사방으로 막혀 있어 무한히 뻗지 않는 경우를 다포체(polytope)라고 부릅니다. 또 꼭짓점을 극점(extreme point)이라고 부릅니다. 유계인 다포체 안의 모든 점은 꼭짓점들의 가중평균(볼록 조합)으로 쓸 수 있으므로, 1차식의 최댓값과 최솟값은 반드시 꼭짓점 가운데서 나옵니다.

2부 · 세 가지 결말과 볼록

LP의 세 가지 결말: 최적·불능·비유계

모든 LP에 최적해가 있는 것은 아닙니다. 어떤 LP를 풀든 결말은 다음 셋 중 하나입니다.

  • 최적해 있음. 공방 예나 트럭 LP처럼 가능 영역이 비어 있지 않고, 목적함수 쪽이 막혀 있어 가장 좋은 값이 존재합니다.
  • 불능(infeasible). 제약을 모두 지키는 점이 하나도 없습니다. 예를 들어 x1 + x2 ≤ 2와 x1 + x2 ≥ 4를 동시에 요구하면 겹치는 영역이 비어 있습니다.
  • 비유계(unbounded). 가능해는 있지만 목적함수를 끝없이 좋게 만들 수 있어 최적값이 없습니다. 예를 들어 트럭 예의 영역(9x + 5y ≥ 30, x, y ≥ 0)에서 비용을 최대화하라고 하면, 트럭을 한없이 많이 부를수록 값이 커져서 끝이 없습니다.

비유계는 가능 영역만으로 결정되지 않고, 영역과 목적함수의 짝에 따라 갈립니다. 트럭 예의 영역은 위와 오른쪽으로 열려 있지만, 비용 10x + 7y를 최소화하면 왼쪽 아래가 막혀 있어 ①(최적해 있음)이 됩니다. 반대로 같은 영역에서 최대화를 하면 ③(비유계)이 됩니다.

왜 LP에서는 < 나 > (등호가 빠진 부등호)를 쓰지 않을까요? 만약 "최대화 x, 제약 x < 5"라는 문제를 허용하면, x = 4.9, 4.99, 4.999, …처럼 5에 한없이 다가갈 수는 있지만 x = 5는 넣을 수 없어 "가장 큰 값"이 존재하지 않습니다. LP에서는 ≤, ≥, =만 허용하므로 경계가 영역에 포함되고, 그래서 위의 세 결말 말고 네 번째 애매한 경우가 생기지 않습니다.

볼록, 그리고 「동네 최고 = 전체 최고」

이 장 처음에 "소수 답을 허용하는 LP는 아주 커져도 빠르게 풀 수 있다"고 말했습니다. 그 비결은 가능 영역의 모양에 있습니다.

정의 어떤 영역 안의 두 점 A와 B를 아무렇게나 골라도, 두 점을 잇는 선분이 통째로 그 영역 안에 들어 있으면 그 영역은 볼록(convex)하다고 합니다.
핵심 사실 LP의 가능 영역은 언제나 볼록합니다. 그래서 LP에서는 "동네 최고가 곧 전체 최고"입니다.

먼저 왜 볼록할까요? 직선 하나가 나누는 반쪽 평면(ax1 + bx2 ≤ c)은 볼록합니다. 두 점 A, B가 모두 c 이하이면, 두 점 사이의 중간 점들은 값이 그 사이 어딘가에 있으므로 역시 c 이하이기 때문입니다. 그리고 볼록한 영역들을 여러 개 겹쳐도(교집합) 여전히 볼록합니다. 두 점이 겹친 곳에 있으면 선분도 각각의 영역 안에 모두 들어가기 때문입니다.

이제 왜 "동네 최고 = 전체 최고"가 될까요? 등산을 떠올려 봅니다. 안개가 낀 산에서 내 발밑 주변만 보일 때, 한 걸음 내디딜 수 있는 모든 방향이 다 내리막이라면 나는 지금 꼭대기에 있을까요? 산봉우리가 여러 개라면 못 믿습니다. 저 멀리 구름 너머에 더 높은 봉우리가 있을 수 있으니까요. 하지만 봉우리가 하나뿐인 완만한 언덕이라면 주변이 다 내리막인 곳이 곧 전체에서 가장 높은 곳입니다.

LP가 바로 그 완만한 언덕입니다. 지금 있는 점 A보다 더 좋은 점 B가 저 멀리 있다고 합시다. 가능 영역이 볼록하므로 A와 B를 이은 선분은 통째로 가능 영역 안에 있습니다. 목적함수는 1차식이므로, 이 선분을 따라 A에서 B 쪽으로 아주 조금만(예를 들어 1%만) 움직여도 값은 A와 B의 값 사이에서 A보다 좋아집니다. 즉, 멀리 더 좋은 점이 있다면 반드시 내 바로 옆(동네)에도 더 좋은 점이 있습니다. 뒤집어 말하면, 내 동네에 더 좋은 점이 하나도 없다면 멀리에도 더 좋은 점이 있을 수 없습니다.

이 한 가지 성질 때문에 LP가 쉽습니다. 아무 꼭짓점에서 시작해 더 좋은 이웃 꼭짓점으로 한 걸음씩 옮겨 가다가, 더 좋은 이웃이 없는 꼭짓점에 닿으면 "여기가 전체에서 최고"라고 자신 있게 멈출 수 있습니다. 이것이 8장에서 배울 심플렉스법의 원리입니다. 반대로 정수계획은 격자점이라 볼록하지 않고, 옆 격자점을 다 확인해도 멀리 더 좋은 정수점이 숨어 있을 수 있습니다.

가이드와 연결

가이드에서 트럭 예의 정수 조건을 지우고 직선을 그려 푸는 그림이 바로 이 장의 도해법입니다. 트럭 예의 LP 답 (3.33, 0)과 최적값 33.33은 직선 10x + 7y = z를 왼쪽 아래로 밀다가 영역의 모퉁이 (10/3, 0)에 닿은 결과입니다.

가이드는 "LP는 빠르고, 답은 항상 꼭짓점에 있다"고 요약합니다. 「답은 항상 꼭짓점에 있다」는 이 장의 꼭짓점 정리이고, 「빠르다」의 뿌리는 가능 영역이 볼록해서 동네 최고가 곧 전체 최고가 된다는 점에 있습니다.

가이드가 모형 규칙으로 "1차식만 쓰고, ≤, ≥, =만 쓸 수 있다"고 말하는 이유도 이 장에서 보았습니다. 1차 부등식(등호 포함)을 겹쳐야 가능 영역이 경계를 품은 볼록한 다각형(다면체)이 되고, 그래야 꼭짓점 정리와 세 결말이 깔끔하게 성립하기 때문입니다.

  • LP는 변수가 실수이고 목적함수와 제약이 모두 1차식인 문제입니다.
  • 변수가 둘인 LP는 부등식의 영역(가능 영역)과 같은 값 직선(등고선)을 그려 푸는 도해법으로 풀 수 있습니다.
  • LP의 결말은 최적해 있음, 불능(가능해 없음), 비유계(끝없이 좋아짐) 셋 중 하나입니다.
  • LP에 최적해가 있으면 꼭짓점 가운데에도 반드시 최적해가 있습니다(꼭짓점 정리).
  • LP의 가능 영역은 언제나 볼록하고, 따라서 동네 최고가 곧 전체 최고입니다.

연습문제

최대화 3x1 + 2x2, 제약 2x1 + x2 ≤ 8, x1 + x2 ≤ 5, x1 ≥ 0, x2 ≥ 0을 도해법으로 푸세요. 네 꼭짓점의 좌표와 목적함수 값을 모두 구하세요.

가능 영역의 경계는 x1 = 0, x2 = 0, 2x1 + x2 = 8, x1 + x2 = 5입니다. 두 경계선의 교점은 (2x1 + x2) − (x1 + x2) = 8 − 5에서 x1 = 3, x2 = 2입니다. 네 꼭짓점은 (0, 0) → 0, (4, 0) → 12, (3, 2) → 13, (0, 5) → 10입니다. 등고선 3x1 + 2x2 = z를 오른쪽 위로 밀면 마지막에 (3, 2)에서 만나고 최적값은 13입니다.

트럭 예(9x + 5y ≥ 30, x, y ≥ 0, 소수 허용)에서 트럭 값이 바뀌어 목적함수가 최소화 12x + 5y가 되었습니다. 톤당 값만 보면 작은 트럭이 1톤당 1만 원, 큰 트럭이 1.33만 원입니다. 도해법으로 최적해와 최적값을 구하세요.

가능 영역의 꼭짓점은 그대로 (10/3, 0)과 (0, 6) 둘입니다. (10/3, 0)에서 값은 12·(10/3) = 40이고, (0, 6)에서 값은 5·6 = 30입니다. 따라서 등고선 12x + 5y = z를 왼쪽 아래로 밀면 마지막에 닿는 꼭짓점은 (0, 6)이고 최적값은 30입니다.

다음 문제들은 최적해 있음, 불능, 비유계 중 어느 결말인가요? (가) 최소화 x + y, 제약 x + y ≥ 2, x − y ≤ 1, x, y ≥ 0 (나) 같은 영역에서 최대화 x + y (다) 최대화 2x + y, 제약 x + y ≤ 3, x ≥ 4, y ≥ 0.

(가) 최적해 있음: x + y ≥ 2이므로 값은 2 이상이고, (0, 2)나 (1.5, 0.5)에서 2가 됩니다(변 (0, 2)–(1.5, 0.5) 전체가 최적). (나) 비유계: x = 0으로 두고 y를 얼마든지 크게 하면 모든 제약을 지키며 x + y → ∞가 됩니다. (다) 불능: x ≥ 4이고 y ≥ 0이면 x + y ≥ 4인데, x + y ≤ 3과 동시에 성립할 수 없습니다.

공방 예에서 이익 식이 5x1 + 4x2가 아니라 6x1 + 4x2로 바뀌면 최적해와 최적값이 어떻게 되나요? 꼭짓점 정리와 어긋나지 않는지 설명하세요.

등고선 6x1 + 4x2 = z가 첫째 제약 직선 6x1 + 4x2 = 24와 평행합니다. 따라서 (4, 0)과 (3, 3/2)를 잇는 변 위의 모든 점이 값 24로 최적해가 됩니다. 최적해는 무수히 많지만, 그 가운데 꼭짓점 (4, 0)과 (3, 3/2)가 들어 있으므로 「최적해가 있다면 꼭짓점 가운데에도 최적해가 있다」는 꼭짓점 정리와 어긋나지 않습니다.

집합 {(x, y) : x ≥ 0, y ≥ 0, y ≥ x2}과 집합 {(x, y) : x = 0 또는 y = 0, x ≥ 0, y ≥ 0}은 각각 볼록인가요? 정의를 써서 판정하세요.

첫째 집합은 포물선 y = x2의 위쪽(내부)으로, 두 점을 이은 선분이 영역 밖으로 나가지 않으므로 볼록입니다(단, 경계가 곡선이라 LP의 다각형 영역은 아닙니다). 둘째 집합은 양의 x축과 양의 y축을 합친 L자 모양입니다. x축 위의 점 (2, 0)과 y축 위의 점 (0, 2)를 이은 선분의 가운데 점 (1, 1)은 두 축 어디에도 없으므로 볼록이 아닙니다.

본문의 Python 코드에서 목적함수가 최대화 5x1 + 4x2 대신 최대화 x1 + 3x2로 바뀌면, 9행과 마지막 출력은 어떻게 바뀔까요?

9행을 z = x1 + 3 * x2로 바꾸면 네 꼭짓점의 값은 (0, 0) → 0, (4, 0) → 4, (0, 3) → 9, (3, 1.5) → 7.5가 됩니다. 따라서 최적은 [0, 3] 9가 됩니다.
