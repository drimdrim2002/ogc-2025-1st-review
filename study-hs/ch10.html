내부점법과 크로스오버

8장의 심플렉스법은 가능 영역의 겉면(모서리)을 따라 꼭짓점에서 꼭짓점으로 걸어갔습니다. 이 장의 내부점법(interior point method)은 정반대로 가능 영역의 안쪽을 가로질러 최적점에 다가갑니다. 솔버에서는 흔히 배리어(barrier)라고 부릅니다.

  • 미리 알아야 할 것. 6장(가능 영역, 꼭짓점, 최적면), 8장(심플렉스법, 기저, 이어 풀기), 9장(쌍대 문제, 상보 여유성, 쌍대 간격, 쌍대 심플렉스), 고등학교 미적분(ln x의 도함수가 1/x이고 x → 0+일 때 ln x → −∞라는 사실, 극값에서 f′(x) = 0, 접선의 방정식).
  • 이 장을 읽고 나면. 장벽 함수와 중심 경로의 뜻을 이해하고 뉴턴법 한 걸음을 계산할 수 있으며, 배리어가 꼭짓점이 아닌 답을 낼 수 있는 이유와 분지한계법 때문에 크로스오버가 필요한 이유를 설명할 수 있습니다.
1부 · 벽을 밀어내는 벌점: 장벽 함수와 중심 경로

경계에 다가가면 무한히 비싸지는 벽

전기가 흐르는 울타리로 둘러싸인 운동장을 걸어간다고 상상해 봅시다. 안쪽에 있을 때는 안전하지만, 울타리에 가까워질수록 강한 경고음이 울립니다. 이 경고음(벌점)을 비용에 더해 두면, 비용을 줄이려는 해는 결코 울타리에 닿거나 밖으로 나가지 못합니다.

자연로그 ln t는 t > 0에서만 정의되고, t → 0+일 때 ln t → −∞로 떨어집니다. 따라서 부호를 바꾼 −ln t는 경계 t = 0에 가까워질수록 +∞로 치솟습니다. 또 도함수는 (ln t)′ = 1/t이고, 합성함수의 미분법으로 (ln(3 − x))′ = −1/(3 − x)입니다.

가장 단순한 1변수 예로 직접 계산해 봅니다.

최소화  x원래 답은 당연히 x = 1
제약    1 ≤ x ≤ 3

제약마다 "벽에서 떨어진 여유"를 적습니다. x − 1 ≥ 0과 3 − x ≥ 0입니다. 두 여유가 0에 가까워질수록 커지는 벌점 −ln(x − 1) − ln(3 − x)에 양수 μ(뮤)를 곱해서 목적함수에 더합니다.

Bμ(x) = x − μ ln(x − 1) − μ ln(3 − x)   (1 < x < 3)
정의 제약 gi(x) ≥ 0들에 대해 장벽 함수 −μ Σi ln gi(x)를 목적함수에 더한 문제를 로그 장벽 문제라고 합니다(모든 gi(x) > 0인 안쪽 점, 곧 내부점에서만 정의). 이때 μ > 0을 장벽 매개변수(barrier parameter)라고 하고, μ마다 장벽 문제의 최소점 x(μ)들을 이어 만든 곡선을 중심 경로(central path)라고 합니다.

위 예에서 Bμ(x)가 가장 작아지는 점에서는 도함수가 0입니다.

Bμ′(x) = 1 − μ/(x − 1) + μ/(3 − x) = 0

양변에 (x − 1)(3 − x)를 곱해 정리하면 x² − (4 + 2μ)x + (3 + 4μ) = 0이고, 근의 공식으로 1 < x < 3 안의 근을 고르면 다음과 같습니다.

μ가 클 때는 벌점이 강해서 양쪽 벽의 한가운데(2, 해석적 중심) 근처에 머물고, μ를 줄일수록 원래 목적함수 x가 이겨 진짜 답 1로 다가갑니다. 그러면서도 x(μ)는 언제나 1보다 큽니다. 경계에 닿지 않고 안쪽에서 다가갑니다.

중심 경로 위에서는 쌍대 간격이 정확히 보인다

9장에서 원시 가능해와 쌍대 가능해를 함께 갖고 있으면 최적값이 그 사이에 갇힌다고 했습니다. 놀랍게도 중심 경로 위의 점은 쌍대 가능해를 공짜로 만들어 줍니다.

위 예 최소화 x, x ≥ 1, −x ≥ −3의 쌍대 문제를 9장의 규칙으로 적으면 다음과 같습니다(x의 부호가 자유이므로 쌍대 제약은 등식입니다).

최대화  u1 − 3u2원시 값 x의 하한
제약    u1 − u2 = 1,   u1, u2 ≥ 0

이제 u1 = μ/(x − 1), u2 = μ/(3 − x)라고 정해 봅시다. 두 여유가 양수이므로 u1, u2 > 0이고, 앞 절의 최소점 조건 1 − μ/(x − 1) + μ/(3 − x) = 0이 바로 u1 − u2 = 1입니다! 즉 (u1, u2)가 저절로 쌍대 가능해가 됩니다. 게다가 이 식을 고쳐 쓰면

u1 × (x − 1) = μ,   u2 × (3 − x) = μ

입니다. 9장의 상보 여유성은 「여유 × 가격 = 0」이었습니다. 중심 경로는 그것을 「여유 × 가격 = μ」로 모두 똑같이 느슨하게 만든 것입니다. 따라서 원시 값과 쌍대 값의 차이(쌍대 간격)를 계산하면

x − (u1 − 3u2) = u1(x − 1) + u2(3 − x) = μ + μ = 2μ

가 됩니다. 장벽 항이 붙은 부등식이 k개인 LP라면 쌍대 간격은 정확히 kμ입니다. 실제로 숫자를 넣어 보면 이렇습니다.

2부 · 뉴턴법과 공방 예의 중심 경로

뉴턴법: 접선으로 근 찾기

앞의 1변수 예에서는 2차방정식 근의 공식으로 x(μ)를 바로 풀었지만, 변수가 수만 개인 LP에서는 공식으로 풀 수 없습니다. 대신 도함수 g(x) = Bμ′(x) = 0을 만족하는 근을 조금씩 찾아가는 뉴턴법을 씁니다.

미분가능한 함수 y = g(x) 위의 점 (x0, g(x0))에서 그은 접선의 방정식은 y − g(x0) = g′(x0)(x − x0)입니다. 이 접선이 x축(y = 0)과 만나는 점을 구하면 x = x0 − g(x0) / g′(x0)입니다.

정의 뉴턴법(Newton's method)은 현재 점 x에서 g(x)의 접선이 0이 되는 자리 x새 = x − g(x) / g′(x)로 옮겨 가는 것을 반복해 g(x) = 0의 근을 찾는 방법입니다.

앞의 예에서 g(x) = 1 − μ/(x − 1) + μ/(3 − x)를 한 번 더 미분하면 g′(x) = μ/(x − 1)² + μ/(3 − x)²입니다. μ = 1의 중심 x = 1.585786에서 출발해, μ = 0.5의 중심(1.381966)을 뉴턴법으로 찾아가 봅니다.

그래서 실제 내부점법은 μ를 한 번에 조금씩만 줄이고(예: 절반씩), 매번 이전 중심 근처에서 뉴턴 걸음을 몇 번 밟아(영역 밖으로 나가려 하면 보폭을 절반씩 줄여 가며) 새 중심을 따라갑니다. 이 전체 과정을 Python으로 16줄만 적어 실행해 봅니다.

x = 2.0
mu = 1.0
for round_no in range(6):
    for i in range(5):
        g = 1 - mu / (x - 1) + mu / (3 - x)
        gp = mu / ((x - 1) * (x - 1)) + mu / ((3 - x) * (3 - x))
        alpha = 1.0
        nx = x - alpha * g / gp
        while nx <= 1 or nx >= 3:
            alpha = alpha / 2
            nx = x - alpha * g / gp
        x = nx
    print("mu =", mu, "x =", round(x, 6), "간격 =", 2 * mu)
    mu = mu / 2

  • 3~4행 mu를 6번 줄여 가며, 각 mu마다 뉴턴 걸음을 5번씩 밟습니다.
  • 5~6행 도함수 g = Bμ′(x)와 이계도함수 gp = Bμ″(x)를 계산합니다.
  • 7~12행 새 점 nx가 영역 (1, 3)을 벗어나면 보폭 alpha를 절반씩 줄여 안쪽에 머물게 한 뒤 옮깁니다.
  • 13~14행 현재 mu와 x, 그리고 쌍대 간격 2 * mu를 출력한 뒤 mu를 절반으로 줄입니다.

변수가 n개인 LP에서는 1계 도함수가 기울기 벡터, 2계 도함수가 n × n 대칭 행렬(헤세 행렬)이 됩니다. 그래서 뉴턴 걸음 한 번은 나눗셈 대신 그 대칭 행렬을 계수로 하는 연립방정식 하나를 푸는 일입니다. 실제 솔버는 원시 변수와 쌍대 변수를 함께 움직이며 「여유 × 가격 = μ」 식에 뉴턴법을 적용하는 원시–쌍대(primal-dual) 내부점법을 씁니다.

3부 · 꼭짓점이 아닌 답과 크로스오버

최적해가 여럿이면 배리어는 한가운데로 간다

7장에서 LP의 최적해가 꼭짓점 하나가 아니라 모서리 전체(최적면)일 수 있다고 했습니다. 최적해가 꼭짓점 하나뿐이면 배리어도 μ → 0일 때 그 꼭짓점으로 다가갑니다. 그런데 최적해가 여럿이면 사정이 달라집니다.

최소화  y최적해: 아래 변 전체 (0 ≤ x ≤ 1, y = 0)
제약    0 ≤ x ≤ 1,   0 ≤ y ≤ 1

장벽 함수는 y − μ[ln x + ln(1 − x) + ln y + ln(1 − y)]입니다. 목적함수에 x가 없으므로, x는 오직 장벽 항 −ln x − ln(1 − x)만 가장 작게 만들면 됩니다. x로 미분해 0으로 두면 −1/x + 1/(1 − x) = 0이므로 μ와 상관없이 항상 x = 1/2입니다. 한편 y(μ)는 1부와 같은 계산으로 0을 향해 내려갑니다(μ = 1, 0.1, 0.01에서 0.382, 0.090, 0.0099).

따라서 중심 경로는 수직선 x = 1/2을 따라 내려와 (1/2, 0)에 도착합니다. 이 점도 최적해이긴 하지만 모서리의 한가운데이지 꼭짓점이 아닙니다. 심플렉스법이라면 (0, 0)이나 (1, 0)을 냈을 것입니다.

핵심 사실 중심 경로는 μ → 0일 때 최적면의 한가운데(경계가 아닌 안쪽)로 수렴합니다. 게다가 배리어는 유한한 μ에서 멈추므로, 최적해가 하나뿐이어도 답은 꼭짓점 바로 앞의 안쪽 점입니다. 따라서 배리어의 답에는 7·8장의 기저가 붙어 있지 않습니다.

장벽 함수 −μ ln(여유)는 마지막 순간까지 모든 벽에서 가능한 한 멀리 떨어져 있으려 합니다. 목적함수가 최적면 안에서 어느 점이나 똑같이 취급하면, 장벽 함수만 남아 그 면의 한가운데를 고릅니다.

크로스오버: 안쪽 점을 꼭짓점으로

기저가 없는 답을 그대로 두면 안 될 때가 있습니다. 그래서 배리어 뒤에 마무리 작업 하나를 더 붙입니다.

정의 크로스오버(crossover)는 내부점법이 낸 답을 같은 목적값을 갖는 최적 꼭짓점, 곧 최적 기저로 바꾸는 후처리입니다.

원리는 직관적입니다. 위 정사각형 예에서 배리어가 낸 점 (1/2, 0)을 보세요. x = 1/2은 왼쪽 벽(0)에도 오른쪽 벽(1)에도 붙어 있지 않습니다. 게다가 x를 0 쪽으로 밀어도 목적값 y = 0은 전혀 나빠지지 않습니다. 그래서 x를 벽 x = 0에 닿을 때까지 밀어 붙이면 꼭짓점 (0, 0)을 얻습니다(1 쪽으로 밀어 (1, 0)을 얻을 수도 있습니다).

큰 문제에서도 마찬가지입니다. 벽에 붙지 않은 변수들을 목적값이 나빠지지 않는 방향으로 하나씩 벽(경계)까지 밀어 붙여서 꼭짓점을 만든 뒤, 심플렉스 피벗 몇 번으로 최적 기저를 완성합니다. 변수가 수만 개인 문제에서는 밀어 붙여야 할 변수가 많아서, 크로스오버가 배리어 본체만큼 시간을 먹기도 합니다.

왜 분지한계법은 꼭짓점을 필요로 하는가

크로스오버가 무겁다면 차라리 꺼 버리면 되지 않을까요? 여기서 8장의 「이어 풀기」와 9장의 「쌍대 심플렉스」가 결정적인 역할을 합니다.

13장의 분지한계법은 맨 처음 뿌리의 LP 완화를 푼 뒤, x ≤ 3이나 x ≥ 4 같은 제약을 하나씩 추가해 수많은 자식 가지를 만듭니다. 그 자식 LP들은 부모의 최적 기저에서 쌍대 심플렉스로 이어 풀면 몇 걸음 만에 끝납니다. 그런데 뿌리를 배리어로 풀고 크로스오버를 끄면, 뿌리 답에 기저가 없으니 자식들이 출발할 발판이 없습니다.

뿌리 LP가지 LP크로스오버대가
배리어쌍대 심플렉스 (이어 풀기)필수. 뿌리 답을 기저로 바꿔야 가지들이 이어 풀 수 있음크로스오버 시간
배리어배리어 (매번 처음부터)생략 가능. 기저를 물려줄 일이 없음가지마다 이어 풀기 없이 큰 계산을 반복 → 분지 전체가 느려질 수 있음
심플렉스쌍대 심플렉스 (이어 풀기)해당 없음. 처음부터 기저가 있음큰 뿌리 LP에서 느릴 수 있음

즉 "뿌리에서 크로스오버를 끈다"는 선택은 "가지들도 기저 없이(배리어로) 푼다"는 선택과 짝을 이룰 때만 앞뒤가 맞습니다. 덧붙여 14장에서 배울 Gomory 절단 역시 최적 기저(단체표의 한 줄)에서 만들어지므로, 기저가 없으면 이런 절단도 뽑아낼 수 없습니다.

4부 · 가이드와 연결

가이드의 어느 설명이 이 장의 내용인가

가이드의 「LP를 푸는 두 방법: 심플렉스와 배리어」. "영역의 안쪽을 가로질러 최적점으로 다가갑니다"는 1~2부의 중심 경로(공방 예 그림의 초록색 점들)입니다. "큰 LP에서 대체로 빠르고 여러 코어를 잘 씁니다"는 반복 수가 적고 매 반복 큰 행렬 연립방정식을 나눠 풀기 때문입니다. "답이 꼭짓점이 아닐 수 있고, 이어 풀기가 안 됩니다"와 "크로스오버로 꼭짓점을 얻은 뒤 그 아래 가지들을 심플렉스로 풉니다"는 3부의 내용 그대로입니다.

가이드의 솔버 설정(Method = 2, Crossover = 0). tryAgain은 뿌리 LP 완화를 배리어로 풀고(Method = 2) 크로스오버를 끄려고(Crossover = 0) 했습니다. 그런데 Gurobi 공식 문서의 단서에 따르면, 분지한계법의 뿌리에서는 Method와 NodeMethod(가지 LP를 푸는 방법)가 둘 다 배리어일 때만 크로스오버를 끌 수 있고, 그렇지 않으면 Crossover = 0 설정이 무시됩니다. 그 단서의 이론적 이유가 3부 표의 첫째 줄과 둘째 줄입니다.

가이드의 NoRel 휴리스틱 설명. 아주 큰 문제에서는 제한 시간 내내 LP를 풀지 않는 NoRel 휴리스틱을 쓰므로 배리어 설정이 실제로 동작할 일이 없고, 배리어 설정이 쓰이는 것은 그보다 작은 문제 쪽입니다.

  • 내부점법(배리어)은 경계 가까이에서 무한히 커지는 장벽 함수(−μ ln 여유)를 더해, 영역 안쪽의 중심 경로를 따라 최적점에 다가갑니다.
  • 중심 경로 위에서는 「여유 × 가격 = μ」가 성립해, 쌍대 간격 kμ가 바로 보입니다.
  • 각 μ의 중심점은 접선으로 근을 찾는 뉴턴법으로 쫓아가며, μ를 조금씩 줄이고 필요하면 보폭을 줄여 안쪽에 머뭅니다.
  • 배리어는 큰 LP와 다중 코어에 강하지만, 최적해가 여럿이면 최적면의 가운데로 가므로 기저(꼭짓점)가 없는 답을 냅니다.
  • 크로스오버는 그 답을 최적 꼭짓점으로 바꿔, 분지한계법의 자식 가지들이 쌍대 심플렉스로 이어 풀 수 있게 해 줍니다.

연습문제

1부의 예 최소화 x, 제약 1 ≤ x ≤ 3에서 Bμ′(x) = 0을 풀어 x(μ) = 2 + μ − √(1 + μ²)를 직접 유도해 보세요.

1 − μ/(x − 1) + μ/(3 − x) = 0 양변에 (x − 1)(3 − x)를 곱하면 (x − 1)(3 − x) − μ(3 − x) + μ(x − 1) = 0입니다. 전개하면 −x² + 4x − 3 + 2μx − 4μ = 0, 부호를 바꾸면 x² − (4 + 2μ)x + (3 + 4μ) = 0입니다. 근의 공식으로 x = (2 + μ) ± √((2 + μ)² − (3 + 4μ)) = 2 + μ ± √(1 + μ²)입니다. + 쪽은 2 + μ + √(1 + μ²) > 3이라 영역 밖이므로 − 쪽이 답입니다.

같은 예에서 μ = 0.5일 때 중심 x = 2.5 − √1.25 ≈ 1.381966에 대해 u1, u2와 쌍대 간격을 계산해 2μ = 1인지 확인하세요.

x − 1 ≈ 0.381966, 3 − x ≈ 1.618034입니다. u1 = 0.5 / 0.381966 ≈ 1.309017, u2 = 0.5 / 1.618034 ≈ 0.309017이므로 u1 − u2 = 1로 쌍대 가능해입니다. 쌍대 값은 u1 − 3u2 ≈ 1.309017 − 0.927051 = 0.381966이고, 쌍대 간격은 1.381966 − 0.381966 = 1.0 = 2μ입니다.

최소화 x, 제약 0 ≤ x ≤ 4에 대해 μ = 1일 때의 중심점과, μ → ∞일 때의 중심(해석적 중심)을 구하세요.

B1′(x) = 1 − 1/x + 1/(4 − x) = 0에 x(4 − x)를 곱하면 x(4 − x) − (4 − x) + x = 0, 즉 x² − 6x + 4 = 0입니다. 범위 (0, 4) 안의 근은 x = 3 − √5 ≈ 0.764입니다. μ → ∞이면 장벽 항 −ln x − ln(4 − x)만 남아 도함수 −1/x + 1/(4 − x) = 0을 만족하는 한가운데 x = 2가 됩니다.

3부의 정사각형 예(0 ≤ x ≤ 1, 0 ≤ y ≤ 1)에서 목적함수를 최소화 x + y로 바꾸면 중심 경로는 어디로 수렴할까요? 이때도 크로스오버가 필요할까요?

x와 y가 완전히 대칭이므로 x(μ) = y(μ) = [(1 + 2μ) − √(1 + 4μ²)] / 2가 되어 μ → 0일 때 꼭짓점 (0, 0)으로 수렴합니다. 최적해가 하나뿐이므로 극한점은 꼭짓점입니다. 하지만 실제 배리어는 유한한 μ에서 멈추므로 답은 (0, 0) 바로 앞의 안쪽 점이고, 정확한 기저를 얻으려면 (짧게라도) 크로스오버가 필요합니다.

2부의 μ = 1 중심 x = 1.585786에서 μ = 0.1로 한꺼번에 줄여 뉴턴 걸음 한 번을 계산하면 왜 영역 (1, 3) 밖으로 나가는지 직접 계산해 보세요.

x = 1.585786, μ = 0.1을 넣으면 g = 1 − 0.1/0.585786 + 0.1/1.414214 ≈ 0.9이고, g′ = 0.1/(0.585786)² + 0.1/(1.414214)² ≈ 0.291421 + 0.05 = 0.341421입니다. 따라서 x새 = 1.585786 − 0.9 / 0.341421 ≈ −1.050으로, x < 1인 영역 밖으로 나갑니다. 본문의 Python 코드에서는 while 문이 보폭 alpha를 절반씩 줄여 이를 막습니다.

"뿌리 LP는 배리어로 풀고, 크로스오버는 끄고, 가지 LP는 쌍대 심플렉스로 푼다"는 설정이 왜 앞뒤가 맞지 않나요?

쌍대 심플렉스로 자식 가지를 이어 풀려면 부모(뿌리)의 최적 기저가 있어야 합니다. 크로스오버를 끄면 배리어가 낸 답에 기저가 없으므로 첫 가지들이 출발할 수 없습니다. 따라서 뿌리에서 크로스오버를 끄려면 가지들도 기저가 필요 없는 배리어로 풀어야 합니다.

큰 LP에서 배리어가 심플렉스보다 여러 CPU 코어를 잘 쓰는 이유를 두 문장으로 설명해 보세요.

배리어는 반복 수가 적은 대신 반복마다 큰 대칭 행렬의 연립방정식을 풀고, 이 행렬 계산은 여러 조각으로 나누어 여러 코어에서 동시에 처리하기 좋습니다. 반면 심플렉스는 가벼운 피벗을 많이 수행하지만 각 피벗이 직전 피벗의 기저에 의존해 차례대로만 진행되므로 병렬로 나누기 어렵습니다.
