완화·한계·분지한계법: 답이 어디쯤 있는지 증명하며 찾기

메타휴리스틱은 좋은 해를 찾지만 "이 해가 최적에서 얼마나 먼가"는 말해 주지 못합니다. MIP 솔버는 해를 찾는 동시에 "어떤 해도 이보다 좋을 수 없다"는 한계를 계속 끌어올립니다. 이 장은 그 한계가 어디서 오는지(완화), 두 한계 사이의 거리(gap)를 어떻게 재는지, 그리고 그 둘을 이용해 탐색 공간을 잘라 내는 분지한계법이 왜 맞는지를 증명과 함께 설명합니다.

뒤쪽 절반은 실제 솔버가 분지한계법 위에 얹는 장치들(전처리, 탐색 순서, 원시 휴리스틱)의 원리입니다. 특정 솔버의 사용법이 아니라 "그 장치가 상한과 하한 중 무엇을 움직이는가"를 이해하는 것이 목표입니다. 절단평면은 10장, 라그랑지 완화와 열 생성은 11장에서 다룹니다.

이 장은 4장(LP와 꼭짓점), 6장(쌍대성, 쌍대 심플렉스), 8장(MIP의 정의)을 씁니다. 예는 처음부터 끝까지 가이드 3·4장의 트럭 문제입니다.

최소화  10x + 7y   제약  9x + 5y ≥ 30,  x, y ≥ 0,  x, y 정수트럭 문제 (만 원)
1부 · 완화와 하한

완화: 조건을 풀면 하한이 나온다

최소화 문제를 (X, f)로 적겠습니다. X는 가능해의 집합, f는 목적함수입니다. 최적값은 z* = min{f(x) : x ∈ X}입니다.

정의 9.1 문제 (XR, fR)이 (X, f)의 완화(relaxation)라는 것은 두 조건을 만족한다는 뜻이다.

(가) X ⊆ XR — 원래의 가능해는 모두 완화 문제에서도 가능해다.

(나) fR(x) ≤ f(x) ∀ x ∈ X — 원래의 가능해에서 완화 문제의 목적함수는 원래 값보다 크지 않다.

가장 흔한 경우는 fR = f로 두고 제약 일부를 지우는 것입니다. 정수 조건을 지우면 LP 완화(LP relaxation)입니다. 다른 제약을 지워도, 목적함수를 아래에서 어림해도 완화입니다. 11장의 라그랑지 완화는 (가)와 (나)를 함께 쓰는 완화입니다(제약을 지우는 대신 목적함수에 벌점을 더함).

정리 9.2 (완화의 하한 성질) zR = min{fR(x) : x ∈ XR}이라 하면

(1) zR ≤ z*.

(2) 완화 문제가 불능(XR = ∅)이면 원래 문제도 불능이다.

(3) 완화 문제의 최적해 xR이 X에 속하고 f(xR) = fR(xR)이면, xR은 원래 문제의 최적해다.

(1) 원래 문제의 최적해 x*는 (가)에 의해 XR에 있으므로 zR ≤ fR(x*) ≤ f(x*) = z*. 두 번째 부등호가 (나)입니다. (2) X ⊆ XR = ∅. (3) f(xR) = zR ≤ z*이고 xR ∈ X라서 z* ≤ f(xR)이므로 등호가 성립합니다. ∎

트럭 문제의 LP 완화는 정수 조건만 지운 LP이고, 그 최적해는 (x, y) = (10/3, 0), 값 100/3 ≈ 33.33입니다(4장). 정리 9.2 (1)에 의해 트럭 몇 대를 부르든 33.33만 원보다 쌀 수 없습니다. (3)은 분지한계법의 "이 가지는 끝났다" 판정의 근거입니다.

LP 완화의 하한은 쌍대성(6장)으로도 볼 수 있습니다. LP 완화의 쌍대 문제는 최대화 30u, 9u ≤ 10, 5u ≤ 7, u ≥ 0이고 해는 u = 10/9, 값 100/3입니다. 약쌍대 정리에 의해 쌍대 가능해 하나만 있어도 그 값은 LP 완화의 하한이고, 따라서 MIP의 하한입니다. 예를 들어 u = 1(9 ≤ 10, 5 ≤ 7을 지킴)을 고르면 "30만 원보다 싼 방법은 없다"는 증명서가 됩니다. 증명서는 LP를 끝까지 풀지 않아도 만들 수 있다는 점이 11장에서 다시 쓰입니다.

상한, 하한, gap

정의 9.3 최소화 MIP를 푸는 도중에

incumbent는 지금까지 찾은 가장 좋은 가능해이고, 그 값 UB를 상한 또는 원시 한계(primal bound)라 한다. 최적값 z* ≤ UB.

"어떤 가능해도 LB보다 좋을 수 없다"가 증명된 값 LB를 하한 또는 쌍대 한계(dual bound)라 한다. LB ≤ z*.

절대 gap = UB − LB, 상대 gap = (UB − LB) / |UB|.

최적값은 언제나 [LB, UB] 구간 안에 있습니다. 절대 gap이 0이면 incumbent가 최적임이 증명된 것입니다. "원시"는 원래 문제의 가능해에서 나온 한계, "쌍대"는 완화(그리고 그 쌍대 문제)에서 나온 한계라는 뜻입니다.

예: 최소화 문제에서 하한 100, 상한 108이면 최적값은 [100, 108] 안에 있고 절대 gap 8, 상대 gap 8/108 ≈ 7.41%입니다. "지금 해는 최적보다 많아야 7.41% 나쁘다"고 말할 수 있습니다(UB 기준). 상대 gap의 분모를 무엇으로 두는지는 솔버마다 다르며, 가이드 4장이 소개한 Gurobi의 정의는 |UB|를 씁니다.

두 멈춤 기준이 함께 있을 때

솔버는 보통 "절대 gap < εabs" 또는 "상대 gap < εrel" 중 하나라도 만족하면 멈춥니다. 상대 기준은 절대 기준으로 바꿔 생각할 수 있습니다. 상대 gap < εrel ⇔ UB − LB < εrel · |UB|. 즉 상대 기준은 "절대 gap이 εrel · |UB|보다 작으면"입니다. 따라서

실제로 쓰이는 문턱 = max(εabs, εrel · |UB|)

가이드 8장의 예를 계산해 봅니다. εabs = 2 − 0.001 = 1.999, εrel = 10−4, UB = 100,000이면 상대 쪽 문턱은 100,000 × 10−4 = 10이라 절대 쪽(1.999)보다 큽니다. 솔버는 UB − LB < 10, 곧 LB > 99,990이 되는 순간 멈춥니다. 그 순간 99,990 < z* ≤ 100,000까지만 증명되어 있으므로, 목적함수가 짝수뿐이라 해도 99,992, 99,994, 99,996, 99,998이라는 네 값이 아직 배제되지 않았습니다. 두 문턱이 같아지는 것은 |UB| · 10−4 = 1.999, 곧 UB = 19,990(대략 2만)일 때이고, 이보다 큰 문제에서는 상대 기준이 먼저 걸립니다. 가이드 8장의 「MIPGapAbs = 2 − TOL: 짝수만 나오는 목적함수」 절이 지적한 내용이 이 계산입니다.

2부 · 분지한계법

분지: 정수해를 잃지 않고 나누기

정의 9.4 문제 (X, f)를 분지(branching)한다는 것은 X = X1 ∪ X2 ∪ … ∪ Xk가 되도록 하위 문제 (Xi, f)들을 만드는 것이다. 그러면 z* = mini z*i이다.

LP 완화의 해에서 정수여야 하는 변수 xj가 소수 값 v를 가지면, xj ≤ ⌊v⌋인 가지와 xj ≥ ⌈v⌉인 가지로 나눕니다(변수 분지). 두 가지를 합치면 ⌊v⌋ < xj < ⌈v⌉인 부분만 빠지는데, 그 사이에는 정수가 없으므로 정수해는 하나도 잃지 않습니다. 동시에 지금의 LP 해(xj = v)는 두 가지 어디에도 속하지 않으므로, 두 가지의 LP 완화는 모두 지금 해와 다른 해를 내놓습니다. 같은 자리를 맴돌지 않는다는 뜻입니다.

하위 문제 하나하나를 가지 또는 노드, 맨 처음 문제를 뿌리(root), 만들어졌지만 아직 처리하지 않은 가지를 열린 가지라고 합니다. 가지의 LP 완화는 부모의 LP 완화에 제약 하나를 더한 것이므로 가능 영역이 부모의 부분집합이고, 그 최적값은 부모보다 작아질 수 없습니다. 그래서 아직 풀지 않은 가지는 부모의 LP 값을 하한으로 물려받습니다.

알고리듬과 세 가지 가지치기

최소화 MIP의 분지한계법(Branch-and-Bound)을 단계로 적습니다.

  1. 열린 가지 목록 L = {뿌리}, UB = +∞(incumbent 없음).
  2. L이 비었으면 멈춘다. incumbent가 있으면 그것이 최적해이고, 없으면 문제가 불능이다.
  3. L에서 가지 하나 N을 꺼내 LP 완화를 푼다. 값을 zN, 해를 xN이라 한다.
  4. 가지치기(한계, bounding). 다음 중 하나면 N을 버리고 2로 간다.
    • (가) 불능: LP가 불능이면 이 가지에는 정수해도 없다(정리 9.2 (2)).
    • (나) 정수성: xN이 모든 정수 조건을 만족하면 이 가지의 최적해다(정리 9.2 (3)). zN < UB이면 incumbent를 xN으로 바꾸고 UB = zN.
    • (다) 한계: zN ≥ UB이면 이 가지의 어떤 해도 incumbent보다 좋지 않다(정리 9.2 (1)).
  5. 그렇지 않으면 소수 값인 정수 변수 하나를 골라 두 가지로 나누고, 둘을 L에 넣는다(부모의 zN을 하한으로 물려받음). 2로 간다.

도중의 전체 하한은 LB = min(UB, 열린 가지들의 하한 중 가장 작은 값)입니다. 열린 가지가 없으면 LB = UB가 되어 끝납니다. 이 알고리듬이 정확한(최적을 놓치지 않는) 이유는 세 가지치기가 모두 "그 가지에는 incumbent보다 좋은 정수해가 없다"는 사실에만 의존하기 때문입니다. 분지는 정수해를 잃지 않으므로, 버려지지 않은 정수해는 언젠가 어떤 가지에 남아 있다가 (나)로 발견됩니다. 변수가 유계인 정수 변수라면 가지를 나눌 때마다 어떤 변수의 범위가 줄어드므로 유한 번 안에 끝납니다.

3단계에서 자식의 LP를 풀 때 이어 풀기가 큰 역할을 합니다. 부모의 LP를 심플렉스로 풀었다면 최적 기저가 남아 있습니다. 자식 가지는 부모에 xj ≤ 3 같은 제약 하나를 더한 것이라, 부모의 최적 기저는 감소 비용 조건(쌍대 가능성)을 그대로 만족하고 새 제약 하나만 어깁니다. 6장의 쌍대 심플렉스가 정확히 이 상황에서 출발하는 방법이라, 대개 피벗 몇 번이면 자식의 LP가 풀립니다. 분지한계법이 LP를 수천, 수만 번 풀면서도 감당할 만한 이유입니다.

목적함수 값이 띄엄띄엄할 때

정리 9.5 모든 가능해의 목적함수 값이 양의 정수 k의 배수라고 하자. 그러면

(1) LP 값이 zN인 가지의 정수해는 모두 k⌈zN/k⌉ 이상이다. 따라서 k⌈zN/k⌉ ≥ UB이면 그 가지를 버려도 된다.

(2) 전체에서 UB − LB < k이면 incumbent는 최적이다.

(1) 그 가지의 정수해 x의 값 f(x)는 zN 이상(정리 9.2)이고 k의 배수입니다. zN 이상인 가장 작은 k의 배수가 k⌈zN/k⌉이므로 f(x) ≥ k⌈zN/k⌉ ≥ UB. (2) incumbent보다 좋은 가능해 x가 있다면 f(x) < UB이고 둘 다 k의 배수이므로 f(x) ≤ UB − k입니다. 그런데 UB − k < LB ≤ f(x)이므로 모순입니다. ∎

트럭 문제는 단가가 정수라 비용이 정수(k = 1)입니다. ⑦은 ⌈36.8⌉ = 37 ≥ 37이므로 버려지고, 열린 가지가 없어 (3, 1), 37이 최적으로 증명됩니다. (2)로 말하면 ⑦의 LP를 풀어 그 가지의 하한이 36.8이 된 시점(남은 열린 가지는 ⑦뿐)에 UB − LB = 37 − 36.8 = 0.2 < 1입니다. 위 표의 ⑦ 행은 ⑦을 버린 뒤의 상태라서 LB가 37로 적혀 있고, 이 중간 순간은 표에 따로 적지 않았습니다.

tryAgain의 목적함수는 왜 짝수인가

tryAgain 모형(8장 6부)의 목적함수는 Σp<q Σi 2(F + dist(i)) xpqi입니다. F(고정비)와 dist(i)(간선 수)는 정수이고 xpqi ∈ {0, 1}입니다. 각 항이 2 × (정수) × (0 또는 1)이므로 짝수이고, 짝수의 합은 짝수입니다. y와 z는 목적함수에 없습니다. 따라서 모든 가능해의 값이 2의 배수이고 정리 9.5 (2)에 의해 UB − LB < 2이면 멈춰도 됩니다. 정리 9.5 (2)는 엄격한 부등호(< 2)를 요구합니다. 진짜 gap이 정확히 2라면 UB − 2인 해가 아직 있을 수 있어 멈추면 안 되는데, 수치 오차로 LB가 아주 조금 크게(gap이 1.9999999처럼 조금 작게) 계산될 수 있습니다. 문턱을 2보다 살짝 작게(1.999) 잡으면 이런 경우에 성급하게 멈추지 않습니다. 이것이 가이드 8장의 MIPGapAbs = 2 − TOL입니다. 배의 그래프에 홀수 순환이 있으면 모형이 센 비용과 실제 경로의 비용이 어긋날 수 있다는 3장 4부의 이야기와는 별개로, 이 논증은 그대로 성립합니다. 실제 비용이 아니라 모형의 목적함수 값에 대한 성질이기 때문입니다.

얼마나 커질 수 있나

이진변수 n개를 모두 분지하면 깊이 n의 완전 이진 트리가 되어 가지가 2n+1 − 1개입니다. 실제로 그만큼 커지는 문제도 있습니다. 분지한계법이 실용적인 것은 가지치기 덕분이고, 가지치기가 얼마나 잘 되는지는 두 가지에 달려 있습니다.

  • UB가 얼마나 일찍 좋아지는가. 규칙 (다)는 UB가 낮을수록 많이 자릅니다. 좋은 incumbent를 일찍 찾는 것이 원시 휴리스틱(4부)의 일입니다.
  • LP 값이 정수 최적값에 얼마나 가까운가. 가지의 LP 값이 실제 값에 가까울수록 (다)가 일찍 걸립니다. 같은 문제를 LP 값이 더 높게 나오도록 적는 기술이 10장의 정식화의 강도입니다.
3부 · 탐색 순서

어느 가지를 먼저: 노드 선택

3단계에서 "L에서 가지 하나를 꺼낸다"고만 했습니다. 어느 것을 꺼내도 결과(최적해)는 같지만 걸리는 시간과 도중의 모습이 다릅니다.

규칙방법장점단점
최선 우선(best-first)하한이 가장 작은 가지LB가 가장 빨리 오름. 증명에 필요한 가지만 엶(UB가 최적값이라면 하한이 그보다 작은 가지는 어차피 열어야 함)목록이 커져 메모리를 많이 씀. 깊이 내려가지 않아 정수해를 늦게 찾음. 형제 가지로 이어 풀기가 잘 안 됨
깊이 우선(depth-first)방금 만든 자식빨리 바닥에 닿아 정수해(UB)를 일찍 찾음. 부모 → 자식 이어 풀기가 잘 됨. 메모리가 적음나쁜 방향으로 들어가면 오래 헤맴. LB가 잘 안 오름

실제 솔버는 섞어 씁니다. 평소에는 깊이 우선으로 내려가다가(이것을 plunging이라고 부릅니다), 내려간 가지의 하한이 너무 나빠지면 최선 우선으로 다른 곳으로 점프하는 식입니다. 메타휴리스틱의 강화(intensification)와 다양화(diversification) 사이의 균형과 비슷한 문제입니다. 가이드 4장의 트럭 예 표에 "여기서는 설명하기 좋은 순서로 골랐습니다"라고 적힌 것이 이 선택입니다.

어느 변수로 나누나: 분지 변수 선택

LP 해에서 소수 값인 정수 변수가 여럿이면 어느 것으로 나눌지 골라야 합니다. 좋은 선택은 두 자식의 LP 값을 많이 올리는 변수입니다. 그러면 가지가 빨리 (다)로 잘립니다.

  • 가장 소수인 변수(most fractional): 소수 부분이 0.5에 가장 가까운 변수. 계산이 공짜지만 실험적으로는 무작위 선택과 별 차이가 없다고 알려져 있습니다.
  • 강분지(strong branching): 후보 변수마다 두 자식의 LP를 실제로(또는 피벗 몇 번만) 풀어 보고, 값이 가장 많이 오르는 변수를 고릅니다. 가지 수는 크게 줄지만 가지 하나당 계산이 비쌉니다.
  • 의사비용(pseudo-cost): 지금까지 그 변수로 분지했을 때 "소수 부분 한 단위당 LP 값이 평균 얼마나 올랐는가"를 기록해 두고 그 통계로 예측합니다. 처음에는 기록이 없으니, 기록이 쌓일 때까지 강분지를 쓰고 이후 의사비용으로 바꾸는 혼합 방식이 흔합니다.

트럭 예의 뿌리에서는 x만 소수라 선택의 여지가 없었습니다. ⑤에서도 x만 소수였습니다. 변수가 많은 문제에서는 이 선택이 가지 수를 몇 배씩 바꿉니다.

4부 · 솔버 안의 보조 장치

전처리: 풀기 전에 모형을 조이기

전처리(presolve)는 분지한계법에 들어가기 전에 모형을 최적값을 바꾸지 않으면서 더 작고 단단하게 바꾸는 일입니다(아래 예들은 정수해 집합도 그대로 둡니다). 원리는 대부분 "제약 하나와 변수 범위만 보고 추론하기"입니다.

범위 조이기(bound tightening)의 예: 정수 x, y ≥ 0과 제약 3x + 2y ≤ 10이 있습니다. y ≥ 0이므로 3x ≤ 10, x ≤ 10/3, 정수이므로 x ≤ 3. 같은 방식으로 y ≤ 5. 다른 제약에서 y ≥ 2를 알게 되면 3x ≤ 10 − 4 = 6이라 x ≤ 2로 더 조여집니다. 이렇게 줄인 범위는 다시 다른 제약의 추론에 쓰여 연쇄적으로 퍼집니다.

그 밖의 원리: 값이 하나로 정해진 변수를 고정해 지우기, 항상 성립하는 제약 지우기, 같은 제약 합치기, 8장에서 본 시간창 계산처럼 불가능한 xij를 0으로 고정하기, 계수 조이기(big-M 계수를 유효한 범위 안에서 줄이기). 전처리는 정수해 집합을 바꾸지 않으면서 LP 완화의 가능 영역을 줄일 수 있어, 하한을 올리는 효과도 있습니다.

원시 휴리스틱: 상한을 내리는 장치

분지한계법만으로는 규칙 (나)로 정수해를 우연히 만날 때까지 incumbent가 없습니다. 솔버는 탐색 중간중간 원시 휴리스틱(primal heuristic)을 돌려 가능해를 찾습니다. CVRPTW에서 쓰는 휴리스틱과 목적은 같지만, 문제의 구조를 모른 채 어떤 MIP에도 쓸 수 있도록 LP 해와 모형의 식만 재료로 쓴다는 점이 다릅니다. 대표적인 원리를 트럭 예로 봅니다.

LP를 풀지 않는 휴리스틱

위 휴리스틱은 대부분 LP 해를 재료로 씁니다. 모형이 아주 크면 뿌리 LP 하나를 푸는 데 제한 시간을 다 쓸 수 있어, LP 없이 정수해를 직접 찾아 고치는 휴리스틱이 필요해집니다. 일반적인 방법은 변수 값을 정수로 둔 채 "제약 위반량 + 목적함수"를 줄이는 방향으로 값을 바꿔 가는 지역 탐색입니다. 가이드 4장과 8장에 나오는 Gurobi의 NoRel 휴리스틱이 이 범주에 속하지만, 그 내부 동작은 공개 문서에 설명되어 있지 않습니다. 확실히 말할 수 있는 것은 정의상의 결과뿐입니다. LP 완화를 풀지 않으므로 LB가 생기지 않고, gap으로 멈출 수 없으며, 최적 증명을 하지 못합니다.

MIP start와 matheuristic

MIP start는 사용자가 알고 있는 가능해를 처음부터 incumbent로 넣어 주는 것입니다. 가지치기 규칙 (다)와 정리 9.5의 정지 규칙이 처음부터 UB를 쓸 수 있게 됩니다. 쉽게 만들 수 있는 가능해가 있는 문제라면 공짜에 가까운 이득입니다.

matheuristic은 MIP 솔버를 휴리스틱의 부품으로 쓰는 방법입니다. 대표가 fix-and-optimize입니다. 변수 일부를 현재 해의 값(또는 휴리스틱이 정한 값)으로 고정하고 나머지만 MIP로 정확히 푼 뒤, 고정하는 변수 묶음을 바꿔 가며 반복합니다. 고정한 만큼 모형이 작아지므로 큰 문제에도 쓸 수 있고, 현재 해의 값으로 고정했다면 현재 해가 부분 문제의 가능해이고 각 단계는 그 부분에 대해 최적이므로 해가 나빠지지 않습니다(휴리스틱이 정한 다른 값으로 고정하면 이 보장은 없습니다). 어떤 묶음을 고정할지 고르는 것은 이웃 설계와 같아서, CVRPTW의 휴리스틱 경험이 그대로 쓰입니다.

가이드의 예시 로그(숫자는 형식을 보이려고 지어낸 것)에서 Incumbent 1600, BestBd 1548이면 상대 gap은 (1600 − 1548)/1600 = 52/1600 = 3.25%로 로그의 값과 맞습니다. 이론으로 해석하면 다음과 같습니다.

  • Unexpl가 계속 는다: 가지치기보다 분지가 빠르다. 위 둘 중 어느 쪽이든 원인이다.

가이드와 연결

가이드 4장 「정수 조건만 빼면 쉬운 문제가 된다」의 "LP 완화의 최적값은 원래 문제의 하한이다"는 정리 9.2 (1)이고, 가이드의 이유 설명(선택지가 늘면 최솟값이 나빠질 수 없다)이 그 증명입니다. 「1장에서 본 대회의 LB도 같은 종류의 숫자」라는 문장은 정의 9.1의 "LP가 아닌 완화"의 예입니다(차들이 서로 막지 않는다고 조건을 푼 문제).

가이드 4장 「상한과 하한 사이에 답이 있다」의 incumbent, best bound, primal/dual bound, 절대·상대 gap은 정의 9.3입니다. 「나누고, 풀고, 버린다」의 세 가지 버리는 경우는 이 장의 규칙 (가)(나)(다)이고, 「트럭 예를 끝까지 따라가기」의 ⑦에서 쓴 추론이 정리 9.5입니다.

가이드 4장 「현대 솔버 = 분지한계법 + 네 가지 보조 장치」의 전처리와 휴리스틱은 이 장 4부, 절단평면은 10장입니다. 「모형이 크면 뿌리에서 막힌다: NoRel 휴리스틱」과 발표자료 비교표의 "하한이 실제 값에 가까운가" 칸이 빈 이유는 "LP를 풀지 않는 휴리스틱은 하한을 만들지 않는다"는 4부의 정의상 결과입니다.

가이드 8장 「MIPGapAbs = 2 − TOL: 짝수만 나오는 목적함수」는 정리 9.5 (2)와 짝수성 증명, 그리고 1부의 "두 멈춤 기준" 계산입니다. 「Heuristics = 0.15: 가능해 찾기에 세 배」는 4부의 "휴리스틱 비중을 늘리면 UB는 빨리, LB는 느리게"입니다. 「NoRelHeurTime: 크면 분지한계법을 포기한다」와 「설정하지 않은 것들」의 초기해(MIP start)는 4부의 MIP start입니다. 가이드 5장의 "전부 내렸다 다시 싣기"가 쉽게 만들 수 있는 가능해의 예입니다.

가이드 9장 「발표자료가 꼽은 세 갈래」의 ② 「중간 항구의 배치를 고정해서 문제를 분해」, 「쓰일 가능성이 낮은 변수를 0으로 고정」은 이 장의 fix-and-optimize(matheuristic)와 전처리식 변수 고정입니다. 고정은 해를 잃을 수 있으므로(정확한 전처리와 달리) 휴리스틱입니다.

연습문제

최소화 MIP에서 LP 완화 값이 250.4, incumbent가 260입니다. 모든 가능해의 값이 정수라면 최적값의 범위는? 값이 5의 배수뿐이라면요?

정수면 ⌈250.4⌉ = 251 ≤ z* ≤ 260. 5의 배수면 5⌈250.4/5⌉ = 5 × 51 = 255 ≤ z* ≤ 260, 곧 z*는 255 또는 260입니다(정리 9.5 (1)을 뿌리에 적용).

εabs = 1.999, εrel = 10−4일 때 UB = 13,260과 UB = 668,004에서 실제로 쓰이는 문턱은 각각 얼마인가요?

13,260 × 10−4 = 1.326 < 1.999이므로 문턱은 1.999(절대 기준). 668,004 × 10−4 = 66.8004이므로 문턱은 약 66.8(상대 기준). 뒤의 경우 목적함수가 짝수뿐이어도 incumbent보다 2씩 작은 값 33개(66.8 미만의 짝수 차이 2, 4, …, 66)가 배제되지 않은 채 멈출 수 있습니다.

"xj = 2.6이면 xj ≤ 2와 xj ≥ 3으로 나눈다"에서, 대신 xj ≤ 2와 xj ≥ 2로 나누면 무엇이 잘못되나요?

정수해는 잃지 않지만(두 가지가 xj = 2를 함께 가짐) 지금의 LP 해 xj = 2.6이 xj ≥ 2 가지에 그대로 남아, 그 가지의 LP가 같은 해를 다시 내놓습니다. 진전이 없어 무한히 같은 분지를 반복할 수 있습니다. 분지는 지금의 소수 해를 두 가지 모두에서 쫓아내야 합니다.

트럭 예에서 뿌리 직후 x ≤ 3 가지를 먼저 끝까지 내려가면(깊이 우선: ③ → ⑤ → ⑥ → ⑦ → ④ → ②) 처리하는 가지 수가 가이드의 순서와 같은가요?

⑥에서 incumbent 37을 얻고, ⑦은 ⌈36.8⌉ = 37 ≥ 37로 잘리고, ④는 불능, ②의 x ≥ 4 가지는 LP 값 40 ≥ 37로 (다)에 의해 잘립니다(정수해이기도 하지만 더 나쁨). 처리하는 가지는 똑같이 일곱 개입니다. 이 예는 너무 작아 순서의 차이가 드러나지 않습니다. 다만 incumbent 40을 한 번도 거치지 않는다는 점이 다릅니다.

정수 x, y ≥ 0, 제약 4x + 3y ≤ 11, x + y ≥ 3일 때 범위 조이기로 x와 y의 상한을 구하고, x + y ≥ 3을 써서 더 조일 수 있는지 보세요.

4x ≤ 11 → x ≤ 2. 3y ≤ 11 → y ≤ 3. x + y ≥ 3과 y ≤ 3에서 x ≥ 0(새 정보 없음), x ≤ 2에서 y ≥ 1. 다시 4x ≤ 11 − 3·1 = 8 → x ≤ 2(변화 없음). 결과: 0 ≤ x ≤ 2, 1 ≤ y ≤ 3. 실제 정수해는 (0,3), (1,2), (2,1)이고 모두 이 범위 안에 있습니다.

모든 가능해의 값이 짝수인데 상대 gap 기준만 쓰고 절대 gap 기준을 1e-10으로 두면, 작은 문제에서 무엇이 달라지나요?

정리 9.5의 이득을 못 씁니다. LB가 UB에 1e-10 이내로 다가가거나 상대 기준에 걸릴 때까지 분지를 계속하므로, 마지막 가지(정수 목적함수인 트럭 예에서 k = 1의 올림을 쓰지 않으면 ⑦을 더 나눠야 하는 것과 같은 상황)를 더 나눠야 할 수 있습니다. 다만 솔버가 계수를 보고 목적함수가 정수(또는 짝수)라는 것을 스스로 알아채 같은 추론을 쓰는 경우도 있어, 실제 차이는 솔버에 따라 다릅니다.

LP를 풀지 않는 휴리스틱만 제한 시간 내내 돌렸습니다. 끝났을 때 로그의 BestBd와 Gap 열에는 무엇이 남을까요? 이론적으로만 답하세요.

LP 완화를 풀지 않았으므로 완화에서 나오는 하한이 없습니다. 하한은 전처리 등에서 얻은 아주 약한 값이거나 아예 없고(−∞), 따라서 gap은 크거나 정의되지 않습니다. 해의 품질은 증명되지 않으며, 최적해를 찾았더라도 멈출 근거가 없어 시간을 끝까지 씁니다.
