# 고3용 두 문서의 공통 약속 (study-hs · guide-hs)

- 관리: `study-hs` 세션. 용어와 기호의 기준은 이 파일입니다. `guide-hs`가 새 용어가 필요하면 이 파일에 없는지 먼저 보고, 없으면 `study-hs` 세션에 알려 주세요.
- 마지막 갱신: 2026-11-19 2판 (guide-hs 요청 반영: 3-1절 「개념 → 교재 장」 찾아보기, 5절 끝 「가이드 쪽 용어」, 높이 기호 h(i) = pos(i) 메모)
- 독자: 이과 고3, Python 기초(변수, if, for, 리스트, 함수) 가능. 행렬·그래프 이론·알고리즘·최적화는 처음.

## 1. 글쓰기 약속

1. 새 개념은 고교 수학(1차식, 연립방정식, 부등식, 집합과 명제, 수열과 Σ, 미적분, 확률과 통계)에서 출발합니다.
2. 순서는 **비유·그림 → 작은 숫자 예 → 정의 → 일반적인 말**입니다. 정의 상자가 맨 앞에 오지 않습니다.
3. 증명은 본문에 넣지 않습니다. 본문에는 「왜 그런가」(직관적인 이유)를 쓰고, 엄밀한 증명이나 대학 수준 내용은 「참고」 상자로 뺍니다. 참고 상자는 건너뛰어도 뒤가 읽혀야 합니다.
4. 영어 용어는 처음 나올 때 한 번만 괄호로 병기합니다. 예: 가능해(feasible solution).
5. 실무 용어 CVRPTW는 쓰지 않고 **「택배 트럭 경로 문제」**라고 부릅니다(아래 예 목록 참고).
6. 코드는 Python만, 20줄 안팎으로 짧게, 코드 바로 아래에 줄 번호별 풀이를 붙입니다. 쓰는 문법은 변수, if, for, while, 리스트, 함수, `range`, `len`, `print`, `min`, `max`, `abs` 정도로 제한합니다. 리스트 내포(list comprehension), 클래스, 외부 라이브러리는 쓰지 않습니다. 솔버 사용법(Gurobi 등)은 `study-hs`에서 다루지 않습니다.
7. 문체는 「~합니다」체. 문장은 짧게.
8. 약어 BFS는 **너비 우선 탐색**만 뜻합니다. LP 교과서의 basic feasible solution은 「기저가능해」로 풀어 씁니다.
9. 수학의 범위 [a, b]는 「범위」라고 부릅니다. **「구간」은 tryAgain 모형의 말(차 한 대가 한 칸에 서 있는 기간)로만** 씁니다.
10. 다른 문서를 가리킬 때: 풀이 해설은 「가이드」, 이론 교재는 「교재」. `study-hs` 안에서는 가이드의 장 번호를 적지 않고 주제 이름으로 가리킵니다(두 문서가 동시에 쓰이고 있어 번호가 바뀔 수 있음). `guide-hs`가 교재를 가리킬 때는 아래 3절의 장 번호를 써도 됩니다(번호가 바뀌면 알립니다).

## 4. 기호 표기

| 대상 | 표기 | 메모 |
|---|---|---|
| 변수 | x, y, x₁, x₂ | 첨자는 아래첨자. 첨자가 여럿이면 붙여 쓰고(x<sub>pqi</sub>), 숫자를 넣을 때 헷갈리면 쉼표(x<sub>02,1</sub>: p = 0, q = 2, 칸 1) |
| 최적화 문제 | 「최소화 10x + 7y」, 「제약 9x + 5y ≥ 30」 | min, max, s.t. 대신 한글 |
| 범위 지정 | 식 오른쪽에 「모든 칸 i」 | 기호 ∀는 교재 2장에서 한 번 소개하고, 본문 식에서는 한글로 적음 |
| 합 | Σ<sub>i</sub> a<sub>i</sub>, 범위가 헷갈리면 「i = 1부터 n까지」를 말로 덧붙임 | 고교 Σ<sub>k=1</sub><sup>n</sup>과 같은 뜻임을 교재 2장에서 설명 |
| 집합 | {x \| 조건}, ∈, ⊂, ∩, ∪, ∅ | 고교 표기. ⊂는 「부분집합(같아도 됨)」. 원소 개수는 \|S\| (고교의 n(S)) |
| 수의 집합 | 실수 ℝ, 정수 ℤ, 「0 또는 1」은 {0, 1} | |
| 바닥·천장 | ⌊a⌋ (a 이하의 가장 큰 정수, 고교의 가우스 기호 [a]), ⌈a⌉ (a 이상의 가장 작은 정수) | 분수 부분 frac(a) = a − ⌊a⌋ |
| 분수 | 10/3 꼴. 필요하면 ≈ 33.33 병기 | |
| 벡터 | (x₁, …, xₙ). 굵은 글씨 없음 | |
| 내적 | a·x = a₁x₁ + … + aₙxₙ | 대학 교재의 aᵀx 표기는 교재 3장 참고 상자에서만 소개 |
