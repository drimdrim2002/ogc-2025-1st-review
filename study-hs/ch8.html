심플렉스법

7장에서 꼭짓점이 기저가능해와 같다는 것을 배웠습니다. 하지만 변수가 100개만 되어도 기저의 개수가 1029개를 넘어, 모든 기저를 다 풀어 볼 수는 없습니다. 심플렉스법(simplex method)은 한 꼭짓점에서 출발해 더 좋은 이웃 꼭짓점으로 옮겨 다니며, 모든 기저를 보지 않고도 순식간에 최적해에 닿는 알고리듬입니다.

  • 미리 알아야 할 것. 3장(연립방정식과 소거법), 6장(도해법, 불능·비유계, 「동네 최고 = 전체 최고」), 7장(표준형, 여유·잉여 변수, 기저, 기저가능해, 축퇴).
  • 이 장을 읽고 나면. 공방 예를 사전과 단체표로 끝까지 풀 수 있고, 감소 비용의 뜻과 최적·비유계 판정을 설명할 수 있으며, 2단계법·제자리걸음·이어 풀기(warm start)가 무엇인지 말할 수 있습니다.
1부 · 사전과 피벗: 꼭짓점 건너뛰기

사전: 지금 어느 꼭짓점에 서 있는가

공방 예를 다시 가져옵니다. 여유 변수 s1, s2 ≥ 0을 붙인 등식과 최대화할 이익 z는 다음과 같습니다.

최대화  z = 5x1 + 4x2이익
제약    6x1 + 4x2 + s1 = 24,   x1 + 2x2 + s2 = 6,   x1, x2, s1, s2 ≥ 0

출발할 꼭짓점이 하나 필요합니다. 모든 제약이 "≤, 오른쪽 ≥ 0"이면 원점 (0, 0)이 언제나 가능해이므로, 처음 기저로 여유 변수 묶음 {s1, s2}를 고릅니다. 기저 변수 s1, s2를 왼쪽에, 비기저 변수 x1, x2를 오른쪽에 두고 식을 정리하면 다음과 같습니다.

s1 = 24 − 6x1 − 4x2목재 여유
s2 =  6 −  x1 − 2x2시간 여유
z  =  0 + 5x1 + 4x2이익
정의 기저 변수들과 목적함수를 모두 비기저 변수만의 식으로 풀어 적은 식 묶음을 사전(dictionary)이라고 합니다.

사전 한 장에는 지금 상태에서 필요한 정보가 모두 들어 있습니다. 세 가지를 읽어 봅니다.

  1. 현재 점과 값. 비기저 변수는 0이므로 x1 = 0, x2 = 0입니다. 따라서 오른쪽의 상수항이 그대로 기저 변수의 값입니다: s1 = 24, s2 = 6, 이익 z = 0. 꼭짓점 (0, 0)입니다.
  2. 어느 쪽으로 움직일까 (진입 변수). z 줄을 봅니다. x1의 계수가 +5, x2의 계수가 +4입니다. 비기저 변수를 0에서 1만큼 키우면 이익이 각각 5, 4만큼 늘어납니다. 둘 다 좋지만 더 크게 오르는 x1을 0에서 키워 보기로 합니다. 이렇게 기저 안으로 새로 들어올 변수를 진입 변수(entering variable)라고 합니다.
  3. 얼마나 멀리 갈 수 있나 (최소비 검사). x2 = 0을 유지한 채 x1을 0에서 점점 키웁니다. 그러면 s1 = 24 − 6x1과 s2 = 6 − x1이 함께 줄어듭니다. 두 변수 모두 0 이상이어야 하므로:
    • s1 ≥ 0 때문에 24 − 6x1 ≥ 0 → x1 ≤ 24/6 = 4
    • s2 ≥ 0 때문에 6 − x1 ≥ 0 → x1 ≤ 6/1 = 6
    둘 다 지켜야 하므로 더 작은 쪽인 x1 = 4까지만 갈 수 있습니다. (만약 6까지 가면 s1 = −12가 되어 영역 밖으로 나갑니다.) 이 나눗셈 비교를 최소비 검사(ratio test)라고 합니다. x1 = 4에 닿는 순간 s1이 가장 먼저 0이 되어 비기저로 물러납니다. 이렇게 기저에서 나가는 변수를 탈출 변수(leaving variable)라고 합니다.

한 걸음: 피벗으로 (0, 0) → (4, 0) → (3, 3/2)

정의 기저에서 탈출 변수를 빼고 진입 변수를 넣어 새 사전을 만드는 한 걸음을 피벗(pivot)이라고 합니다.

첫째 피벗 (x1 진입, s1 탈출). 탈출 변수 s1의 식 s1 = 24 − 6x1 − 4x2를 진입 변수 x1에 대해 풀어 적습니다.

x1 = 4 − (2/3)x2 − (1/6)s1

이제 나머지 두 식(s2와 z)의 x1 자리에 이 식을 대입해 x1을 없앱니다. 중학교의 대입법 그대로입니다.

x1 = 4 − (2/3)x2 − (1/6)s1
s2 = 6 − [4 − (2/3)x2 − (1/6)s1] − 2x2 = 2 − (4/3)x2 + (1/6)s1
z  = 5[4 − (2/3)x2 − (1/6)s1] + 4x2 = 20 + (2/3)x2 − (5/6)s1

새 기저는 {x1, s2}입니다. 비기저 변수 x2 = s1 = 0을 넣으면 현재 점은 (4, 0), 이익은 z = 20입니다. 한 걸음에 (0, 0)에서 (4, 0)으로 옮겼고 이익이 0에서 20으로 뛰었습니다.

아직 끝이 아닙니다. z 줄에서 x2의 계수가 +2/3으로 양수입니다. s1의 계수 −5/6은 음수이니 s1을 키우면 이익이 줄어듭니다. 따라서 x2를 진입 변수로 고릅니다.

둘째 피벗 (x2 진입, s2 탈출). 최소비 검사를 합니다.

  • x1 줄: 4 ÷ (2/3) = 6
  • s2 줄: 2 ÷ (4/3) = 3/2 = 1.5

더 작은 쪽은 3/2이므로 s2가 탈출 변수입니다. s2 = 2 − (4/3)x2 + (1/6)s1을 x2에 대해 풀면 x2 = 3/2 + (1/8)s1 − (3/4)s2입니다. 이것을 x1 줄과 z 줄에 대입합니다.

x2 = 3/2 + (1/8)s1 − (3/4)s2
x1 = 3   − (1/4)s1 + (1/2)s2
z  = 21  − (3/4)s1 − (1/2)s2

새 기저는 {x1, x2}이고 현재 점은 (3, 3/2), 이익은 z = 21입니다. z 줄을 보세요. 비기저 변수 s1, s2의 계수가 모두 음수(−3/4, −1/2)입니다. s1이나 s2는 0 이상이어야 하므로(원료를 남기거나 시간을 남기면), 어느 쪽을 올려도 21에서 값이 깎이기만 합니다. 따라서 (3, 3/2), 이익 21이 최적입니다!

그림에서 보듯 꼭짓점 (0, 3)은 아예 들르지도 않고 두 걸음 만에 끝났습니다. 오른쪽 그림처럼 최소비 검사는 "앞으로 나아가다가 어느 제약 벽에 가장 먼저 부딪히는가"를 재는 자입니다.

같은 계산을 표로: 단체표

사전을 매번 문자로 길게 대입하는 대신, 3장의 소거법 표처럼 숫자만 칸에 맞춰 적은 것이 단체표(simplex tableau)입니다.

목적함수 z = 5x1 + 4x2는 z − 5x1 − 4x2 = 0으로 한쪽으로 몰아 마지막 줄에 적습니다. 그래서 사전의 z 줄과 부호가 반대입니다. 최대화 문제에서는 마지막 줄에 음수가 남아 있으면 아직 이익을 더 키울 수 있다는 뜻이고, 모두 0 이상이 되면 최적입니다. 색칠한 줄이 그 단계에서 빠져나갈 탈출 변수의 줄(피벗 줄)입니다.

표 0 · 기저x1x2s1s2오른쪽비 (x1 진입)
s164102424 ÷ 6 = 4 (최소)
s2120166 ÷ 1 = 6
z−5−4000

표 0에서 표 1로 넘어가는 계산은 3장의 소거법 그대로입니다. 피벗 줄(s1 줄)을 피벗 자리의 수 6으로 나눠 x1 계수를 1로 만듭니다. 그다음 s2 줄에서는 새 x1 줄의 1배를 빼고, z 줄에는 새 x1 줄의 5배를 더해서 x1 열의 다른 수를 전부 0으로 만듭니다.

표 1 · 기저x1x2s1s2오른쪽비 (x2 진입)
x112/31/6044 ÷ (2/3) = 6
s204/3−1/6122 ÷ (4/3) = 3/2 (최소)
z0−2/35/6020

이번에는 x2 열의 z 줄이 −2/3으로 음수이고, 비는 s2 줄이 3/2로 더 작습니다. s2 줄을 4/3로 나눈 뒤, x1 줄과 z 줄에서 x2 열을 0으로 만들면 표 2가 됩니다.

표 2 · 기저x1x2s1s2오른쪽판정

각 표는 같은 연립방정식을 기저만 바꿔 다시 정리한 것이므로 해의 집합은 바뀌지 않습니다. 표 2의 마지막 줄에 나온 3/4와 1/2에는 아주 재미있는 뜻이 숨어 있습니다(목재나 시간을 1만큼 더 주면 이익이 얼마나 느는가). 이것은 9장 「쌍대성」의 핵심 주인공으로 다시 등장합니다.

2부 · 감소 비용, 최적 판정, 세 결말

감소 비용과 최적 판정

방금 본 공방 예의 사전 z 줄에는 비기저 변수마다 계수가 붙었습니다. 이 계수에 특별한 이름을 붙입니다. 이제부터는 표준형(최소화 문제)을 기준으로 이야기해 봅니다.

최소화 문제의 사전에서 비용 z가 다음과 같이 적혔다고 합시다.

z = (현재 비용) + c̄1x1 + c̄2x2 + …

(여기서 오른쪽의 x1, x2, …는 현재의 비기저 변수들입니다.) 비기저 변수 xj를 0에서 1만큼 올리고, 기저 변수들이 등식을 지키도록 따라 움직이게 두면, 총비용 z는 c̄j만큼 변합니다.

정의 현재 기저에 대해 비기저 변수 하나를 0에서 1만큼 올릴 때 목적함수가 변하는 양(사전 목적함수 줄의 계수)을 그 변수의 감소 비용(reduced cost)이라고 합니다. 기저 변수의 감소 비용은 0입니다.

왜 이름이 「감소 비용」일까요? 어떤 제품(변수 xj)을 한 단위 새로 만들면 직접 비용이 들지만, 그만큼 자원을 써야 하므로 기존 기저 변수들이 비켜 주면서 아끼는 비용이 생깁니다. 둘을 상계하고 남은 순수한 비용 변화라서 감소 비용이라고 부릅니다. (최소화에서 감소 비용이 음수이면 비용이 줄어드니 넣는 쪽이 이득이고, 최대화에서는 사전 계수가 양수인 쪽이 이익이 느니 이득입니다.)

핵심 사실 (최적 판정) 최소화 문제의 기저가능해에서 모든 비기저 변수의 감소 비용이 0 이상이면, 그 해는 전체 가능 영역에서 최적해입니다. (최대화 사전에서는 모든 계수가 0 이하이면 최적입니다.)

왜 "이웃 꼭짓점"만이 아니라 모든 가능해보다 좋다고 확신할 수 있을까요? 사전의 목적함수 식 한 줄이 그 이유입니다. 예를 들어 공방 예의 마지막 사전은 z = 21 − (3/4)s1 − (1/2)s2입니다. 어떤 가능해를 가져오든 s1 ≥ 0이고 s2 ≥ 0이어야 합니다. 0 이상인 수에 3/4과 1/2을 곱해 21에서 빼면, 결과는 언제나 21 이하입니다! 즉 이 식 하나가 "이웃 꼭짓점뿐 아니라 가능 영역 전체의 어떤 점도 21을 넘을 수 없다"는 증명서 역할을 합니다.

트럭 LP로 숫자를 확인해 봅니다. 7장에서 트럭 LP의 표준형은 최소화 10x + 7y, 제약 9x + 5y − s = 30 (x, y, s ≥ 0)이었습니다. 기저 {x}를 골라 x에 대해 풀면 x = 10/3 − (5/9)y + (1/9)s이고, 비용에 넣으면 다음과 같습니다.

x = 10/3 − (5/9)y + (1/9)s
비용 = 10(10/3 − (5/9)y + (1/9)s) + 7y = 100/3 + (13/9)y + (10/9)s

작은 트럭 y의 감소 비용은 +13/9, 잉여 변수 s의 감소 비용은 +10/9입니다. 실제로 작은 트럭 y를 1대 부르면 7만 원이 들지만 대신 큰 트럭을 5/9대 덜 불러도 되므로 50/9만 원을 아껴서, 순비용 변화가 7 − 50/9 = 13/9만 원이 됩니다. 두 감소 비용이 모두 양수(0 이상)이므로 (10/3, 0), 비용 100/3 ≈ 33.33이 최적해입니다.

비유계와 불능은 어떻게 알아채나

6장에서 LP의 세 결말(최적·불능·비유계)을 배웠습니다. 심플렉스법은 셋을 모두 정확히 판정합니다.

비유계 판정. 예를 들어 최대화 z = x1 + x2, 제약 x1 − x2 ≤ 1, x1, x2 ≥ 0을 사전으로 적어 봅니다.

s = 1 − x1 + x2
z = 0 + x1 + x2

x2를 진입 변수로 골라 0에서 키워 봅니다. 그런데 s 식을 보니 x2 앞의 부호가 +1입니다. x2를 키울수록 s = 1 + x2도 같이 커지기만 하고, s가 0이 되어 막아 주는 일이 결코 일어나지 않습니다. 최소비 검사에 걸리는 기저 변수가 하나도 없는 것입니다. 따라서 x2를 끝없이 키우면 z도 끝없이 커지며, 심플렉스법은 즉시 비유계(unbounded)를 선언하고 멈춥니다.

처음 꼭짓점 찾기: 2단계법과 불능 판정. 그렇다면 트럭 예(9x + 5y − s = 30)처럼 여유·잉여 변수 기저 {s}를 잡으면 s = −30 < 0이 되어 처음부터 가능하지 않을 때는 어떻게 출발할까요? 2단계법(two-phase method)을 씁니다.

  • 1단계: 가능해 하나 찾기. 먼저 모든 등식의 오른쪽이 0 이상이 되도록 맞추고(필요하면 양변에 −1 곱하기), 각 식에 0 이상의 인공 변수(artificial variable) ri를 더합니다. 트럭 예에서는 9x + 5y − s + r = 30입니다. 이제 기저 {r}을 잡으면 r = 30 ≥ 0이라 바로 출발할 수 있습니다! 목적함수로 "인공 변수의 합 최소화"(w = r)를 풀어서 r을 0으로 줄입니다.
  • 결과 읽기. 1단계의 최적값이 0보다 크면, 인공 변수를 0으로 만들 방법이 없다는 뜻이므로 원래 LP는 불능(infeasible)입니다. (예: x + y ≥ 3, x + y ≤ 1은 1단계에서 r ≥ 2가 나와 불능으로 끝납니다.) 반대로 1단계 최적값이 0이면 인공 변수를 버리고, 지금 손에 쥔 기저가능해에서 2단계(원래 목적함수)를 이어 갑니다.

트럭 예의 1단계를 한 번에 확인합니다. r = 30 − 9x − 5y + s, w = 30 − 9x − 5y + s에서 x의 계수가 −9(최소화이므로 유리한 쪽)입니다. x를 진입시키고 최소비 30/9 = 10/3으로 r을 탈출시키면 x = 10/3 − (5/9)y + (1/9)s − (1/9)r, w = 0 + r이 됩니다. 1단계 최적값이 0이므로 r을 지우고 2단계로 넘어가면, 바로 앞에서 구한 트럭 LP의 최적 사전에 도착합니다.

3부 · 제자리걸음, 속도, 이어 풀기

제자리걸음(축퇴와 순환), 그리고 피벗 횟수

7장에서 기저 변수 가운데 값이 0인 것이 있는 상태를 축퇴라고 불렀습니다. 심플렉스법에서 축퇴는 최소비 검사에서 최솟값이 0이 되는 모습으로 나타납니다.

작은 예를 봅니다. 최대화 z = x1 + x2, 제약 x1 ≤ 1, x1 + x2 ≤ 1, x1, x2 ≥ 0.

단계사전점과 z
시작 {s1, s2}s1 = 1 − x1,  s2 = 1 − x1 − x2,  z = x1 + x2(0, 0), z = 0
① x1 진입, 비 1 동률 → s1 탈출x1 = 1 − s1,  s2 = 0 + s1 − x2,  z = 1 − s1 + x2(1, 0), z = 1
② x2 진입, 비 0/1 = 0 → s2 탈출x2 = 0 + s1 − s2,  x1 = 1 − s1,  z = 1 − s2(1, 0), z = 1 (그대로)

②에서 기저는 {x1, s2}에서 {x1, x2}로 바뀌었지만 점은 (1, 0) 그대로이고 z도 1 그대로입니다. 이렇게 값은 안 움직이고 기저 이름표만 바뀌는 피벗을 제자리걸음(축퇴 피벗)이라고 합니다. 그래도 ② 덕분에 z 줄 계수가 모두 0 이하(s2가 −1, s1이 0)가 되어 최적임을 판정할 수 있었습니다.

제자리걸음이 여러 번 이어지면, 자칫 이전에 지나온 기저로 되돌아와 똑같은 기저들을 빙빙 돌며 끝나지 않는 순환(cycling)이 생길 수 있습니다. 이를 막는 간단한 약속이 Bland 규칙입니다: 진입 변수나 탈출 변수 후보가 여럿일 때, 변수 번호가 가장 작은 것을 고르면 순환이 절대 일어나지 않고 심플렉스법은 반드시 유한 번 만에 끝납니다.

그러면 심플렉스법은 보통 몇 번이나 피벗할까요? 이론적으로 최악을 억지로 만들어 내면(Klee–Minty 예처럼 찌그러진 상자 모양의 문제), 꼭짓점을 거의 다 들러 지수적으로 많은 피벗이 걸리는 경우도 있습니다. 하지만 현실의 대부분 문제에서는 제약 수 m의 몇 배 정도(보통 2m~3m번 안팎)의 피벗만으로 최적에 닿아 매우 빠릅니다.

이어 풀기 (warm start)

심플렉스법이 정수계획 솔버에서 특히 사랑받는 큰 이유가 하나 더 있습니다. 바로 이어 풀기(warm start)입니다.

문제 하나를 다 풀었을 때의 마지막 기저를 기억해 둡니다. 그다음 문제가 조금 바뀌었을 때, 처음 (0, 0)부터 다시 시작하지 않고 방금 저장한 기저에서 출발하면 이미 최적 근처라 피벗 몇 번 만에 새 답이 나옵니다.

  • 목적함수의 계수만 바뀐 경우. 제약은 그대로이므로 이전 최적 기저는 여전히 기저가능해입니다. 감소 비용만 다시 계산해 양수(최대화 기준)인 변수가 있으면 거기서부터 바로 피벗을 이어 가면 됩니다.
  • 제약이 하나 추가된 경우. 예를 들어 트럭 LP를 풀어 x = 10/3을 얻은 뒤, "큰 트럭은 3대 이하: x ≤ 3"이라는 제약을 하나 덧붙인다고 합시다. 이전 답 (10/3, 0)은 새 제약을 어기므로 이 장의 방법으로는 바로 이어 갈 수 없습니다. 그런데 이때 감소 비용은 여전히 "최적 기준(0 이상)"을 지키고 있습니다! 이처럼 최적 판정은 유지된 채 깨진 가능성만 고쳐 가는 짝 방법을 쌍대 심플렉스(dual simplex)라고 하며, 9장에서 바로 이 예로 살펴봅니다.

13장에서 배울 분지한계법은 문제를 풀다가 소수 답(예: x = 10/3)이 나오면 x ≤ 3과 x ≥ 4라는 제약 하나씩을 덧붙인 작은 문제들을 계속 풉니다. 그때마다 부모 문제의 최적 기저에서 쌍대 심플렉스로 이어 풀기 때문에, 수만 개의 작은 LP를 순식간에 해치울 수 있습니다.

Python으로 공방 예 단체표 돌리기

공방 예의 표 0에서 출발해 최적에 닿을 때까지 피벗을 되풀이하는 전체 과정을 Python으로 적어 봅니다.

tab = [[6, 4, 1, 0, 24], [1, 2, 0, 1, 6], [-5, -4, 0, 0, 0]]
basis = [2, 3]
names = ["x1", "x2", "s1", "s2"]
while True:
    enter = -1
    for j in range(4):
        if tab[2][j] < 0:
            enter = j
            break
    if enter == -1:
        break
    leave = -1
    best_r = 10**9
    for i in range(2):
        if tab[i][enter] > 0:
            r = tab[i][4] / tab[i][enter]
            if r < best_r:
                best_r = r
                leave = i
    piv = tab[leave][enter]
    for j in range(5):
        tab[leave][j] = tab[leave][j] / piv
    for i in range(3):
        if i != leave:
            f = tab[i][enter]
            for j in range(5):
                tab[i][j] = tab[i][j] - f * tab[leave][j]
    basis[leave] = enter
    print(names[basis[0]], names[basis[1]], "-> 값:", tab[2][4])

x1 s2 -> 값: 20.0
x1 x2 -> 값: 21.0
  • 1~3행 표 0의 숫자(마지막 열이 오른쪽 값), 처음 기저 [2, 3](s1, s2), 변수 이름 목록입니다.
  • 5~11행 진입 변수 찾기입니다. 마지막 줄(tab[2])에서 0보다 작은 첫 번째 열을 찾습니다. 모두 0 이상이면 최적(enter == -1)이므로 멈춥니다. (일반적인 큰 문제에서는 소수 계산 오차 때문에 < 0 대신 < -0.000001처럼 아주 작은 음수 기준을 씁니다.)
  • 12~19행 최소비 검사입니다. 진입 열의 계수가 양수인 행마다 오른쪽 ÷ 계수를 구해 가장 작은 행(leave)을 고릅니다. 10**9는 최솟값을 구하기 위해 처음에 넣어 둔 큰 수입니다.
  • 20~27행 3장의 소거법 그대로 피벗을 실행합니다. 피벗 행을 piv로 나누고, 나머지 두 행에서는 진입 열의 계수 f배만큼 빼서 그 열을 0으로 만듭니다.
  • 28~29행 기저 목록을 바꾸고 현재 기저와 목적함수 값 tab[2][4]를 출력합니다.

가이드와 연결

가이드의 「심플렉스와 배리어」 절은 "심플렉스는 가능 영역의 꼭짓점에서 이웃 꼭짓점으로 옮겨 다니며 좋아지는 방향으로 갑니다", "조건이 하나 추가된 문제를 이전 답의 기저에서 이어서 풀 수 있어(warm start)"라고 설명합니다. 전자가 이 장의 피벗이고, 후자가 3부의 이어 풀기입니다.

가이드가 「솔버 로그 읽기」에서 설명하는 It/Node 열("가지 하나당 평균 심플렉스 반복 횟수")의 반복 1회가 바로 이 장의 피벗 1회입니다. 그 숫자가 수십 안팎으로 작게 나오는 이유는 이어 풀기 덕분에 몇십 번의 피벗만으로 새 최적해에 닿기 때문입니다.

  • 심플렉스법은 사전을 따라 한 번에 기저 변수 하나와 비기저 변수 하나를 맞바꾸며(피벗) 이웃 꼭짓점으로 이동합니다.
  • 진입 변수는 목적함수를 좋게 하는 비기저 변수, 탈출 변수는 최소비 검사에서 가장 먼저 0이 되는 기저 변수입니다.
  • 단체표는 사전의 계수만 모아 소거법으로 피벗하는 표입니다.
  • 모든 비기저 변수의 감소 비용이 최적 조건(최소화에서는 0 이상)을 만족하면, 가능 영역 전체에서의 최적해입니다.
  • 최소비 검사에 후보가 없으면 비유계, 2단계법의 1단계 최적값이 0보다 크면 불능입니다.
  • 축퇴가 있으면 점은 그대로고 기저만 바뀌는 제자리걸음이 생기며, 기저를 기억해 두면 문제가 조금 바뀌었을 때 이어 풀기(warm start)가 가능합니다.

연습문제

공방 예의 표 0에서 첫 진입 변수로 x1 대신 x2를 골랐다면 피벗이 어떻게 진행되나요? 어느 꼭짓점들을 지나 몇 번 만에 끝나나요?

x2 진입: 최소비는 s1 줄 24/4 = 6, s2 줄 6/2 = 3이므로 s2 탈출. x2 = 3 − (1/2)x1 − (1/2)s2, s1 = 12 − 4x1 + 2s2, z = 12 + 3x1 − 2s2가 되어 꼭짓점 (0, 3), z = 12로 갑니다. 다음에는 x1 진입(계수 +3): 최소비는 x2 줄 3 ÷ (1/2) = 6, s1 줄 12/4 = 3이므로 s1 탈출. x1 = 3 − (1/4)s1 + (1/2)s2를 대입하면 x2 = 3/2 + (1/8)s1 − (3/4)s2, z = 21 − (3/4)s1 − (1/2)s2로 최적입니다. 경로는 (0, 0) → (0, 3) → (3, 3/2)이며 똑같이 두 번 만에 끝납니다.

7장 연습문제의 LP(최대화 z = 3x1 + 2x2, 제약 2x1 + x2 + s1 = 8, x1 + x2 + s2 = 5, 모두 ≥ 0)를 사전이나 단체표로 풀고 (0, 0) → (4, 0) → (3, 2)로 이동하는 과정을 적으세요.

시작 기저 {s1, s2}: s1 = 8 − 2x1 − x2, s2 = 5 − x1 − x2, z = 3x1 + 2x2. x1 진입, 비 8/2 = 4 < 5/1 = 5이므로 s1 탈출. 첫 피벗 뒤: x1 = 4 − (1/2)x2 − (1/2)s1, s2 = 1 − (1/2)x2 + (1/2)s1, z = 12 + (1/2)x2 − (3/2)s1 (점 (4, 0), z = 12). 다음 x2 진입, 비 4 ÷ (1/2) = 8, 1 ÷ (1/2) = 2이므로 s2 탈출. 둘째 피벗 뒤: x2 = 2 + s1 − 2s2, x1 = 3 − s1 + s2, z = 13 − s1 − s2. 계수가 모두 음수이므로 (3, 2), z = 13이 최적입니다.

최대화 x1 + 2x2, 제약 −x1 + x2 ≤ 2, x1, x2 ≥ 0에 심플렉스법을 적용해, 비유계 판정이 어떻게 나오는지 사전을 적어 보이세요.

여유 변수 s ≥ 0을 넣으면 사전은 s = 2 + x1 − x2, z = x1 + 2x2입니다. 만약 x1을 진입시키면 s 식의 x1 계수가 +1이라 s가 줄지 않고 늘기만 하므로 최소비 검사 후보가 없어 곧바로 비유계입니다. (x2부터 진입시키면 비 2/1 = 2로 s가 탈출해 x2 = 2 + x1 − s, z = 4 + 3x1 − 2s가 되는데, 이어서 x1을 진입시키면 x2 식의 x1 계수가 +1이라 역시 막는 줄이 없어 비유계로 끝납니다.)

제약 x + y ≥ 3과 x + y ≤ 1 (x, y ≥ 0)을 함께 가진 LP에 2단계법을 쓰면 1단계는 어떻게 끝나나요?

등식으로 적으면 x + y − s1 = 3, x + y + s2 = 1입니다. 둘째 식은 s2가 기저가 될 수 있으므로 첫째 식에만 인공 변수 r ≥ 0을 더해 x + y − s1 + r = 3으로 두고 w = r을 최소화합니다. 그런데 둘째 식에서 x + y = 1 − s2 ≤ 1이므로 r = 3 − (x + y) + s1 ≥ 2 + s1 ≥ 2입니다. 따라서 1단계 최적값은 2 > 0이 되고, 원래 문제는 불능으로 판정됩니다.

본문의 제자리걸음 예(x1 ≤ 1, x1 + x2 ≤ 1)의 ①단계에서 비가 1로 동률이었을 때, s1 대신 s2를 탈출시켰다면 다음 사전이 어떻게 달라지나요?

x1 = 1 − x2 − s2를 s1과 z에 넣으면 s1 = 0 + x2 + s2, z = 1 − s2가 됩니다. z 줄에 x2의 계수가 0, s2의 계수가 −1이므로 제자리걸음 피벗을 한 번 더 하지 않고도 곧바로 최적 판정이 납니다. (단, x2 계수가 0이므로 (1, 0) 외에 (0, 1) 등 다른 최적해도 존재합니다.)

본문의 Python 코드에서 진입 변수를 고를 때 "음수 중 첫 번째" 대신 "절댓값이 가장 큰 음수"를 고르면 첫 피벗이 달라질까요? 만약 tab[2]의 초기값이 [-4, -5, 0, 0, 0]이었다면 어떻게 될까요?

공방 예에서는 −5가 이미 첫 번째 음수이고 절댓값도 가장 크므로 첫 피벗이 같습니다. 만약 [-4, -5, 0, 0, 0](이익 4x1 + 5x2)이었다면 본문 코드는 여전히 0번 열 x1부터 진입시키지만, 가장 작은 음수(절댓값이 가장 큰 음수)를 고르면 1번 열 x2부터 진입시킵니다.
