분해 기법: 라그랑지 완화와 열 생성

모형이 너무 크거나 몇 개의 제약이 문제 전체를 묶고 있어 한 번에 풀기 어려울 때, 문제를 쪼개 푸는 두 가지 고전적인 방법이 있습니다. 얽어매는 제약을 지우는 대신 어긴 만큼 벌금을 물리는 라그랑지 완화와, 변수를 "덩어리 하나"로 다시 잡고 필요한 덩어리만 그때그때 만들어 넣는 열 생성입니다. 둘 다 9장의 쌍대성과 14장의 볼록 껍질 위에서 같은 하한을 만들어 냅니다.

  • 미리 알아야 할 것. 9장(제약에 승수를 곱해 더해 하한 만들기, 그림자 가격, 쌍대성), 13장(완화, 상한과 하한, 분지한계법), 14장(정식화의 강도, 볼록 껍질, 이상적 정식화, 완전 단모듈). 3장의 「열로 읽기」와 8장의 감소 비용도 다시 씁니다.
  • 이 장을 읽고 나면. 라그랑지 완화가 어떻게 LP 완화보다 좋은 하한을 만들 수 있는지 산 모양 그래프로 설명하고, 재단 문제에서 쌍대값을 이용해 새 패턴 열을 만드는 과정을 손으로 따라갈 수 있습니다.
1부 · 라그랑지 완화

어려운 제약을 벌금으로 바꾼다

학교 기숙사의 주차 규칙을 떠올려 봅시다. 주차 금지 구역을 콘크리트 벽으로 막아 두면 아예 들어갈 수 없는 제약이 됩니다. 반대로 벽을 치우고 "들어가면 한 번에 과태료 λ만 원을 낸다"고 바꾸면 어떨까요? 과태료가 0원이면 아무나 들어가고, 과태료가 아주 비싸면 아무도 들어가지 않습니다. 적당한 과태료를 정하면 금지 구역 문제를 훨씬 유연하게 다룰 수 있습니다.

13장의 완화는 제약을 아예 지웠습니다. 라그랑지 완화는 어려운 제약을 지우는 대신, 어긴 양에 라그랑지 승수라는 벌금 단가 λ를 곱해 목적함수에 더합니다. 그러면 남은 쉬운 제약만 안고 문제를 풀 수 있고, 놀랍게도 어떤 승수를 고르든 원래 문제의 하한이 나옵니다.

아주 작은 두 변수 예제로 시작합니다. 물건 1(비용 1, 무게 3, 효용 1)과 물건 2(비용 9, 무게 2, 효용 3) 가운데 몇 개를 고릅니다. 배낭 무게 한도 4는 지키기 쉬운 조건으로 두고, "효용 합은 2 이상"이라는 조건을 어려운 제약으로 봅니다.

최소화 x1 + 9x2목적함수
x1 + 3x2 ≥ 2어려운 제약 (떼어 낼 제약)
3x1 + 2x2 ≤ 4,  x1, x2 ∈ {0, 1}쉬운 부분 X

먼저 답 세 가지를 구해 놓습니다. 쉬운 부분 X만 보면 (1, 1)은 무게가 3 + 2 = 5 > 4라 탈락이므로, X에는 세 점 (0, 0), (1, 0), (0, 1)만 남습니다.

  • 정수 최적값 z* = 9. X의 세 점 중 어려운 제약 x1 + 3x2 ≥ 2를 지키는 것은 (0, 1)뿐입니다(0 + 3 = 3 ≥ 2). 비용은 9입니다.
  • LP 완화 값 zLP = 4. 정수 조건을 지워 0 ≤ x1, x2 ≤ 1로 풀면 (1, 1/3)이 무게 3(1) + 2(1/3) = 11/3 ≤ 4와 효용 1 + 3(1/3) = 2를 모두 지킵니다. 비용은 1 + 9(1/3) = 4입니다(다른 꼭짓점 (0, 2/3)은 6, (0, 1)은 9).

이제 어려운 제약 x1 + 3x2 ≥ 2를 떼고, 모자란 양 (2 − x1 − 3x2)에 승수 λ ≥ 0을 곱해 목적함수에 더합니다. X의 세 점 위에서 최솟값을 구하는 새 문제를 적습니다.

L(λ) = 최솟값x∈X [ x1 + 9x2 + λ(2 − x1 − 3x2) ]   (λ ≥ 0)

왜 λ ≥ 0이어야 할까요? 원래 제약을 지키는 해 x*는 x1 + 3x2 ≥ 2이므로 모자란 양 (2 − x1 − 3x2)가 0 이하입니다. 여기에 0 이상인 λ를 곱하면 벌금 항 λ(2 − x1 − 3x2)도 0 이하가 되어, 제약을 넉넉히 지킬수록 오히려 보상을 받습니다. 반대로 제약을 어기면 (2 − x1 − 3x2) > 0이라 벌금을 냅니다.

정의 어려운 제약을 지우는 대신 어긴 양에 승수 λ를 곱해 목적함수에 더한 문제를 라그랑지 완화(Lagrangian relaxation)라고 합니다. 곱해 주는 수 λ를 라그랑지 승수(Lagrangian multiplier), 승수 λ일 때 완화된 문제의 최적값 L(λ)를 라그랑지 쌍대 함수라고 합니다.
핵심 사실 (라그랑지 약쌍대) 최소화 문제에서 ≥ 제약을 떼었을 때 모든 λ ≥ 0에 대해 L(λ) ≤ z*입니다. (등식 제약을 떼면 λ의 부호 제한 없이 L(λ) ≤ z*입니다.)

원래 문제의 최적해 x*는 쉬운 부분 X의 원소이자 어려운 제약을 지키는 해입니다. 따라서 x*에서 벌금 항 λ(2 − x1 − 3x2)는 0 이하이고, x*에서의 목적함수 값은 z* 이하입니다. L(λ)는 X 전체에서의 최솟값이므로 x*에서의 값보다 클 수 없습니다. 곧 L(λ) ≤ z*입니다. 9장의 약쌍대성과 똑같은 논리입니다.

L(λ)의 산 모양 그래프와 라그랑지 쌍대

위의 예에서 X의 점 세 개마다 λ에 따른 식을 적으면 모두 λ의 1차식(직선)이 됩니다.

  • x = (0, 0): 0 + λ(2 − 0) = 2λ
  • x = (1, 0): 1 + λ(2 − 1) = 1 + λ
  • x = (0, 1): 9 + λ(2 − 3) = 9 − λ

L(λ)는 어느 λ에서든 이 세 직선 가운데 가장 낮은 값입니다. λ = 0이면 세 직선의 값이 0, 1, 9이므로 가장 작은 L(0) = 0이 (0, 0)에서 나옵니다. λ가 1을 넘으면 1 + λ가 2λ보다 낮아지고, λ = 4에서 1 + 4 = 5와 9 − 4 = 5가 만납니다. λ가 4보다 커지면 9 − λ가 가장 낮아져 값이 내려갑니다.

어느 λ에서든 L(λ) ≤ z*이므로, 우리가 원하는 것은 이 산의 가장 높은 꼭대기입니다.

정의 모든 허용되는 승수 λ 가운데 가장 큰(좋은) 하한을 찾는 문제를 라그랑지 쌍대(Lagrangian dual)라고 하고, 그 값을 LD = 최댓값λ ≥ 0 L(λ)로 적습니다.

이 예에서 산의 꼭대기는 λ = 4일 때 LD = 5입니다. 정수 조건을 통째로 지웠던 LP 완화 값 4보다 1만큼 더 강한 하한입니다.

부분 기울기법으로 산 정상 찾기

그림에서는 세 직선을 그려 눈으로 꼭대기를 찾았지만, 실제 문제에는 X의 점이 수백만 개이고 승수 λ도 수백 개일 수 있습니다. 그래프를 다 그릴 수 없으니, 한 점에서 출발해 조금씩 산을 올라가야 합니다.

고등학교 미적분에서 함수의 최댓값을 찾으려면 미분계수 f'(λ)가 0인 곳을 찾았습니다. 그런데 L(λ) 그래프를 보세요. 꼭대기인 λ = 4는 뾰족하게 꺾인 점입니다. 왼쪽 기울기는 +1, 오른쪽 기울기는 −1이라서 미분이 되지 않고, 기울기가 0인 지점도 없습니다. 그래도 산을 오르는 방향은 아주 쉽게 알 수 있습니다.

현재 λ에서 L(λ)를 구할 때 고른 해 x(λ)의 어긴 양 g = 2 − x1 − 3x2를 보세요.

  • 제약을 어겼으면(g > 0) 벌금 λ가 아직 너무 싸다는 뜻이니 λ를 올립니다. 실제로 그래프에서도 이때 직선의 기울기가 g > 0이라 오른쪽으로 가면 올라갑니다.
  • 제약을 넉넉히 지켰으면(g < 0) 벌금 λ가 너무 비싸다는 뜻이니 λ를 내립니다. 이때 직선의 기울기도 g < 0이라 왼쪽으로 가면 올라갑니다.

이 어긴 양 g를 부분 기울기(subgradient)라고 합니다. 승수 하나를 정하고 문제를 푼 뒤, 부분 기울기 방향으로 한 걸음 옮기는 일을 되풀이하는 방법이 부분 기울기법(subgradient method)입니다.

λ ← max(0, λ + st · g)   (g = 어긴 양, st는 t번째 걸음 크기)

걸음 크기 st는 처음에는 크게 내딛고 갈수록 줄입니다(예: st = 2 ÷ (t + 1)). 단, λ ≥ 0이어야 하므로 0 아래로 내려가면 0으로 되돌립니다. Python으로 위 예제에 대해 이 과정을 7걸음 돌려 봅니다.

def lagrange(lam):
    items = [(0, 0), (1, 0), (0, 1)]
    best_v = None
    best_x = None
    for x1, x2 in items:
        val = 1 * x1 + 9 * x2 + lam * (2 - x1 - 3 * x2)
        if best_v is None or val < best_v:
            best_v = val
            best_x = (x1, x2)
    g = 2 - best_x[0] - 3 * best_x[1]
    return best_v, best_x, g

lam = 0.0
best_ld = 0.0
for t in range(7):
    val, x, g = lagrange(lam)
    if val > best_ld:
        best_ld = val
    print(t, round(lam, 3), x, round(val, 3), g)
    step = 2.0 / (t + 1)
    lam = max(0.0, lam + step * g)
print("best_ld =", round(best_ld, 3))

  • 1~11행 주어진 승수 lam에서 X의 세 점 (0, 0), (1, 0), (0, 1)을 모두 넣어 보고 가장 작은 값과 그때의 해 best_x, 어긴 양 g를 돌려줍니다.
  • 13~14행 승수 lam은 0에서 시작하고, 지금까지 찾은 가장 큰 하한을 best_ld에 따로 기억합니다.
  • 15~21행 일곱 번 반복하면서 매번 L(lam)을 계산하고, 걸음 크기 2.0 / (t + 1)만큼 g 방향으로 승수를 고칩니다.

출력에서 두 가지 중요한 성질을 읽을 수 있습니다.

  • L(λ)는 매 걸음 오르지 않습니다. t = 1에서 5.0을 찍었다가 t = 2에서 4.0으로 내려갑니다. 꼭대기를 지나쳤기 때문입니다. 그래서 지금까지 본 최댓값 best_ld를 반드시 따로 챙겨 두어야 합니다.
  • 어긴 양 g가 0이 되지 않아도 꼭대기에 있을 수 있습니다. t = 1에서 λ = 4.0일 때 x = (1, 0)을 골라 g = +1이 나왔지만, 사실 그 자리가 꼭대기였습니다. 꺾인 점에서는 한쪽 기울기가 +1이고 반대쪽 기울기가 −1이라 g = 0이 나오지 않습니다. 대신 걸음이 줄어들수록 꼭대기 λ = 4 주변을 좁게 오갑니다.

부분 기울기법이 쓸모 있는 진짜 이유는 분해(decomposition)에 있습니다. 예를 들어 트럭 두 대가 고객들을 나눠 맡는 문제에서, "고객마다 한 대가 방문해야 한다"는 결합 제약만 승수로 떼어 내면 어떻게 될까요? 남는 문제는 트럭 A 혼자만의 문제와 트럭 B 혼자만의 문제로 완전히 갈라집니다. 덩치 큰 문제 하나를 푸는 대신 작은 문제 여러 개를 따로 풀고 승수만 맞춰 가는 것이 라그랑지 분해의 힘입니다.

왜 LP 완화보다 강해질 수 있나

위의 작은 예에서 왜 LP 완화는 4이고 라그랑지 쌍대는 5였을까요? 14장의 볼록 껍질로 보면 한눈에 설명됩니다.

쉬운 부분 X = {(0, 0), (1, 0), (0, 1)}의 LP 완화 3x1 + 2x2 ≤ 4는 점 (1, 1/3)을 허용해서 비용을 4까지 끌어내렸습니다. 그런데 X의 세 점에 고무줄을 걸어 만든 볼록 껍질 conv(X)는 삼각형 x1 + x2 ≤ 1(x1, x2 ≥ 0)입니다. 점 (1, 1/3)은 합이 4/3 > 1이라 이 삼각형 밖에 있습니다.

라그랑지 완화 L(λ)는 X를 정수로 그대로 두고 풀기 때문에, 사실상 쉬운 부분 X를 그 볼록 껍질 conv(X)로 바꾼 뒤 어려운 제약을 건 것과 같은 효과를 냅니다. 삼각형 x1 + x2 ≤ 1 위에서 x1 + 3x2 ≥ 2를 지키며 x1 + 9x2를 최소화하면, 두 식의 경계가 만나는 (1/2, 1/2)에서 값 1(1/2) + 9(1/2) = 5가 나옵니다. 바로 LD = 5입니다.

핵심 사실 쉬운 부분 X의 LP 완화를 PX라 하면 다음이 성립합니다.
  1. 언제나 zLP ≤ LD ≤ z*입니다.
  2. LD는 "x ∈ conv(X)이고 어려운 제약을 지킨다"는 LP의 최적값과 같습니다.
  3. 만약 PX 자체가 이미 conv(X)와 같으면(14장의 이상적 정식화, 예를 들어 완전 단모듈 행렬이면), LD = zLP가 되어 하한이 더 좋아지지는 않습니다.

세 번째 성질이 중요합니다. 무엇을 어려운 제약으로 떼어 낼지 잘 골라야 합니다. 남은 쉬운 부분 X가 이미 14장의 완전 단모듈처럼 LP로 풀어도 정수가 나오는 모양이라면, 라그랑지 쌍대는 계산을 쪼개 빠르게 해 줄 수는 있어도 하한 숫자는 LP 완화와 똑같습니다. 반대로 배낭 제약처럼 LP 완화가 느슨한 부분을 X에 남겨 정수로 풀면, 라그랑지 쌍대가 LP 완화보다 높은 하한을 만들어 냅니다.

2부 · 열 생성

변수를 「덩어리 하나」로 다시 적기

2부에서는 기호 약속을 하나 바꿉니다. 1부에서 λ는 벌금 승수였지만, 열 생성에서는 관례대로 덩어리(열)를 몇 번 쓰는지의 가중치를 λ로 적고, 제약에 붙는 쌍대값(가격)을 π로 적습니다.

앞 절의 핵심 사실 2를 다시 읽어 봅시다. 라그랑지 쌍대 LD가 좋은 이유는 쉬운 부분 X를 그 볼록 껍질 conv(X)로 다룬 덕분이었습니다. 그렇다면 아예 처음부터 "X에 속하는 점(가능한 덩어리 계획) 하나하나"를 결정변수로 삼아 LP를 적으면 어떨까요?

이때 3장의 「열로 읽기」가 빛을 발합니다. 3장에서 행렬 A의 한 열은 "변수 1단위가 쓰거나 만들어 내는 자원의 명세서"였습니다. 이번에는 그 명세서 한 줄(한 열)이 "작은 계획을 한 번 실행했을 때 나오는 결과 전체"입니다. 이런 재정식화를 제안자의 이름을 따 Dantzig–Wolfe 재정식화라고 부릅니다.

문제는 가능한 덩어리의 수가 수백만, 수억 개나 된다는 점입니다. 변수를 전부 적고 시작할 수조차 없습니다. 해법은 8장 심플렉스법의 감소 비용입니다. 심플렉스법은 수많은 비기저 변수 중에서 감소 비용이 음수인 변수 하나만 찾으면 다음 피벗으로 넘어갈 수 있고, 감소 비용이 음수인 변수가 하나도 없으면 지금 답이 최적입니다. 따라서 변수를 처음부터 다 만들지 말고, 그때그때 9장의 쌍대값 π를 이용해 "넣으면 이득인 새 열" 하나만 찾아 붙이면 됩니다.

정의
  • 변수가 엄청나게 많은 전체 LP를 주 문제(master problem), 그중 일부 열만 뽑아 만든 작은 LP를 제한 주 문제(restricted master problem, RMP)라고 합니다.
  • RMP의 쌍대값 π를 받아, 주 문제에 넣었을 때 감소 비용이 음수인 새 열(덩어리)을 찾아내는 보조 문제를 가격 문제(pricing problem)라고 합니다.
  • RMP 풀기 → 가격 문제로 새 열 찾기 → RMP에 추가하기를 반복해 주 문제의 LP 최적값을 구하는 방법을 열 생성(column generation)이라고 합니다.

손계산으로 따라가는 재단 문제

열 생성의 고전적인 예인 재단 문제(cutting stock problem)를 끝까지 손으로 풀어 봅니다. 길이가 10인 원자재 막대를 잘라 길이 3짜리 4개, 길이 4짜리 3개, 길이 5짜리 2개를 만들어야 합니다. 쓰는 막대 수를 가장 적게 하려 합니다.

막대 하나를 자르는 방법을 패턴이라고 부르고 벡터 a = (a1, a2, a3)로 적습니다. 각각 길이 3, 4, 5를 몇 개씩 자르는지 뜻합니다. 길이를 합쳐 10을 넘을 수 없으므로 3a1 + 4a2 + 5a3 ≤ 10을 지키는 0 이상의 정수 벡터여야 합니다. 이 작은 예에서는 0이 아닌 패턴이 모두 11개 있습니다(실제 공장에서는 수백만 개가 됩니다).

각 패턴 p를 쓰는 횟수를 λp로 두면, 주 문제는 다음과 같습니다. 한 열이 패턴 p 하나(3장의 열!)입니다.

최소화 Σp λp쓰는 막대 수
Σp a1pλp ≥ 4,  Σp a2pλp ≥ 3,  Σp a3pλp ≥ 2길이 3, 4, 5의 수요
λp ≥ 0 정수모든 패턴 p (LP 완화에서는 정수 조건 제외)

이제 9장의 쌍대값 π = (π1, π2, π3)를 씁니다. 그림자 가격의 뜻대로 πi는 "길이 i 조각 하나를 만들었을 때 줄어드는 막대 수", 곧 조각 하나의 가치입니다. 어떤 패턴 a = (a1, a2, a3)가 만들어 내는 조각들의 총가치는 3장의 내적으로 π·a = π1a1 + π2a2 + π3a3입니다. 막대 하나를 쓰는 비용은 1이므로, 이 패턴 열의 감소 비용(8장)은 다음과 같습니다.

패턴 a의 감소 비용 = 1 − (π1a1 + π2a2 + π3a3)

감소 비용이 음수이려면 π·a > 1이어야 합니다. 곧 가격 문제는 "길이 10 막대 안에서 π1a1 + π2a2 + π3a3를 최대화하는 정수 배낭 문제"입니다. 최댓값이 1을 넘으면 그 패턴을 새 열로 넣고, 1 이하이면 더 좋은 열이 없으므로 끝입니다.

단계RMP가 가진 패턴 열RMP LP 값쌍대값 π가격 문제가 찾은 패턴감소 비용
0(3,0,0), (0,2,0), (0,0,2)23/6 ≈ 3.83(1/3, 1/2, 1/2)(2, 1, 0), 가치 7/6−1/6 → 추가
1위 셋 + (2, 1, 0)7/2 = 3.5(1/4, 1/2, 1/2)최대 가치 10 → 멈춤

한 줄씩 따라갑니다.

  1. 0단계. 막대마다 한 종류만 자르는 가장 단순한 세 패턴 (3, 0, 0), (0, 2, 0), (0, 0, 2)만으로 시작합니다. 각각 4/3개, 3/2개, 1개씩 쓰면 수요 (4, 3, 2)를 딱 맞추므로 LP 값은 4/3 + 3/2 + 1 = 23/6입니다. 상보 여유성(9장)에 의해 쓰인 세 열의 감소 비용이 0이어야 하므로 3π1 = 1, 2π2 = 1, 2π3 = 1에서 쌍대값 π = (1/3, 1/2, 1/2)가 나옵니다. 길이 3 조각은 1/3막대 가치, 길이 4와 5는 1/2막대 가치라는 뜻입니다.
  2. 가격 문제 풀기. 이 가격으로 길이 10 안에서 가치가 가장 큰 패턴을 찾으면 (2, 1, 0)(길이 3 둘과 길이 4 하나, 합 10)입니다. 가치는 2×(1/3) + 1×(1/2) = 7/6 > 1이므로 감소 비용이 1 − 7/6 = −1/6 < 0입니다. 막대 하나로 7/6막대 몫의 일을 해내니 이득입니다!
  3. 1단계. 새 열 (2, 1, 0)을 RMP에 넣고 LP를 다시 풉니다. (2, 1, 0)을 2번(길이 3 네 개, 길이 4 두 개), (0, 2, 0)을 1/2번(길이 4 하나), (0, 0, 2)를 1번(길이 5 둘) 쓰면 합계가 2 + 1/2 + 1 = 3.5 = 7/2입니다. 이때 쓰인 세 열의 감소 비용이 0이라는 식 2π1 + π2 = 1, 2π2 = 1, 2π3 = 1을 풀면 π = (1/4, 1/2, 1/2)입니다. 이 가격으로 길이 10 안에서 만들 수 있는 최대 가치는 1입니다(예: (2,1,0)이 2×(1/4)+1/2 = 1). 감소 비용이 0보다 작은 패턴이 하나도 없으므로 3.5가 11개 패턴 전체를 다 넣은 주 문제의 LP 최적값입니다.

LP 값이 3.5이고 쓰는 막대 수는 정수여야 하므로 13장의 천장 논증에 따라 ⌈3.5⌉ = 4개 이상 필요합니다. 실제로 (2, 1, 0) 2개, (0, 0, 2) 1개, (0, 1, 0) 1개면 총 4개로 수요를 모두 맞춥니다. 4개가 정수 최적입니다.

이 정식화가 얼마나 강한지도 비교해 봅시다. 패턴을 쓰지 않고 "k번째 막대에서 길이 i를 몇 개 자르는가"로 직접 식을 세우면, 전체 필요한 길이가 3×4 + 4×3 + 5×2 = 34이므로 LP 완화는 막대를 소수로 쪼개 34 ÷ 10 = 3.4를 줍니다. 패턴 정식화의 LP 값 3.5가 더 강합니다. 막대 하나 안에서 길이를 10 이하 정수로 채우는 배낭 구조가 이미 열(conv(X)) 안에 녹아 있기 때문입니다.

분지가격법과 택배 트럭 경로 문제

재단 문제의 LP 해에는 λ2 = 1/2처럼 소수가 남아 있었습니다. 소수가 나오면 13장처럼 가지를 나눠야 합니다. 분지한계법의 가지마다 열 생성으로 LP를 푸는 방법을 분지가격법(branch-and-price)이라고 합니다.

여기서 조심할 점이 하나 있습니다. 주 문제의 변수 λp가 1/2이라고 해서 "λp = 0"인 가지와 "λp = 1"인 가지로 직접 나누면 어떻게 될까요? λp = 0으로 막아 놓은 가지에서도, 가격 문제가 방금 금지한 바로 그 패턴 p를 또 가장 좋은 새 열로 만들어 낼 수 있습니다. "이 패턴 한 개만은 만들지 마라"는 조건을 가격 문제에 넣는 것은 매우 까다롭습니다.

그래서 분지가격법에서는 주 문제의 가중치 λp 대신 원래 문제의 뜻으로 분지합니다. 예를 들어 "두 주문 i와 j를 같은 막대(같은 경로)에 넣는가, 따로 넣는가", 혹은 경로 문제라면 "간선 (i, j)를 쓰는가, 쓰지 않는가"로 나눕니다. 이런 조건은 가격 문제(배낭이나 최단 경로) 안에도 아주 자연스럽게 들어갑니다.

12장에서 본 택배 트럭 경로 문제가 바로 분지가격법의 대표적인 무대입니다.

  • 12장의 3첨자 모형은 트럭의 순서(xijk)와 시각(tik)을 변수로 두었고, 시간창 때문에 약한 big-M 제약이 들어가 LP 완화가 느슨했습니다.
  • 대신 "트럭 한 대가 차고지에서 출발해 용량과 시간창을 지키며 고객 몇 명을 돌고 돌아오는 유효한 경로 전체"를 열 하나 r로 삼습니다. 주 문제는 12장의 집합 분할 꼴인 Σr airλr = 1 (모든 고객 i가 정확히 한 경로에 들어간다)이 됩니다.
  • 가격 문제는 고객 i마다 받은 쌍대값 πi를 보상으로 여겨, "이동 비용 − 방문 고객 보상 πi" 합이 가장 작은 유효 경로 하나를 찾는 문제가 됩니다.

경로 하나 안에 용량, 시간창, 부분 순환 금지가 모두 정수로 들어 있고 big-M이 사라지기 때문에 LP 완화 하한이 훨씬 빡빡해집니다. 열 생성과 분지가격법은 택배 트럭 경로 문제에서 가장 강력한 정확해법으로 쓰입니다.

세 하한의 관계

13장부터 15장까지 배운 세 가지 하한을 한 줄에 세웁니다. 원래 정수계획 문제를 "쉬운 부분 X + 얽어매는 제약"으로 나누었을 때 다음 부등식이 언제나 성립합니다.

zLP ≤ LD = zDW ≤ z*
  • zLP: 원래 직접 모형의 LP 완화 값 (13장).
  • LD: 얽어매는 제약을 벌금으로 뗀 라그랑지 쌍대의 최적값 (15장 1부).
  • zDW: 같은 쉬운 부분 X의 해들을 열(덩어리)로 삼아 Dantzig–Wolfe 재정식화한 주 문제의 LP 값 (15장 2부).
  • z*: 원래 문제의 진짜 정수 최적값.

앞의 산 모양 예제에서도 zLP = 4 ≤ LD = 5 ≤ z* = 9가 확인되었고, 재단 문제에서도 직접 정식화 LP(3.4) ≤ 열 생성 LP(3.5) ≤ 정수 최적(4)이 성립했습니다. LD와 zDW가 항상 같은 이유는, 둘 다 똑같이 "쉬운 부분 X를 그 볼록 껍질 conv(X)로 바꿔 놓고 얽어매는 제약을 맞춘다"는 같은 일을 하기 때문입니다. 다만 라그랑지 완화는 승수 λ(쌍대 쪽)를 움직여 올라가고, 열 생성은 열의 가중치 λ(원시 쪽)를 쌓아 가며 쌍대값 π로 가격을 매긴다는 방향만 다릅니다.

이 때문에 두 방법은 서로 장단점이 엇갈립니다. 라그랑지 완화는 매번 LP를 풀지 않고 가벼운 부분 기울기 걸음만으로 빠르게 하한을 얻을 수 있고, 열 생성은 LP를 푸는 대신 분지한계법과 결합하기 좋은 소수 원시 해를 바로 내어 줍니다.

가이드와 연결

가이드는 풀이의 발전 방향으로 「중간 항구의 배치를 먼저 정해서 둘로 가르기」, 「라그랑지 완화」, 「분지가격법」을 소개합니다. 이 가운데 중간 항구 배치를 고정하는 방법은 하한을 주지 않는 휴리스틱(13장의 일부를 고정하고 풀기)이고, 뒤의 둘이 이 장에서 배운 분해 기법입니다.

가이드는 tryAgain 모형에서 x와 y를 잇는 제약 ②③④를 벌금으로 돌려 "칸 배정"과 "접근 가능성"으로 가르는 라그랑지 완화를 예로 듭니다. 14장에서 확인했듯이 공식 예시의 LP 완화가 145(정수 최적 190)이므로 라그랑지 쌍대가 하한을 더 끌어올릴 여지는 있지만, 떼고 남은 부분 문제가 정수성 성질을 가지면(PX = conv(X)) 하한은 LP와 같아집니다. 실제로 얼마나 오르는지는 이 교재에서 계산하지 않았습니다.

가이드는 또한 "칸 하나가 항해 전체 동안 받는 구간들의 일정"을 열 하나로 삼는 분지가격법 아이디어를 듭니다. 구간이 겹치지 않는다는 제약 ②는 한 열 안의 일정에 자연스럽게 녹아들지만(14장의 구간 행렬), 접근 가능성 제약 ⑤가 이웃한 여러 칸을 서로 묶기 때문에 가격 문제가 칸별로 깔끔히 나뉘지 않는다는 설계상의 어려움이 있습니다.

  • 라그랑지 완화는 어려운 제약을 지우는 대신 어긴 양 × 승수 λ의 벌금을 목적함수에 더하며, 모든 허용 λ에서 원래 최적값의 하한 L(λ)을 줍니다.
  • L(λ)는 꺾인 산 모양(오목 함수)이고, 부분 기울기법(g = 어긴 양)으로 꼭대기 LD를 향해 올라갑니다. 매 걸음 값이 오르지는 않으므로 최댓값을 따로 기록합니다.
  • 열 생성은 3장의 "열로 읽기"와 9장의 쌍대값 π를 결합해, 제한 주 문제(RMP)와 가격 문제를 오가며 감소 비용이 음수인 덩어리 열만 추가합니다.
  • 분지가격법은 열 생성을 분지한계법 각 가지에 넣어 푸는 방법이며, 택배 트럭 경로 문제의 대표적인 정확해법입니다.
  • 같은 분해에 대해 세 하한은 zLP ≤ LD = zDW ≤ z*를 만족하며, 쉬운 부분 X에 정수성 성질이 없을 때만 LP 완화보다 강한 하한을 얻습니다.

연습문제

어려운 제약 x1 + 3x2 ≥ 2 대신 부등호 방향이 반대인 x1 + 3x2 ≤ 2를 떼어 낸다면, 승수 λ의 부호와 벌금 항은 어떻게 바뀌어야 하나요?

제약을 지키는 해에서 "넘친 양"은 x1 + 3x2 − 2 ≤ 0입니다. 따라서 λ ≥ 0에 대해 목적함수에 + λ(x1 + 3x2 − 2)를 더하면 제약을 지키는 해에서 벌금 항이 0 이하가 되어 L(λ) ≤ z*가 성립합니다. (2 − x1 − 3x2) 꼴을 그대로 쓰려면 λ ≤ 0이어야 합니다.

본문의 2변수 예제(L(λ) = min(2λ, 1 + λ, 9 − λ))에서 λ = 2.5일 때 L(2.5)와 부분 기울기 g, 그리고 부분 기울기법에서 λ가 커지는지 작아지는지 구하세요.

세 직선의 값은 2(2.5) = 5, 1 + 2.5 = 3.5, 9 − 2.5 = 6.5이므로 최솟값 L(2.5) = 3.5이고 x = (1, 0)이 선택됩니다. 어긴 양 g = 2 − 1 − 0 = +1 > 0이므로 λ는 커지는 쪽(꼭대기 λ = 4 쪽)으로 움직입니다.

부분 기울기법에서 t = 1일 때 L(4) = 5였는데 t = 2에서 L(5) = 4로 내려갔습니다. 알고리듬이 고장 난 것인가요?

고장 난 것이 아닙니다. 꼭대기 λ = 4에서 그래프가 꺾여 있어 부분 기울기 g = +1이 0이 되지 않았고, 걸음 크기 s1 = 1만큼 오른쪽으로 넘어간 λ = 5에서는 다른 직선(9 − λ)이 선택되면서 값이 4로 떨어졌습니다. 부분 기울기법에서는 이런 일이 흔하므로 지금까지 얻은 가장 좋은 값 best_ld = 5.0을 따로 저장해 둡니다.

재단 문제에서 1단계의 쌍대값이 π = (1/4, 1/2, 1/2)일 때, 패턴 (3, 0, 0)과 (0, 1, 1)의 감소 비용은 각각 얼마인가요? 둘 중 주 문제에 추가할 만한 열이 있나요?

(3, 0, 0)의 가치는 3×(1/4) = 3/4이므로 감소 비용은 1 − 3/4 = +1/4 > 0입니다. (0, 1, 1)의 가치는 1/2 + 1/2 = 1이므로 감소 비용은 1 − 1 = 0입니다. 둘 다 음수가 아니므로 추가할 필요가 없습니다.

분지가격법에서 주 문제의 소수 변수 λp = 0.5를 보고 "λp = 0"과 "λp = 1"로 직접 분지하지 않고 원래 문제의 조건으로 분지하는 이유를 말하세요.

λp = 0인 가지에서는 그 패턴 p만 빼야 하는데, 가격 문제가 방금 금지한 바로 그 패턴 p를 다시 최적 열로 찾아 낼 수 있기 때문입니다. "두 항목을 함께 자른다 / 따로 자른다"처럼 원래 문제의 구조로 분지해야 가격 문제에도 자연스럽게 조건을 넣을 수 있고, 양쪽 가지의 균형도 잘 맞습니다.

어떤 문제의 쉬운 부분 X를 정할 때, PX가 이미 완전 단모듈(TU)이고 오른쪽 수가 정수입니다. 라그랑지 쌍대값 LD는 원래 LP 완화 값 zLP보다 커질 수 있나요?

커질 수 없습니다. TU 행렬과 정수 오른쪽 수로 된 다면체 PX는 이미 볼록 껍질 conv(X)와 같기 때문에(14장), X를 정수로 풀어도 conv(X) 위에서 푸는 것과 같아져 LD = zLP가 됩니다. 다만 문제를 여러 작은 조각으로 쪼개 빠르게 푸는 계산상의 이점은 여전히 있을 수 있습니다.
