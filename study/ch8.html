정수계획 모델링: 논리·스위치·흐름·연결성을 1차 부등식으로

4~7장의 LP는 변수가 실수라서 가능 영역이 다면체 하나였습니다. 이 장에서는 변수 일부가 정수, 특히 0 아니면 1이어야 한다는 조건을 더합니다. 그러면 "한다/안 한다", "이것이면 저것", "켜야 쓸 수 있다", "전체가 하나로 이어져 있다" 같은 조합적인 조건을 1차 부등식만으로 적을 수 있게 됩니다.

가이드 3장은 이런 요령(관용구)을 표로 보여 줍니다. 이 장은 같은 요령을 왜 그 식이 그 뜻이 되는지 증명할 수 있는 수준으로 다룹니다. 진리표로 확인하는 방법, 논리식을 기계적으로 부등식으로 바꾸는 규칙, big-M의 M을 가장 작게 고르는 계산, 그리고 부분 순환을 막는 식(MTZ)이 정말로 "부분 순환만" 막고 정상적인 순환은 하나도 막지 않는다는 양방향 증명이 들어 있습니다. 마지막 부에서는 tryAgain이 연결성을 적은 방법(높이를 따라 접근 가능성을 전파하는 식)을 MTZ, 흐름 식과 나란히 놓고 비교합니다.

솔버가 이런 모형을 어떻게 푸는지는 9장, 같은 조건을 적는 여러 방법 중 어느 것이 "더 좋은지"를 재는 이론은 10장에서 다룹니다. 이 장은 "맞게 적는 법"에 집중합니다.

1부 · 정수 조건이 더해진 LP

IP와 MIP

정의 8.1 정수계획(integer program, IP)은 LP(4장)에 "모든 변수는 정수"라는 조건을 더한 문제입니다. 혼합정수계획(mixed-integer program, MIP)은 변수 일부만 정수여야 하는 문제입니다. 값이 0 또는 1뿐인 정수 변수를 이진변수(binary variable)라고 하고, x ∈ {0, 1}로 적습니다. 목적함수와 제약은 여전히 1차식이어야 합니다(그래서 MILP, ILP라고도 부릅니다).

식으로 쓰면 MIP는 다음 꼴입니다. 변수를 정수 쪽 x와 실수 쪽 w로 나눕니다.

최소화  cTx + dTw
제약   Ax + Gw ≥ b,  x ≥ 0,  w ≥ 0
         x의 성분은 모두 정수이것 하나가 LP와의 차이

정수 조건 한 줄이 문제의 성격을 바꿉니다. LP의 가능 영역은 다면체(2장)라서 볼록하고, 최적해가 꼭짓점에 있으며(4장), 심플렉스법이나 내부점법으로 빠르게 풀립니다. IP의 가능해 집합은 다면체 안의 정수 격자점들, 곧 띄엄띄엄 떨어진 점의 모임입니다. 볼록하지 않으니 "이웃 꼭짓점으로 옮겨 가며 좋아지는 방향"이라는 심플렉스의 논리가 통하지 않고, 점이 유한하더라도 그 수가 변수 개수에 대해 지수적으로 많습니다. 이진변수 n개면 후보가 2n개입니다. IP는 일반적으로 NP-hard입니다. NP는 "답이 주어지면 그것이 맞는지를 다항 시간에 확인할 수 있는 문제들"이고, NP-hard는 NP의 모든 문제를 다항 시간 변환으로 이 문제로 바꿀 수 있는, 곧 적어도 NP의 어느 문제만큼은 어려운 부류입니다. 이 부류의 어느 문제에도 다항 시간 알고리듬은 알려져 있지 않습니다.

그런데도 MIP가 널리 쓰이는 이유는 두 가지입니다. 하나는 표현력입니다. 이 장에서 보듯이 이진변수와 1차 부등식만으로 거의 모든 조합적 조건을 적을 수 있습니다. 다른 하나는 LP를 발판으로 쓸 수 있다는 점입니다. 정수 조건만 지우면 LP가 되고, 그 LP의 값이 원래 문제의 하한이 됩니다. 이것이 9장의 분지한계법의 출발점입니다.

모델링의 목표: 정수해 집합을 정확히 잘라 내기

모형을 적는다는 것은 "내가 허용하고 싶은 해들의 집합"을 정수 격자점의 집합으로 정확히 표현하는 일입니다. 맞게 적었다는 것은 두 방향을 모두 뜻합니다.

  • 건전성(soundness): 식을 만족하는 정수해는 모두 실제로 허용되는 해다. (엉터리 해를 들이지 않는다.)
  • 완전성(completeness): 실제로 허용되는 해는 모두 (적절한 보조 변수 값과 함께) 식을 만족한다. (멀쩡한 해를 잘라 내지 않는다.)

휴리스틱을 짤 때 "이웃 연산이 불가능해를 만들지 않는가"와 "모든 가능해에 도달할 수 있는가"를 따지던 것과 비슷한 두 방향입니다. 이 장의 증명은 대부분 이 두 방향을 하나씩 확인하는 모양입니다. 하나만 확인하고 넘어가면 흔히 사고가 납니다. 예를 들어 big-M을 너무 작게 잡으면 건전하지만 완전하지 않고(멀쩡한 해가 잘림), 부분 순환을 막는 식을 빼먹으면 완전하지만 건전하지 않습니다(엉터리 해가 들어옴).

2부 · 논리를 부등식으로

진리표로 확인하기

이진변수 a를 명제 "a를 한다"의 참(1)/거짓(0)으로 읽습니다. 이진변수 몇 개에 대한 부등식이 어떤 논리식과 같은 뜻인지는 모든 0/1 조합을 넣어 보면 확인됩니다. 변수가 k개면 조합이 2k개라 손으로도 됩니다. 예로 "a이면 b 또는 c"(a → b ∨ c)와 부등식 a ≤ b + c를 비교합니다.

abca → (b ∨ c)a ≤ b + c

001참0 ≤ 1 성립
010참0 ≤ 1 성립
011참0 ≤ 2 성립
100거짓1 ≤ 0 위반
101참1 ≤ 1 성립
110참1 ≤ 1 성립
111참1 ≤ 2 성립

여덟 줄 모두에서 "논리식이 참"과 "부등식 성립"이 일치합니다. 따라서 이진변수 위에서는 두 표현이 정확히 같은 뜻입니다(건전하고 완전함). 이 확인법은 어떤 관용구에도 쓸 수 있습니다. 이 장에 나오는 논리 관용구는 모두 이 방법으로 검산했습니다.

기계적인 변환: 절 하나 = 부등식 하나

진리표는 확인용이고, 식을 만드는 데는 다음 규칙이 편합니다. 논리학에서 리터럴(literal)은 명제 a 또는 그 부정 ¬a를 말하고, 절(clause)은 리터럴 몇 개를 "또는(∨)"으로 이은 것입니다. 예: a ∨ ¬b ∨ c.

정리 8.2 (절의 부등식 표현) 이진변수 위에서 절 "xj (j ∈ S) 중 하나 이상이 1이거나, xj (j ∈ T) 중 하나 이상이 0이다"는 다음 부등식과 같은 뜻이다.
Σj∈S xj + Σj∈T (1 − xj) ≥ 1

리터럴 xj는 xj = 1일 때 참이고, 리터럴 ¬xj는 1 − xj = 1일 때 참입니다. 따라서 왼쪽은 "참인 리터럴의 개수"입니다. 절이 참 ⇔ 참인 리터럴이 하나 이상 ⇔ 왼쪽 ≥ 1. ∎

모든 논리식은 절 여러 개를 "그리고(∧)"로 이은 꼴(합의 곱 꼴, 논리곱 표준형 CNF)로 바꿀 수 있고, "그리고"는 부등식을 여러 줄 쓰는 것이므로, 이진변수에 대한 어떤 논리 조건도 1차 부등식 몇 줄로 적을 수 있습니다. 자주 쓰는 것을 이 규칙으로 만들어 봅니다. "p → q"는 "¬p ∨ q"와 같다는 것만 기억하면 됩니다.

하고 싶은 말절로 바꾸면정리 8.2를 적용정리하면
a이면 b¬a ∨ b(1 − a) + b ≥ 1a ≤ b
a와 b를 둘 다 할 수는 없다¬a ∨ ¬b(1 − a) + (1 − b) ≥ 1a + b ≤ 1
a이면 b 또는 c¬a ∨ b ∨ c(1 − a) + b + c ≥ 1a ≤ b + c
a와 b를 다 하면 c¬a ∨ ¬b ∨ c(1 − a) + (1 − b) + c ≥ 1c ≥ a + b − 1
셋 중 적어도 하나a ∨ b ∨ ca + b + c ≥ 1a + b + c ≥ 1
셋 중 많아야 하나모든 쌍에 ¬a ∨ ¬b 등 세 절a + b ≤ 1, a + c ≤ 1, b + c ≤ 1한 줄로 a + b + c ≤ 1 (아래 설명)

마지막 줄은 규칙대로 하면 쌍마다 한 줄씩 세 줄이 나옵니다. 이진변수 위에서는 한 줄 a + b + c ≤ 1과 같은 뜻입니다(둘 이상이 1이면 어느 쪽이든 위반). 같은 정수해 집합을 적는 방법이 여럿일 수 있다는 첫 번째 예입니다. 정수해만 보면 둘은 같지만, 정수 조건을 지운 LP에서는 다릅니다. a = b = c = 1/2은 쌍별 세 줄(1/2 + 1/2 ≤ 1)은 모두 지키지만 한 줄짜리(3/2 ≤ 1)는 어깁니다. 한 줄짜리가 소수 해를 더 많이 쳐냅니다. 이 차이가 왜 중요한지는 10장의 주제입니다.

한 방향 함의와 양방향 동치

a ≤ b는 "a이면 b"일 뿐입니다. b = 1, a = 0도 허용합니다. "a일 때 그리고 그때에만 b"(a ↔ b)를 원하면 반대 방향 b ≤ a도 적어 a = b로 만들어야 합니다. 조금 더 복잡한 양방향 정의도 같은 방식입니다.

정의하고 싶은 것식각 줄의 역할
a = b ∨ c (a는 "b나 c 중 하나라도 하면 1")a ≥ b, a ≥ c, a ≤ b + c앞의 둘: b나 c가 1이면 a = 1. 셋째: 둘 다 0이면 a = 0
a = b ∧ c (a는 "둘 다 하면 1")a ≤ b, a ≤ c, a ≥ b + c − 1앞의 둘: 하나라도 0이면 a = 0. 셋째: 둘 다 1이면 a = 1

실전에서는 한 방향만 적고 끝내는 경우가 많습니다. 반대 방향이 최적화 때문에 저절로 성립하기 때문입니다. 이것을 정확하게 말하면 다음과 같습니다.

정리 8.3 (쓸모없는 스위치는 꺼진다) 최소화 문제에서 이진변수 y가 목적함수 계수 f > 0을 가지고, y는 "xj ≤ y" 꼴의 제약에서만 오른쪽에 나타난다고 하자. 그러면 모든 최적해에서, xj가 모두 0이면 y = 0이다. (xj가 이진이면 "어떤 xj도 1이 아니면"과 같은 말입니다.)

반대 방향은 정리가 아니라 제약 xj ≤ y 자체가 해 줍니다. 0 ≤ xj ≤ 1인 xj 가운데 양수인 것이 하나라도 있으면 이진변수 y는 1일 수밖에 없습니다.

최적해에서 y = 1인데 xj가 모두 0이라고 합시다. y만 0으로 바꾼 해를 봅니다. y가 나오는 제약은 xj ≤ y뿐이고 xj = 0 ≤ 0이므로 모두 지켜집니다. 다른 제약에는 y가 없으니 영향이 없습니다. 목적함수는 f > 0만큼 줄어듭니다. 원래 해가 최적이라는 가정에 모순입니다. ∎

가이드 3장의 창고 예가 이 정리입니다. 창고를 여는 비용 f(목적함수에서 y의 계수)가 양수라서 "보내지도 않을 창고를 여는 해"는 최적해로 나오지 않습니다. 계수가 0이면(f = 0) 정리가 성립하지 않습니다. 그때는 y = 1, x = 0인 해가 최적해에 섞일 수 있습니다. 그것이 해롭지 않은지는 따로 따져야 합니다. tryAgain 모형의 y가 바로 목적함수 계수가 0인 경우입니다(모형은 이 장 6부에 적습니다. 가이드 6장의 마지막 이해 확인 문제이기도 합니다).

3부 · 스위치로 제약을 켜고 끄기

big-M과 가장 작은 M

"이진변수 x가 1일 때만 부등식 g(t) ≤ 0을 적용한다"(t는 실수 변수들)는 조건문입니다. 1차식만 허용되므로, 스위치가 꺼졌을 때 제약이 저절로 성립할 만큼 오른쪽을 느슨하게 만듭니다.

정의 8.4 (big-M 제약) 상수 M을 써서 g(t) ≤ M(1 − x)로 적는 것을 big-M 제약이라고 한다. x = 1이면 g(t) ≤ 0, x = 0이면 g(t) ≤ M이다. M이 유효(valid)하다는 것은 다른 모든 제약을 지키는 모든 t에 대해 g(t) ≤ M이라는 뜻이다. 즉 M ≥ max g(t) (다른 제약 아래에서의 최댓값)이면 된다.

M이 유효하면 x = 0일 때 제약은 아무것도 자르지 않습니다(완전성). M이 그보다 작으면 x = 0인데도 일부 t가 잘려 나가 멀쩡한 해를 잃습니다. 반대로 M을 필요 이상으로 크게 잡으면 정수해 집합은 그대로지만, 정수 조건을 지운 LP에서 x가 1보다 조금만 작아도(예: x = 0.9이면 오른쪽이 0.1M) 제약이 사실상 꺼져 버려 LP가 실제 문제를 잘 흉내 내지 못합니다. 그래서 원칙은 유효한 것 중 가장 작은 M입니다. 그 값은 대개 다른 제약에서 바로 계산됩니다.

예: CVRPTW 시간 선후 제약의 M

xij는 "고객 i 다음에 바로 j"이면 1, ti는 i의 서비스 시작 시각, si는 서비스 시간, τij는 이동 시간, [ai, bi]는 시간창입니다. 원하는 조건은 "xij = 1이면 tj ≥ ti + si + τij"입니다. g = ti + si + τij − tj ≤ 0을 켜고 끄면 됩니다.

tj ≥ ti + si + τij − Mij(1 − xij)

Mij는 g의 최댓값 이상이어야 합니다. 시간창 때문에 ti ≤ bi, tj ≥ aj이므로 g가 가장 커지는 것은 ti = bi, tj = aj일 때입니다.

Mij = max g = bi + si + τij − aj

숫자로 해 봅니다. bi = 50, si = 10, τij = 15, aj = 20이면 Mij = 50 + 10 + 15 − 20 = 55입니다. 확인: xij = 0이고 최악의 경우 ti = 50, tj = 20이어도 오른쪽은 50 + 10 + 15 − 55 = 20이라 tj = 20 ≥ 20이 성립합니다. M = 54로 잡으면 이 경우 20 ≥ 21이 되어, i와 j가 이어져 있지도 않은데 (ti, tj) = (50, 20)이라는 멀쩡한 시각 조합이 잘립니다. 계산된 Mij가 0 이하면(bi + si + τij ≤ aj) 제약이 x와 상관없이 항상 성립하므로 아예 적지 않아도 됩니다. 반대로 ai + si + τij > bj이면 i 다음에 j는 시간상 불가능하므로 xij = 0으로 고정할 수 있습니다. 이런 정리는 9장의 전처리(presolve)가 자동으로 하는 일이기도 합니다.

지시 제약, 고정비, 택일

지시 제약(indicator constraint)은 "x = 1이면 g(t) ≤ 0"을 M 없이 솔버에 그대로 넘기는 표현입니다. 모형을 적는 사람이 M을 계산하지 않아도 되고, 솔버는 내부에서 분지(9장)로 처리하거나 스스로 M을 계산합니다. 수학적으로 허용하는 해 집합은 유효한 M을 쓴 big-M 제약과 같습니다. 즉 새로운 표현력이 생기는 것이 아니라 M을 고르는 일을 솔버에 맡기는 것입니다.

고정비(fixed charge): 연속량 w(창고에서 내보내는 양)가 양수이려면 이진변수 y(창고를 연다)가 1이어야 하고, 열면 고정비 f가 듭니다. w ≤ U·y, 목적함수에 f·y. U는 w의 유효한 상한(창고 용량)입니다. 정리 8.3과 같은 논리로 최적해에서 w = 0이면 y = 0입니다.

택일(disjunction): "조건 A 또는 조건 B 중 하나는 성립"입니다. 이진변수 s로 어느 쪽을 지킬지 고르고, 고르지 않은 쪽을 big-M으로 끕니다. 예: 정수 변수 a, b가 서로 달라야 한다(a ≠ b) ⇔ "a ≥ b + 1 또는 b ≥ a + 1". a, b ∈ {0, …, 9}라면

a ≥ b + 1 − M·ss = 0이면 a > b
b ≥ a + 1 − M·(1 − s)s = 1이면 b > a

M은 꺼진 쪽이 항상 성립할 만큼이어야 합니다. s = 1일 때 첫 줄 a ≥ b + 1 − M이 모든 a, b에 대해 성립하려면 M ≥ max(b + 1 − a) = 9 + 1 − 0 = 10. 둘째 줄도 같아서 M = 10이 가장 작은 유효한 값입니다. 가이드 10장의 종합 과제 C(기계 한 대의 작업 순서)가 이 택일 제약을 모든 작업 쌍에 쓰는 모형입니다.

곱, 절댓값, 최댓값

이진 × 이진: w = a·b는 위의 "a = b ∧ c" 정의와 같습니다. w ≤ a, w ≤ b, w ≥ a + b − 1, w ≥ 0. w는 실수로 두어도 이 네 줄이 w를 0 또는 1로 고정합니다(a, b가 정수일 때). 진리표로 확인됩니다.

이진 × 유계 실수: w = x·z (x ∈ {0,1}, 0 ≤ z ≤ U).

w ≤ U·x,  w ≤ z,  w ≥ z − U(1 − x),  w ≥ 0

x = 0이면 첫 줄과 넷째 줄로 w = 0이고 셋째 줄은 z − U ≤ 0이라 저절로 성립. x = 1이면 둘째·셋째 줄로 w = z이고 첫 줄 z ≤ U는 저절로 성립. 두 경우 모두 w = x·z입니다. 실수 × 실수는 이런 식으로 정확히 적을 수 없습니다(근사만 가능).

절댓값과 최댓값: |a − b|를 최소화하려면 새 변수 t를 두고 t ≥ a − b, t ≥ b − a, 목적함수에 t. maxk Tk를 최소화하려면 t ≥ Tk (모든 k), 목적함수에 t. 두 경우 모두 t는 "필요한 것들의 최댓값 이상"이라는 한 방향 조건만 있고, 최소화가 t를 그 최댓값까지 끌어내립니다(정리 8.3과 같은 논리). 그래서 이 요령은 그 양을 작게 하고 싶을 때만 통합니다. 절댓값을 크게 하고 싶거나 t = max가 다른 제약에 정확히 쓰여야 한다면 이진변수로 "어느 쪽이 최대인가"를 골라야 합니다(택일).

4부 · 흐름과 집합

흐름 보존과 네트워크 흐름 모형

유향 그래프(3장) G = (V, A)에서 간선 (i, j) ∈ A마다 흐르는 양 fij ≥ 0을 변수로 둡니다. 노드 i의 공급량을 bi(양수면 내보냄, 음수면 받아들임, 0이면 거쳐 감)라 하면 흐름 보존은

Σj:(i,j)∈A fij − Σj:(j,i)∈A fji = bi∀ i ∈ V   (나가는 양 − 들어오는 양 = 공급)
0 ≤ fij ≤ uij∀ (i, j) ∈ A   (용량)

목적함수 Σ cijfij를 최소화하면 최소비용 흐름 문제입니다. 공급 노드 s 하나(bs = 1), 수요 노드 t 하나(bt = −1), 나머지 0이고 비용이 간선 길이면 s에서 t까지의 최단 경로 문제가 됩니다. 흐름 보존식의 계수 행렬은 3장의 유향 그래프 근접 행렬 그대로입니다(열 하나 = 간선 하나, 그 열에 +1 하나와 −1 하나). 이 행렬의 특별한 성질 덕분에 b와 u가 정수이면 LP로 풀어도 정수 흐름이 나온다는 사실이 알려져 있고, 그 이유는 10장에서 다룹니다.

작은 예

노드 s, a, t와 간선 s→a(비용 1), a→t(비용 1), s→t(비용 3)에서 s가 2단위를 내보내고 t가 2단위를 받습니다. 용량은 모두 1입니다. 보존식: s: fsa + fst = 2, a: fat − fsa = 0, t: −fat − fst = −2. 용량이 1이라 fsa = fat = fst = 1이 유일한 가능해이고 비용은 1 + 1 + 3 = 5입니다. 용량을 2로 늘리면 s→a→t로 2단위를 보내는 쪽(비용 4)이 s→t 직행(비용 6)보다 쌉니다.

배정, 집합 분할·덮개·포장

배정 문제(assignment)는 가이드 3장에서 본 것처럼 xik ∈ {0,1}, Σk xik = 1(고객마다 정확히 하나)입니다. 일대일 배정(작업자 n명, 일 n개)이면 Σi xik = 1도 붙습니다. 일대일 배정은 이분 그래프(3장) 위의 흐름 문제이기도 합니다.

원소들의 집합 U = {1, …, m}과, U의 부분집합들의 목록 S1, …, Sn(각각 비용 cj)이 있다고 합시다. 부분집합 j를 고르면 xj = 1입니다. 원소 i가 부분집합 j에 들어 있으면 aij = 1, 아니면 0인 0/1 행렬 A를 씁니다.

정의 8.5 최소화 Σ cjxj, x ∈ {0,1}n에 대해
  • 집합 분할(set partitioning): Σj aijxj = 1 ∀ i. 모든 원소가 고른 집합들 중 정확히 하나에 들어간다.
  • 집합 덮개(set covering): Σj aijxj ≥ 1 ∀ i. 모든 원소가 적어도 하나에 들어간다.
  • 집합 포장(set packing): Σj aijxj ≤ 1 ∀ i. 고른 집합들이 서로 겹치지 않는다(보통 최대화).

경로 문제와의 연결이 중요합니다. U를 고객, Sj를 "차량 하나가 돌 수 있는 경로 하나가 방문하는 고객들"(용량과 시간창을 지키는 경로만), cj를 그 경로의 비용으로 두면, 집합 분할 문제가 곧 VRP입니다. "모든 고객이 정확히 한 경로에 포함된다"는 한 종류의 제약만 남고, 순서·시각·용량은 "어떤 경로가 목록에 있는가"에 모두 숨습니다. 대신 경로의 수가 천문학적이라 목록을 미리 다 만들 수 없습니다. 이 문제를 푸는 방법(열 생성)이 11장의 주제입니다. 삼각 부등식을 만족하는 비용이면 덮개로 풀어도 되는 경우가 많습니다. 두 번 방문된 고객을 한 경로에서 빼도 비용이 늘지 않기 때문입니다.

작은 예

고객 {1, 2, 3}, 가능한 경로 S1 = {1}(비용 4), S2 = {2}(4), S3 = {3}(4), S4 = {1, 2}(5), S5 = {2, 3}(5), S6 = {1, 2, 3}(9). 집합 분할의 가능해를 모두 나열하면 {1}{2}{3} = 12, {1,2}{3} = 9, {1}{2,3} = 9, {1,2,3} = 9입니다. {1,2}와 {2,3}을 함께 고르면 고객 2가 두 번이라 분할이 아닙니다(덮개로는 허용, 비용 10). 최적값은 9이고 최적해가 셋입니다.

5부 · 순서와 연결성

부분 순환: 이웃만 보는 식의 한계

외판원 문제(TSP): 도시 0, 1, …, n−1을 한 번씩 들르고 돌아오는 가장 짧은 순환을 찾습니다. xij = 1은 "i 다음에 바로 j"입니다(i ≠ j). 가장 먼저 떠오르는 제약은 차수 제약입니다.

Σj≠i xij = 1∀ i   모든 도시에서 정확히 한 번 나간다
Σi≠j xij = 1∀ j   모든 도시로 정확히 한 번 들어온다

(용어 하나: 유향 그래프에서는 화살표를 따라 출발점으로 돌아오는 걸음을 유향 순환이라 하고, 3장의 무향 순환과 달리 길이 2인 i → j → i도 순환으로 셉니다.)

성질 8.6 차수 제약을 만족하는 0/1 해는 "도시들을 몇 개의 서로소인 유향 순환으로 나눈 것"과 일대일로 대응한다. 그 순환이 하나뿐일 때만 TSP의 해다.

각 도시에서 나가는 간선이 정확히 하나이므로 "다음 도시" 함수 σ(i) = (xij = 1인 j)가 정의됩니다. 들어오는 간선도 정확히 하나이므로 σ는 일대일 대응(순열)입니다. 어떤 도시에서 σ를 반복 적용하면 도시가 유한하므로 언젠가 이미 본 도시가 나오는데, σ가 일대일이라 처음 도시로 돌아옵니다. 그래서 도시들은 σ의 순환들로 나뉩니다. 거꾸로 순환들로 나눈 것은 어느 것이든 차수 제약을 지킵니다. ∎

도시 6개에서 0 → 1 → 2 → 0과 3 → 4 → 5 → 3은 차수 제약을 모두 지키지만 TSP의 해가 아닙니다. 이런 순환을 부분 순환(subtour)이라 합니다. 차수 제약은 각 도시의 "앞뒤"만 보는 국소적인 식이고, "전체가 하나로 이어져 있다"는 전역적인 성질을 볼 수 없습니다. 이 한계를 메우는 방법이 여럿 있습니다.

MTZ 제약과 양방향 증명

Miller–Tucker–Zemlin(MTZ) 정식화는 출발 도시 0이 아닌 도시마다 순번 변수 ui를 둡니다.

uj ≥ ui + 1 − (n − 1)(1 − xij)∀ i ≠ j,  i, j ∈ {1, …, n−1}
1 ≤ ui ≤ n − 1∀ i ∈ {1, …, n−1}

3부의 big-M 꼴(M = n − 1)입니다. xij = 1이면 uj ≥ ui + 1. 출발 도시 0이 끼는 간선에는 이 식을 걸지 않는다는 점이 핵심입니다.

정리 8.7 차수 제약 + MTZ 제약을 만족하는 (x, u)가 있다 ⇔ x가 도시 전체를 도는 순환 하나다.

(⇒, 건전성) x가 순환 둘 이상으로 나뉜다고 합시다(성질 8.6). 그중 도시 0을 지나지 않는 순환 i1 → i2 → … → ik → i1이 적어도 하나 있습니다. 이 순환의 간선은 모두 도시 0과 무관하므로 MTZ 식이 걸려 있고, x = 1이라 ui2 ≥ ui1 + 1, …, ui1 ≥ uik + 1입니다. k개를 모두 더하면 양변의 u 합이 같아져 0 ≥ k가 되어 모순입니다.

(⇐, 완전성) x가 순환 하나 0 → i1 → i2 → … → in−1 → 0이라 합시다. uit = t(몇 번째로 방문하는가)로 둡니다. 범위 1 ≤ u ≤ n − 1은 성립합니다. xij = 1인 간선(둘 다 0이 아닌 것)은 연속한 방문이라 uj = ui + 1로 식을 등호로 지킵니다. xij = 0인 쌍에서는 식이 uj ≥ ui − (n − 2)인데, ui ≤ n − 1이고 uj ≥ 1이므로 ui − uj ≤ n − 2, 곧 항상 성립합니다. ∎

완전성 쪽에서 M = n − 1이 "유효한 가장 작은 M"으로 딱 맞게 쓰인다는 것을 볼 수 있습니다. 도시 4개로 전수 확인하면, 차수 제약을 지키는 9개의 해(자기 자신으로 가지 않는 순열) 가운데 하나의 순환인 6개는 MTZ를 만족하는 u가 있고, 부분 순환으로 나뉘는 3개(0↔1과 2↔3처럼 두 쌍으로 나뉘는 것)는 그런 u가 없습니다.

CVRPTW의 시각 제약 tj ≥ ti + si + τij − Mij(1 − xij)도 같은 일을 합니다. si + τij > 0이면 차고지를 거치지 않는 순환을 따라 시각이 계속 늘어나야 하므로 모순이 생깁니다. 시간창 식이 MTZ를 겸하는 것입니다.

부분 순환 제거 부등식(DFJ)

Dantzig–Fulkerson–Johnson(DFJ) 정식화는 순번 변수 없이 x만으로 적습니다.

Σi∈S Σj∈S, j≠i xij ≤ |S| − 1    ∀ S ⊂ {0, …, n−1}, 2 ≤ |S| ≤ n − 1

"도시들의 어떤 부분집합 S 안에서만 오가는 간선은 |S| − 1개 이하"라는 뜻입니다. S 안에 닫힌 부분 순환이 있으면 그 안의 간선이 |S|개라 위반됩니다(건전성). 순환 하나짜리 해는 S가 전체가 아닌 한 S 밖으로 나가는 간선이 반드시 있어, S 안의 간선은 많아야 |S| − 1개입니다(완전성).

문제는 개수입니다. 부분집합 S의 수가 대략 2n이라 도시 50개면 1015개가 넘습니다. 그래서 처음부터 다 적지 않고, 차수 제약만으로 풀어서 나온 해에 부분 순환이 보이면 그 S에 대한 식만 추가하고 다시 풀기를 반복합니다. "지금 해가 어기는 식이 목록에 있는가, 있다면 어느 것인가"를 찾는 일을 분리 문제(separation problem)라고 합니다. 정수해에서는 순환을 따라가 보기만 하면 되므로 쉽습니다. 이 "필요한 식만 그때그때 추가"는 10장의 절단평면, 11장의 열 생성("필요한 변수만 그때그때 추가")과 짝을 이루는 생각입니다.

연결성을 적는 세 가지 방법

부분 순환 문제는 일반화하면 "선택된 것들이 특정 노드(차고지, 출입구)와 이어져 있어야 한다"는 조건입니다. RORO 문제의 "칸에서 출입구까지 머무는 차를 피해 가는 길이 있어야 한다"(가이드 5장의 접근 가능)도 같은 종류입니다. 1차 부등식으로 적는 대표적인 방법을 셋 비교합니다(끝의 비교 표에는 앞 절의 DFJ도 함께 넣었습니다).

① 순번 변수: MTZ

위에서 본 것입니다. 노드마다 실수(또는 정수) 변수 u(6장의 쌍대 변수 u와는 무관한 순번 변수입니다. 이 장은 관용구마다 그 분야의 관례 기호를 따르므로 s, t, u, b 같은 글자가 절마다 다른 뜻으로 쓰입니다. 뜻은 각 절에서 정한 것만 따르면 됩니다)를 두고 선택된 간선을 따라 u가 늘어나게 합니다. 변수 n개, 제약 약 n2개가 늘고 big-M이 들어갑니다.

② 흐름 변수

출발 노드 0에서 상품을 흘려보내, 각 노드가 그것을 받을 수 있는지로 연결성을 판정합니다. TSP의 단일 상품 흐름 정식화는 0이 n − 1단위를 내보내고 다른 도시가 1단위씩 소비하게 하며, 흐름은 선택된 간선으로만 흐르게 합니다.

Σj f0j = n − 1,   Σi fij − Σk fjk = 1∀ j ≠ 0   (흐름 보존)
0 ≤ fij ≤ (n − 1) xij∀ i ≠ j   (선택된 간선으로만)

도시 0을 지나지 않는 부분 순환에 속한 도시들은 밖에서 들어오는 선택된 간선이 없으므로 흐름을 받을 수 없어, 소비 1을 채우지 못합니다(건전성). 순환 하나면 순환을 따라 n − 1, n − 2, …, 1을 흘리면 됩니다(완전성). 변수가 간선 수만큼 늘고, 용량 식에 계수 n − 1(big-M 같은 역할)이 붙습니다.

③ 미리 정한 순서를 따라 전파하기 (tryAgain의 방법)

순번을 변수로 두지 않고 미리 고정합니다. 3장에서 본 대로, 노드에 서로 다른 번호 h(높이)를 매기고 간선마다 "높은 쪽 → 낮은 쪽"으로 방향을 주면 유향 비순환 그래프(DAG)가 됩니다. 노드 i의 아래 이웃 pred(i) = {j : j는 i의 이웃, h(j) < h(i)}. 이진변수 yi("i는 접근 가능")에 대해

y0 = 1출입구(h = 0)는 접근 가능
yi ≤ Σj∈pred(i) yj∀ i ≠ 0   접근 가능하려면 아래 이웃 중 하나가 접근 가능
yi ≤ 1 − (i가 막혀 있음)막힌 노드는 접근 불가
정리 8.8 (전파 식의 건전성) 위 식을 만족하는 0/1 해 y에서 yi = 1이면, i에서 출발해 높이가 줄어드는 방향으로만 움직이며 막히지 않은 노드만 지나 출입구 0에 닿는 경로가 있다.

yi = 1이고 i ≠ 0이면 둘째 식에서 Σj∈pred(i) yj ≥ 1이므로 yj = 1인 아래 이웃 j가 있습니다. j로 옮겨 같은 논리를 반복합니다. 한 걸음마다 높이가 엄격히 줄므로 같은 노드를 두 번 지나지 않고, 노드는 유한하니 유한 걸음 안에 멈추는데(높이를 BFS 순번으로 잡으면 많아야 h(i)걸음), 멈출 수 있는 곳은 둘째 식이 걸리지 않는 노드 0뿐입니다. 지나온 노드는 모두 y = 1이므로 셋째 식에 의해 막히지 않았습니다. ∎ (3장의 "DAG에서 아래로만 내려가면 반드시 끝난다"는 논증 그대로입니다.)

완전성은 일부러 포기합니다. 높이를 거슬러 올라가야만 닿는 칸은 실제로 길이 있어도 y = 0일 수밖에 없습니다. 이 정식화가 허용하는 것은 "높이를 따라 내려가는 길이 있는 칸"뿐이고, 그것은 원래 문제의 접근 가능보다 좁습니다. 가이드 5장의 「규칙 때문에 잃는 것」이 이 손실입니다. 대가로 추가 변수도 big-M도 없고, 모든 계수가 0, ±1입니다.

"옮겨 간 이웃이 더 낮다"는 보장이 없어서, 걸음이 끝나지 않고 같은 노드들을 맴돌 수 있기 때문입니다. 가이드 5장의 6노드 고리로 확인합니다. 출입구 0과 칸 1~5가 0-1-2-3-4-5-0으로 이어져 있고, 칸 1과 5에 머무는 차가 있습니다. 높이는 BFS 순으로 h(1) = 1, h(5) = 2, h(2) = 3, h(4) = 4, h(3) = 5, 그래서 pred(2) = {1}, pred(4) = {5}, pred(3) = {2, 4}입니다.

CVRPTW 3첨자 정식화와 크기

가이드 3장 4부의 모형을 다시 적습니다. 노드 0은 차고지, 1~n은 고객, 차량 k = 1~K입니다. xijk ∈ {0,1}은 차량 k가 i에서 j로 바로 가면 1, tik(실수)는 차량 k가 고객 i에서 서비스를 시작하는 시각입니다. cij는 i에서 j로 가는 비용, qi는 고객 i의 수요량, Q는 차량 용량이고, si(서비스 시간), τij(이동 시간), [ai, bi](시간창)는 3부에서 쓴 그대로입니다.

최소화  Σk Σi Σj cij xijk
(1)  Σk Σj xijk = 1∀ 고객 i   집합 분할 (정확히 한 번)
(2)  Σi xihk − Σj xhjk = 0∀ 고객 h, ∀ k   흐름 보존
(3)  Σj x0jk ≤ 1∀ k   많아야 하나
(4)  Σi qi Σj xijk ≤ Q∀ k   용량 (고른 것들의 합)
(5)  tjk ≥ tik + si + τij − Mij(1 − xijk)∀ 고객 i, j, ∀ k   big-M, MTZ 겸용
(6)  ai ≤ tik ≤ bi∀ 고객 i, ∀ k   시간창

이제 각 줄이 이 장의 어느 관용구인지 이름을 붙일 수 있습니다. (1)은 집합 분할, (2)는 흐름 보존, (3)은 포장, (4)는 이진변수 가중합, (5)는 big-M 조건부 부등식이면서 정리 8.7의 MTZ 역할, (6)은 단순한 변수 범위입니다. Mij는 3부에서 유도한 bi + si + τij − aj입니다.

크기 세기. 변수의 수는 첨자 범위의 곱, 제약의 수는 ∀ 범위의 곱입니다(가이드 3장). 고객 n, 차량 K면 x는 노드 쌍 (n + 1)n개(자기 자신 제외) × K, t는 nK개입니다. n = 100, K = 10이면 x가 101 × 100 × 10 = 101,000개로 가이드가 말한 "약 10만 개"입니다. 제약 (5)는 고객 쌍 n(n − 1) × K = 99,000줄입니다.

대칭성(symmetry). 차량이 모두 같다면, 어떤 해에서 차량 번호만 바꾼 해도 비용이 같은 가능해입니다. 경로 r개를 쓰는 해 하나에 대해 번호만 다른 해가 K!/(K − r)!개 있습니다(K = r = 10이면 3,628,800개). 정수해의 개수가 쓸데없이 불어나고, 9장의 분지한계법은 본질적으로 같은 해들을 하나씩 따로 배제해야 해서 느려집니다. 처방은 두 단계입니다. "번호가 작은 차량부터 쓴다"(Σj x0j1 ≥ Σj x0j2 ≥ …) 같은 대칭 깨기 제약은 "어느 차량이 쓰이는가"의 대칭만 없애서 K!/(K − r)!을 r!로 줄입니다. 위의 K = r = 10 예처럼 차량을 모두 쓰면 합이 모두 1이라 아무것도 자르지 못하고 3,628,800개가 그대로 남습니다. 쓰인 차량들 사이의 r!까지 없애려면 경로에 순서를 강제하는 제약(예: 각 경로가 방문하는 가장 작은 고객 번호가 차량 번호 순으로 커지게)을 더하거나, 차량 첨자 k를 아예 없애는 정식화(2첨자, 집합 분할)를 씁니다. tryAgain 모형이 "어느 수요의 차인지"를 변수에 넣지 않고 구간의 개수만 센 것(가이드 6장 「정하는 것」)도 같은 대칭을 처음부터 없앤 선택입니다.

tryAgain 모형 적어 두기

이 교재는 가이드 6장의 tryAgain 모형을 여러 장에서 예로 씁니다. 여기서 한 번 완전하게 적어 두고, 뒤에서는 제약 번호 ①~⑥으로 가리킵니다. 문제 설정은 1장 「가이드의 문제 한눈에」에 있습니다. 배는 노드 0(출입구)과 칸 1, …, N−1로 된 그래프이고, 배는 항구 0, 1, …, P−1을 차례로 들릅니다. p < q < r은 항구, i, j는 노드입니다. dpq는 항구 p에서 실어 항구 q에서 내릴 차의 수, F는 경로 하나의 고정비, dist(i)는 출입구에서 칸 i까지의 최단 거리, pred(i)는 칸 i의 아래 이웃(3장 정의 3.9)입니다.

  • xpqi ∈ {0, 1}: 항구 p에서 칸 i에 실려 항구 q에서 내려지는 구간이 있으면 1. 구간은 "어느 항구에서 실려 어느 항구에서 내릴 때까지 한 칸에 서 있는 차 한 대"입니다.
  • ypi ∈ {0, 1}: 항구 p에서 노드 i가 접근 가능(머무는 차를 피해 출입구까지 높이를 따라 내려가는 길이 있음)하면 1. 첫 항구에서는 배가 비어 있고 마지막 항구에서는 차를 모두 내려서 머무는 차가 없으므로, y와 제약 ②~⑥은 중간 항구 1, …, P−2에만 둡니다.
  • zpqr ≥ 0 정수: p에서 실어 r에서 내릴 차 가운데, 중간 항구 q에서 임시로 내렸다가 다시 실어 구간을 둘((p, q)와 (q, r))로 쪼갠 대수.

이 장의 말로 읽으면 이렇습니다. 목적함수는 구간 하나가 선적 경로와 하역 경로를 하나씩 만들고 각 경로의 비용이 F + dist(i)라는 뜻입니다(이진변수 가중합). ①은 "고른 구간의 수 = 필요한 대수"인데, 구간을 쪼개면 원래 구간 (p, q)는 줄고 쪼개진 두 구간은 늘어난다는 것을 z로 맞춥니다. ②의 왼쪽은 항구 q보다 전에 실려 q보다 뒤에 내리는 차, 곧 칸 i에 머무는 차의 수입니다. ②③④는 모두 "x이면 y(또는 y가 아님)"를 여러 x에 대해 한 줄로 모은 꼴이고, ⑤⑥은 3장 정의 3.9의 전파 규칙 (다)와 (가)를 5부의 정리 8.8처럼 부등식으로 옮긴 것입니다. ②~⑤는 중간 항구와 칸마다 한 줄씩 있습니다.

가이드와 연결

가이드 3장 「이진변수로 논리를 적는 법」, 「그 밖의 우회법」의 표는 정리 8.2(절 = 부등식)와 진리표 확인법으로 모두 유도됩니다. 「x ≤ y는 "x이면 y"일 뿐」이라는 주의와 창고 예는 정리 8.3입니다. 「두 개를 한 줄로 합치는」 x1 + x2 + x3 ≤ y는 "많아야 하나"(포장)와 "x이면 y"를 겹친 것입니다.

가이드 3장 「big-M: 스위치로 제약을 켜고 끄기」와 「CVRPTW를 MIP로 적으면」의 Mij = bi + si + τij − aj는 정의 8.4의 "유효한 가장 작은 M" 계산입니다. "M이 클수록 약하다"는 말의 정확한 뜻은 9장(LP 완화)과 10장(정식화의 강도)에서 나옵니다.

가이드 3장 「순서를 적을 때 따라오는 골칫거리: 부분 순환」에서 MTZ가 부분 순환을 막는다고 한 것은 정리 8.7의 (⇒) 방향입니다. 이 장은 반대 방향(정상적인 순환은 하나도 잘리지 않는다)도 증명했습니다.

가이드 5장 「「접근 가능」: 이웃만 보고 판정하기」, 「높이가 없으면 왜 안 되는가: 서로 받쳐 주는 섬」은 정리 8.8과 6노드 고리 표입니다. 가이드가 "근거의 사슬이 반드시 출입구에서 끝나야 하므로"라고 한 문장이 정리 8.8의 증명입니다. 「규칙 때문에 잃는 것」은 표의 "완전: 아니오" 칸입니다.

가이드 6장 「제약 ① 수요: 구간의 개수 맞추기」는 4부의 흐름 보존 꼴이고, 「제약 ② 머무는 차가 있는 칸은 접근 불가」, 「제약 ③④」는 포장과 함의를 한 줄에 겹친 Σx ≤ 1 − y, Σx ≤ y, 「제약 ⑤⑥」은 정리 8.8의 전파 식입니다. 「한 칸에 두 대가 겹치는 일은 왜 없는가」는 이 장의 건전성 증명과 같은 모양(가정 → 모순)의 논증입니다.

연습문제

이진변수 a, b, c, d에 대해 "a를 하면 b와 c 중 하나는 해야 하고, d는 할 수 없다"를 정리 8.2로 부등식으로 바꾸세요.

두 절로 나뉩니다. a → (b ∨ c)는 ¬a ∨ b ∨ c이므로 (1 − a) + b + c ≥ 1, 곧 a ≤ b + c. a → ¬d는 ¬a ∨ ¬d이므로 (1 − a) + (1 − d) ≥ 1, 곧 a + d ≤ 1. 답은 두 줄 a ≤ b + c, a + d ≤ 1입니다.

"a와 b 중 정확히 하나"(배타적 또는)와 "a = b의 부정"을 각각 1차식으로 적고, 진리표로 확인하세요.

이진변수에서는 둘 다 a + b = 1입니다(부등식으로만 적으려면 a + b ≥ 1과 a + b ≤ 1 두 줄). (a, b) = (0,0): 0 ≠ 1 위반, (0,1), (1,0): 성립, (1,1): 2 ≠ 1 위반. "정확히 하나"가 참인 경우와 정확히 일치합니다.

c = a ∨ b를 정의하는 세 부등식을 적고, c를 실수 변수 0 ≤ c ≤ 1로 두어도 a, b가 정수이면 c가 자동으로 정수가 되는지 따져 보세요.

c ≥ a, c ≥ b, c ≤ a + b. a = b = 0이면 c ≤ 0이라 c = 0. a, b 중 하나라도 1이면 c ≥ 1이고 c ≤ 1이라 c = 1. 따라서 c는 정수 조건 없이도 0 또는 1로 정해집니다. (상한 c ≤ 1이 꼭 필요합니다. a = b = 1이면 c ≤ 2만 남기 때문입니다.)

bi = 30, si = 5, τij = 8, aj = 40일 때 시간 선후 제약의 가장 작은 유효 Mij는 얼마인가요? bi가 20이면요?

Mij = bi + si + τij − aj = 30 + 5 + 8 − 40 = 3. 검산: xij = 0이고 최악의 경우 ti = 30, tj = 40이면 오른쪽은 30 + 13 − 3 = 40이라 40 ≥ 40으로 딱 성립합니다. bi = 20이면 Mij = 33 − 40 = −7 ≤ 0입니다. i를 가장 늦게 시작해도 j의 시간창이 열리기 전에 도착하므로 tj ≥ ti + si + τij가 xij와 상관없이 항상 성립합니다. 그 제약은 적지 않아도 됩니다(M = 0을 넣으면 무조건 제약이 되는데, 그것도 항상 성립하므로 해를 자르지 않습니다).

정수 변수 a, b ∈ {0, …, 5}가 같지 않다는 택일 제약에서 가장 작은 유효 M은 얼마인가요?

s = 1일 때 a ≥ b + 1 − M이 모든 a, b에 대해 성립하려면 M ≥ max(b + 1 − a) = 5 + 1 − 0 = 6. 다른 줄도 대칭이므로 M = 6입니다.

도시 5개(0~4)에서 0→1→0, 2→3→4→2라는 해가 MTZ 제약을 어기는 것을 직접 보이세요. 0→1→0은 MTZ에 걸리나요?

2→3→4→2는 도시 0을 지나지 않으므로 u3 ≥ u2 + 1, u4 ≥ u3 + 1, u2 ≥ u4 + 1이 걸리고, 더하면 0 ≥ 3이라 모순입니다. 0→1→0의 두 간선은 도시 0이 끼어 있어 MTZ 식이 걸리지 않습니다. 부분 순환 하나만 막으면 해 전체가 불능이 되므로 충분합니다.

3×3 격자 배(가이드 5장 그림: pred(3) = {1}, pred(4) = {1, 2}, pred(6) = {3, 4})에서 칸 1과 칸 2에 머무는 차가 있습니다. 정리 8.8의 식으로 y6 = 1이 가능한가요?

아닙니다. y1 = y2 = 0이므로 y3 ≤ y1 = 0, y4 ≤ y1 + y2 = 0, 따라서 y6 ≤ y3 + y4 = 0입니다. 실제로도 출입구의 이웃이 1과 2뿐이라 어디로도 나갈 수 없습니다.

tryAgain 모형에서 N = 8, P = 4일 때 변수와 제약의 개수를 세세요.

x: P(P−1)/2 × (N−1) = 6 × 7 = 42. y: (P−2) × N = 2 × 8 = 16. z: P(P−1)(P−2)/6 = 4. 변수 62개. 제약 ①: 6, ②~⑤: 4 × 2 × 7 = 56, ⑥: 2. 제약 64개.

고객 3명의 집합 분할 예(본문)에서 경로 {1,2,3}의 비용을 9에서 10으로 올리면 최적해는 어떻게 되나요? 덮개로 풀면요?

분할의 가능해는 {1}{2}{3} = 12, {1,2}{3} = 9, {1}{2,3} = 9, {1,2,3} = 10이므로 최적값 9, 최적해 둘. 덮개는 여기에 {1,2}{2,3} = 10 같은 해가 더해지지만 9보다 싸지 않으므로 최적값은 같습니다.
